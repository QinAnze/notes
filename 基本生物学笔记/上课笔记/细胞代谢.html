细胞代谢

📖 能量是生命的基础。本章涵盖热力学定律、ATP、酶催化、细胞呼吸（糖酵解→Krebs循环→氧化磷酸化）和光合作用（光反应→Calvin循环）。

第一节 能量与细胞

能量来源

  • 几乎所有地球生命的能量都来自太阳
  • 自养生物（光合自养）vs 异养生物

代谢类型

类型定义能量
同化作用/合成代谢简单小分子→复杂大分子消耗能量
异化作用/分解代谢复杂化合物→简单小分子释放能量

热力学定律

第一定律（能量守恒）：

  • 宇宙总能量是常数
  • 能量可转化和转移，不能被创造或消灭

第二定律（熵增）：

  • 熵（S）：度量无序程度的量纲
  • 有序是高度不稳定状态
  • 没有过程效率超过100%
  • 生命靠不断输入能量对抗熵增 → 否则熵增→死亡

放能反应与吸能反应

类型自由能变化实例
放能反应产物自由能 < 反应物呼吸作用（自发进行）
吸能反应需输入自由能光合作用

ATP — 细胞的能量通货

ATP（腺苷三磷酸）结构：

  • 腺嘌呤（含氮碱基）+ 核糖（戊糖）+ 3个磷酸根
  • 2个高能磷酸键（水解时释放大量能量）

ATP循环：

ATP + H₂O → ADP + Pi + 能量（驱动细胞活动）
ADP + Pi + 能量 → ATP（呼吸/光合合成）

易错点：ATP 那一段

  • “高能磷酸键”这个词是个历史误称。真正释放能量的是磷酸基团水解释放自由能， 不是”断键释放能量”（断键本身要吸能）。考试按教材写法答即可，但概念要清楚。
  • ATP 的摩尔数很少、周转极快。人体一天大约自身重量体量的 ATP turnover， 所以”细胞内 ATP 储量少”和”供能能力极强”不矛盾。
  • 放能/吸能反应不能只看 ΔG，还要看耦合：单独吸能的反应没法自发进行， 必须和放能反应偶联（如ATP 水解驱动生物合成）。这是热力学第二定律的落地方式。

第二节 生物催化剂 — 酶

基本特性

  • 绝大多数是蛋白质（少数RNA→核酶）
  • 常温、常压、中性pH下高效催化
  • 通过降低活化能加速反应
  • 具有专一性（一种/一类底物）
  • 活性部位（active site）：与底物结合的局部区域
  • 诱导契合模型：酶与底物结合时构象改变

底物浓度-酶活性曲线怎么读

酶促反应速率随底物浓度上升呈双曲线（Michaelis-Menten），不是直线： 早期近似一级（底物远少于 Km），中间过渡，后期饱和（酶全部被占满，速率=Vmax）。 Km 的物理意义：达到半最大速率时的底物浓度，越小说明亲和力越高。 记住这句就能同时解”曲线怎么画""Km 怎么解释”两类题。

生工联系：酶工程 = 把酶的改造搬到基因层面

工业上想改造酶，只有三条路：

  1. 改反应条件（调pH、改温度）—— 便宜但上限低
  2. 定向进化（易错PCR + 筛选）—— 无需结构信息，但随机改造
  3. 理性设计 / 分子动力学模拟 —— 需要知道结构，做理性突变（如改活性位点附近残基）

工程菌的酶修饰三条路：

  • 共固定化：把酶固定在载体/细胞表面，循环利用
  • 化学固定化：交联成固定化酶，提高热稳定性
  • 融合蛋白：把目标酶和一个可溶标签（如MBP、Trx、弹性蛋白）融合， 利用标签的助溶能力拉高表达量和可溶性

另一个高频应用是改造酶的辅酶选择性： 把 NAD⁺依赖的酶改造成 NADPH 依赖（换辅酶结合域）， 就能接上细胞里另一套还原力（NADPH）， 这在代谢工程里叫”辅酶工程“。

酶的活力单位（U）

  • 标准条件（25℃、最适pH、底物过量）
  • 1 min催化1 μmol底物→产物的酶量 = 1 U

影响酶活性的因素

因素影响
温度活性随温度升高→最适温度→超过界限→活性下降（变性）
pH有最适pH范围，超过则活性下降
抑制剂竞争性（竞争活性部位）和非竞争性（结合别位）；可逆/不可逆
反馈抑制最终产物抑制代谢途径中的酶（维持稳态）

辅助因子与辅酶

类型说明
辅助因子无机金属离子
辅酶有机化合物（大多含核苷酸结构的维生素）
重要辅酶NAD⁺、NADP⁺、FAD（传递H⁺和电子）

核酶（ribozyme）

类型功能
催化分子内反应RNA既是底物又是催化剂（特定折叠形式）
催化分子间反应催化其他分子反应

第三节 细胞呼吸

概述

  • 生物体获得能量的主要代谢途径
  • 有机化合物 + O₂ → CO₂ + 能量
  • 主要在线粒体中进行
  • 温和条件+酶调控→能量逐步释放→高效率

慢跑→有氧呼吸（葡萄糖+O₂→CO₂+H₂O）；快跑→无氧呼吸（葡萄糖→乳酸）

三个阶段

1. 糖酵解（Glycolysis）— 细胞质

  • 不需氧参与
  • 10步化学反应
  • 葡萄糖 → 2丙酮酸 + 2ATP + 2NADH
  • 底物消耗2ATP（启动）→ 产出4ATP → 净2ATP

总反应：

葡萄糖 + 2ADP + 2Pi + 2NAD⁺ → 2丙酮酸 + 2ATP + 2NADH + 2H⁺ + 2H₂O

底物水平磷酸化：底物上的高能磷酸键直接转移到ADP→ATP

葡萄糖代谢分支：

  • 无氧→乳酸（乳酸发酵）或乙醇+CO₂（乙醇发酵）
  • 有氧→乙酰CoA→Krebs循环

2. Krebs循环（三羧酸循环/柠檬酸循环）— 线粒体基质

  • 丙酮酸氧化脱羧 → 乙酰CoA → 进入循环
  • 1分子丙酮酸 → 2CO₂ + 8H + 3NADH + FADH₂ + ATP

易错点：细胞呼吸数字速记

  • 每个葡萄糖的账：糖酵解产2 NADH；丙酮酸脱羧（2 次）产 2 NADH； Krebs（两轮）产 6 NADH + 2 FADH₂ + 2 ATP； 合计10 NADH + 2 FADH₂ + 4 ATP，最终约30~32 ATP（数目随教材/假说略变）。
  • Krebs 循环一圈释放的 CO₂ 是 2 个，但净增的中间体只有 1 个 —— 因为草酰乙酸被消耗、苹果酸又再生回草酰乙酸。它是循环反应（amphibolic）： 既分解供能，也提供氨基酸合成前体。
  • 丙酮酸脱羧 ≠ Krebs循环第一步，是两者之间的”连接反应”， 由**丙酮酸脱氢酶复合体（PDH）**催化，别把它算进循环里。
  • “无氧呼吸”其实不产ATP以外的产物优势——无氧（发酵）的目的不是省ATP， 是在缺氧时维持糖酵解继续跑（再生 NAD⁺）。 无氧呼吸 ≠ 无氧光合，两个”无氧”含义完全不同。
  • 有氧呼吸的 O₂ 参与部位只在电子传递链末端（作为电子受体生成水）， 糖酵解和 Krebs 循环都不直接用氧。所以”缺氧时先停 Krebs”这个说法不准确 —— Krebs 停是因为NAD⁺ 和 FAD 无法再生，才是根本原因。

生工联系：细胞呼吸 = 代谢工程的"中央代谢"

合成生物学的所有改造几乎都绕不开中心代谢（central metabolism）： 糖酵解、Krebs 循环、乙醛酸循环。碳流从葡萄糖进来， 经由这些枢纽节点分流到目标产物。所以：

  • 测代谢流 → 找瓶颈（13C 代谢流分析 ^13C-MFA、代谢控制分析 MCA）
  • 找限速酶 → 敲除竞争通路或过表达（例：生产赤藓糖酸时敲除 甘油醛-3-磷酸脱氢酶 GapA 阻断竞争、推高流向 PPP 的碳）
  • 强化前体供给（过表达 pyruvate carboxylase、天冬氨酸转氨酶等）

经典案例：维生素C（抗坏血酸） 工程酵母走”六碳糖→乙醇酸→L-古洛酸→L-抗坏血酸”路线， 核心改动就是把植物来源的L-GAL oxidase 基因导入酵母， 让酵母自己合成L-抗坏血酸 —— 发酵法生产维生素C 完全靠”引入新酶”。

也提醒一句风险：工程菌的代谢越改越”窄”， 往往对环境波动更敏感（副产物少=抗逆性也低），所以工业上还要配套 鲁棒性工程（比如热激蛋白过表达应对发酵产热）。

3. 氧化磷酸化 — 线粒体内膜

  • NADH和FADH₂的高能电子 → 电子传递链（呼吸链） → O₂
  • 电子能量逐步降低 → 释放能量 → 合成ATP

化学渗透学说（Peter Mitchell, 1961）

  1. 电子传递释放能量 → H⁺从基质→膜间腔
  2. 形成跨膜质子梯度（膜间腔高H⁺浓度）
  3. H⁺顺浓度梯度经ATP合酶→基质
  4. 释放能量 → ADP + Pi → ATP

ATP统计 — 1分子葡萄糖完全氧化

阶段ATP来源数量
糖酵解底物水平磷酸化4ATP - 消耗2ATP + 2NADH（→3或5ATP）5-7 ATP
Krebs循环底物磷酸化2ATP + 8NADH（→20ATP）+ 2FADH₂（→3ATP）25 ATP
总计30-32 ATP

发酵（无氧条件）

类型过程产物
乙醇发酵葡萄糖 → 2丙酮酸 → 2乙醛 → 2乙醇2CO₂ + 2ATP + 2H₂O
乳酸发酵葡萄糖 → 2丙酮酸 → 2乳酸2ATP + 2H₂O

生工联系：发酵就是最成功的生物制造

人类用了几千年的面包、酒、酸奶、酱油，本质上都是利用特定微生物的代谢能力。 工业发酵把这一套搬到了大型罐里，底盘、产物、难点各不相同。

柠檬酸发酵尤其值得记：它证明了”细胞本来会”节俭”，改造让它学会”大方”” —— 工程师的做法是找出负责”节俭”的调控基因并敲除它， 让 TCA 中间产物不再被扣下来当碳源用。这个思路（解除反馈/敲除调控）贯穿整个代谢工程。

常见工业发酵对照：

产品底盘关键点
乙醇酿酒酵母补料流加控乙醇浓度，乙醇对酵母有毒会抑制活性
乳酸（PLA 原料）乳杆菌恒温恒 pH 发酵
柠檬酸黑曲霉经典的代谢调控：柠檬酸是 TCA 中间产物，通常被”截留”不外排；菌种改良后能外排上百 g/L
谷氨酸/赖氨酸/苏氨酸谷氨酸棒杆菌野生型不产，靠抗反馈抗性突变解除终产物抑制
抗生素（青霉素、链霉素）青霉/链霉菌发酵罐里的”小树林”，条件极敏感

其他营养物质的代谢

  • 蛋白质/脂肪 → 中间产物 → 糖酵解/Krebs循环
  • 中间代谢产物 → 生物大分子合成原料

第四节 光合作用

发现历史

实验发现
柳树实验（van Helmont, 17世纪中叶）2.3kg植株+90.8kg干土→5年后树重76.7kg，土仅减57g → 认为植物从水取得物质
Priestley实验（18世纪70年代）植物能更新空气
¹⁸O示踪（1940年）证明光合作用放出的O₂来自H₂O

总反应

6CO₂ + 12H₂O → C₆H₁₂O₆ + 6O₂ + 6H₂O

两大阶段

光反应（类囊体膜）

光合色素：

色素比例吸收光功能
叶绿素a3蓝紫光+红光反应中心（草绿色）
叶绿素b1蓝光+橙色光辅助色素（黄绿色）
类胡萝卜素—蓝紫光辅助色素+保护

光系统：

光系统中心叶绿素位置
PSIIP680吸收光能→水光解放O₂
PSIP700产生NADPH

电子传递链：

  • 电子从P680→P700→NADP⁺
  • 类囊体腔增加4H⁺（pH≈5）→ 质子动力势
  • H⁺经**ATP合酶（CF₁-CF₀）**→基质→推动ATP合成

光合磷酸化：光合电子传递+磷酸化偶合→ADP+Pi→ATP

  • 非循环光合磷酸化（主要途径，产生ATP+NADPH）
  • 循环光合磷酸化（只产生ATP）

碳反应/暗反应（叶绿体基质）— Calvin循环

三个阶段：

  1. CO₂固定：Rubisco催化，CO₂+RuBP→3-PGA
  2. 氧化还原反应：3-PGA→G3P（消耗NADPH+ATP）
  3. RuBP再生：消耗ATP

总消耗：3CO₂ + 6NADPH + 9ATP → 1G3P

💡 第一个产物是三碳化合物（3-PGA）→ C3植物

C3植物 vs C4植物 vs CAM植物

特征C3植物C4植物CAM植物
CO₂固定第一产物3-PGA（3碳）草酰乙酸（4C）草酰乙酸（4C）
代表植物水稻、小麦、大豆玉米、甘蔗仙人掌、景天
气孔开闭白天开白天开夜间开，白天关
叶结构维管束鞘无叶绿体维管束鞘发达有叶绿体—
光呼吸有防止防止

易错点：C3 / C4 / CAM

  • “C3/C4”里的数字指的是 CO₂ 固定后第一产物的碳数， 不是碳的个数、不是叶子的层数、也不是循环圈数。最容易记混的就是这个。
  • C4 和 CAM 的第一产物都是草酰乙酸（4 碳），都是先由PEP 羧化酶固定； 区别在于空间分隔（C4：叶肉 vs维管束鞘）vs 时间分隔（CAM：夜 vs 天）。
  • C4 也有光呼吸，只是 Rubisco 被”CO₂ 浓缩机制”保护、光呼吸被压得很低； 说”C4 没有光呼吸”不严谨。
  • “光呼吸只在光照下发生” 的原因是需要 Rubisco 的活化（光照下 Rubisco 激活酶 carbamylation 才有活性），不是因为光呼吸本身需要光。
  • 气孔开闭策略是应对”水vs 碳”的权衡：开气孔才能进 CO₂，但也会失水。 C3 走”便宜但浪费”（高光呼吸），C4/CAM 走”先浓缩CO₂ 提高 Rubisco 效率”。

生工联系：光合作用 = 细胞工厂的"能量入口"

光合自养生物（蓝细菌、藻类）把光能直接变化学能， 这是所有生物质能路线的入口：

  • 蓝细菌改造产油脂/产氢：改造光合碳流（敲除竞争支路、强化 TAG 合成）
  • 微藻固碳：螺旋藻等做藻油、食品原料
  • 人工光合 / 蓝细菌产氢：光解水的电子不走向 PSII 而走向氢酶（H2ase）

更关键的工业实践是”反方向”——把固碳能力搬进异养细胞： 化学计量学（stoichiometric）改造核心思路之一就是 装上 carboxylase 固定 CO₂ 的模块（如引入 CEM 系统/丙酮酸羧化酶）， 把 CO₂ 直接变成 TCA 中间产物（草酰乙酸），实现**“长胖不长呼吸”**： 碳固定得越多、损失越少。这是合成生物学区别于传统代谢工程的一个新范式。

能量循环

  • 线粒体（呼吸：分解放能）+ 叶绿体（光合：储能）→ 完成能量循环
