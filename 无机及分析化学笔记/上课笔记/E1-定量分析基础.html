E1 定量分析基础

1. 定量分析概述

定量分析的一般过程

定量分析的任务是测定物质中某种或某些组分的含量，一般包括以下步骤：

  1. 取样：所取试样必须具有代表性，能反映整批物料的真实情况
  2. 试样分解：将试样分解制成溶液（酸溶法、碱溶法、熔融法等）
  3. 分离：消除干扰组分（沉淀分离、萃取分离、离子交换等）
  4. 测定：选择合适的分析方法进行测定
  5. 数据处理与结果计算：对实验数据进行统计处理，计算分析结果

🔬 生物工程应用：在生物发酵过程中，需要定量分析培养基中碳源、氮源、无机盐等组分的含量，以优化发酵条件。

纯度、含量与组分的化学表示形式

表示方法定义适用场景
质量分数 w组分质量/试样质量常量组分测定
体积分数 φ组分体积/试样体积液体试样
质量浓度 ρ组分质量/溶液体积溶液分析
摩尔浓度 c组分物质的量/溶液体积滴定分析
物质的量分数 x组分物质的量/总物质的量气体混合物

滴定分析法概述

滴定分析法（容量分析法）是将已知准确浓度的标准溶液滴加到待测溶液中，直至化学反应按计量关系完全反应，根据标准溶液的浓度和消耗体积计算待测组分含量。

滴定分析法的分类：

  • 酸碱滴定法：以质子传递反应为基础 → 详见 E2-酸碱平衡
  • 氧化还原滴定法：以电子转移反应为基础 → 详见 E4-氧化还原平衡与电极电势
  • 配位滴定法：以配位反应为基础 → 详见 E5-配合物与配位平衡
  • 沉淀滴定法：以沉淀反应为基础 → 详见 E3-沉淀生成与溶解平衡

滴定方式：

  • 直接滴定法
  • 返滴定法（剩余滴定法）
  • 置换滴定法
  • 间接滴定法

2. 定量分析中的误差与有效数字

误差与准确度

误差：测定值与真实值之间的差值。准确度由误差大小衡量。

误差的表示：

  • 绝对误差：E=x−xT​
  • 相对误差：Er​=xT​E​×100%

其中 x 为测定值，xT​ 为真实值。

偏差与精密度

偏差：单次测定值与平均值之间的差值。精密度由偏差大小衡量。

  • 绝对偏差：di​=xi​−xˉ
  • 平均偏差：dˉ=n1​∑i=1n​∣xi​−xˉ∣
  • 相对平均偏差：dˉr​=xˉdˉ​×100%
  • 标准偏差：s=n−1∑i=1n​(xi​−xˉ)2​​
  • 相对标准偏差（变异系数）：CV=xˉs​×100%

准确度与精密度的关系：

  • 精密度是保证准确度的前提条件
  • 精密度高不一定准确度高（可能存在系统误差）
  • 准确度高一定需要精密度高

系统误差与随机误差

特征系统误差随机误差
来源方法、仪器、试剂、操作偶然因素
方向单向性（偏高或偏低）双向性（时高时低）
大小可测，大小基本固定不可测，服从统计规律
减免方法对照试验、校准仪器、空白试验增加平行测定次数

🔬 生物工程应用：在酶活力测定中，系统误差可能来源于分光光度计的波长漂移，随机误差可能来源于移液操作的微小差异。

误差的传递与误差的减免

误差传递公式：

对于加减法：sR2​=sA2​+sB2​

对于乘除法：(RsR​​)2=(AsA​​)2+(BsB​​)2

减免误差的方法：

  1. 选择合适的分析方法
  2. 减小测量误差（称量、滴定体积等）
  3. 增加平行测定次数（减小随机误差）
  4. 消除系统误差（对照试验、空白试验、校准仪器）

有效数字及其运算规则

有效数字：在分析工作中实际能测量到的数字，包括所有准确数字和最后一位可疑数字。

有效数字位数的确定：

  • 数字 “0” 之前的数字不是有效数字
  • 数字中间和末尾的 “0” 是有效数字
  • pH、pM、lgK 等对数的有效数字位数取决于小数部分位数

运算规则：

  • 加减法：以小数点后位数最少（绝对误差最大）的数为准
  • 乘除法：以有效数字位数最少（相对误差最大）的数为准
  • 四舍六入五成双：尾数≤4 舍去，≥6 进位；=5 时，前一位为奇数则进，为偶数则舍

易错点：有效数字与四舍六入五成双

  • 加减法看小数位，乘除法看总有效位，两套规则不能混用。这是最经典的送分陷阱。
  • “0” 是不是有效数字：
    • 前导零（0.0025里的两个 0）→ 不是，只表示定位
    • 中间的零（10.05、光吸收里的 0.1000 mol/L）→ 是
    • 末尾的零（1000不加小数点时）→ 存疑，要写成 1.000×10³ 才明确是4位
  • 对数的有效数字看小数位数：pH = -lg[H^+]，所以 pH 的小数位数 = 原始浓度 c 的有效数字位数。 比如 c=1.0×10−5 mol/L → pH = 5.00（3 位？错，只有 2 位）。 写成 pH = 5.00 是把 2 位数据写成了 3 位。同理 lgK 与 K 的关系。
  • 四舍六入五成双不是”四舍五入”：0.125 → 0.12（进位后为偶数，舍）， 0.135 → 0.14（进位后为偶数，进）。目的是避免反复舍入产生累积偏差， 所以叫”银行家舍入”。用普通四舍五入在这类题上会丢分。

3. 实验数据处理及分析质量的保证与控制基础

有限实验数据处理概述

置信区间：在一定的置信水平下，以平均值为中心，包含总体平均值 μ 的范围。

μ=xˉ±n​t⋅s​

其中 t 为置信因子（查 t 分布表），s 为标准偏差，n 为测定次数。

可疑值的取舍：

  • Q 检验法：Q=x最大​−x最小​∣x可疑​−x邻近​∣​
  • Grubbs 检验法：G=s∣x可疑​−xˉ∣​

若计算值大于临界值，则可疑值应舍去。

分析质量的保证与控制基础

质量保证（QA）：为确保分析结果满足预定要求而采取的一系列系统性活动。

质量控制（QC）：为达到质量要求所采取的作业技术和措施。

质量控制图：

  • 以测定结果为纵坐标，测定顺序为横坐标
  • 中心线：xˉ（多次测定的平均值）
  • 警告限：xˉ±2s
  • 控制限：xˉ±3s

🔬 生物工程应用：在生物制药质量控制中，HPLC 分析药物含量时需要使用质量控制图监控分析过程的稳定性。
