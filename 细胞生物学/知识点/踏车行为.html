踏车行为

Nov 25, 2026, 12 min read

踏车行为

相关笔记：细胞运动、有丝

0. 一句话概括

踏车行为（treadmilling）指 actin 纤维或微管在一端加亚基、另一端减亚基，纤维总长度基本不变，而亚基本身像跑步机的履带一样单向流过。它不是”纤维在移动”，而是”亚基在流动”；这是一种消耗 ATP（或 GTP）的非平衡稳态，也是细胞迁移、胞质分裂、内吞与病原体运动的核心机制。

1. 概念与发现

  • 1970 年代，Wegner 用纯化的 actin 证明：在 ATP 存在时，actin 纤维可以在没有马达蛋白的情况下持续”加头去尾”，他把这种现象命名为 treadmilling（踏车）。
  • 三个必要条件：
    1. 纤维有极性：两端化学性质不同；
    2. 两端的临界浓度不同：Cc+​<Cc−​；
    3. 持续供能：ATP（actin）或 GTP（微管）水解维持非平衡态。
  • 与”动态不稳定（dynamic instability）“不同：后者是单根微管在”生长”与”灾变缩短”之间随机切换，长度大幅波动；踏车是两端同时加/减，长度近似恒定。

2. 分子基础（以 actin 为例）

2.1 纤维的极性

  • actin 单体（G-actin，42 kDa）聚合成长丝（F-actin），呈双螺旋，直径约 8 nm。
  • 两端结构不同：
    • + 端（barbed end）：生长快，亚基亲和力高；
    • − 端（pointed end）：生长慢，解离占优。
  • 这种极性来自单体在纤维中的定向排列——所有亚基”头朝同一方向”，因此两端暴露的面不同。

2.2 ATP 水解循环

  1. ATP-actin 结合到 + 端；
  2. 聚合后一段时间内，ATP 被水解为 ADP-Pi；
  3. 磷酸释放，变成 ADP-actin；
  4. ADP-actin 对纤维的亲和力低，优先从 − 端解离；
  5. profilin 把 ADP-actin 的 ADP 换成 ATP，单体重新”充电”，回到 + 端。

关键点：ATP 水解并不是聚合所必需，聚合可以用 ADP-actin 发生；水解的作用是”老化标记”，让旧亚基更容易被拆掉，从而保证踏车方向。

2.3 临界浓度

端临界浓度 Cc​含义
+ 端约 0.1 μM高于此浓度净聚合
− 端约 0.6 μM高于此浓度净聚合，低于则净解离

当游离 G-actin 浓度处于两者之间（约 0.1–0.6 μM）时：

    • 端：浓度高于 Cc+​ → 净加；
  • − 端：浓度低于 Cc−​ → 净减；
  • 两端速率相等时，长度不变，但亚基持续从 − 端流向 + 端。

2.4 辅助蛋白

蛋白作用
profilin结合 ATP-actin，促进核苷酸交换，把它送到 + 端
cofilin/ADF结合 ADP-actin，切断纤维，加速 − 端解聚
twinfilin、CAP在 − 端”接住”ADP-actin，防止重新聚合
capping protein封住 + 端，终止延伸
formin在 + 端持续加合，形成长直束
Arp2/3在纤维侧面成核分支，形成网络
tropomyosin结合纤维侧面，保护其不被 cofilin 切断

这些蛋白共同决定”哪一端加、哪一端减、速度多快”。

3. 体外与体内

3.1 体外

  • 纯化 actin + ATP + Mg²⁺ 即可在试管中观察到踏车；用 TIRF 显微镜可直接看到单根纤维的”加头去尾”。
  • 体外踏车速率由动力学常数决定，通常远慢于细胞内的整体流动。

3.2 体内

结构踏车的表现
板状伪足前端聚合、后端解聚，网络整体向后流（retrograde flow）
丝状伪足+ 端加合，− 端解聚，纤维束延长或回缩
收缩环actin 与 myosin 共同周转，环直径缩小
吞噬杯局部聚合推动伪足包绕颗粒，杯闭合并回收
内吞 actin patch短寿命 actin 斑块快速组装—解聚
病原体彗尾Listeria、Rickettsia、牛痘病毒利用宿主 actin 踏车推动自身

3.3 速度量级

  • 细胞内 retrograde flow 约 1–5 μm/min。
  • Listeria 彗尾推进约 0.1–0.4 μm/s，比多数细胞爬行还快。

4. 微管也能踏车

  • 微管由 α/β 微管蛋白二聚体组成，+ 端加 GTP-微管蛋白，− 端解离 GDP-微管蛋白；同样有 Cc+​<Cc−​。
  • 微管的踏车在体外可以观察到，但在细胞内更多表现为动态不稳定（catastrophe/rescue）。
  • 体内的典型例子是动粒微管极向流（poleward flux）：在有丝分裂中期，动粒微管在靠近动粒的 + 端不断加合，同时在纺锤体极的 − 端不断解聚，微管”整体向极流动”而长度不变。这与染色体列队、后期 A 的染色体移动密切相关（见 有丝）。

5. 踏车与逆行流：两个层次

层次现象驱动
分子踏车：亚基在两端加/减ATP 水解 + 临界浓度差
网络逆行流：actin 网络相对基底向后移动踏车 + myosin II 收缩 + 黏附

分子离合器模型（clutch model）：

  • 黏附（整合素–基质）把 actin 网络”挂”在基底上；
  • 若离合器接合，网络不能后退，聚合的推力就转化为膜前伸；
  • 若离合器打滑，网络向后流动，形成逆行流，前伸效率下降。

所以”踏车”是分子机制，“逆行流”是网络尺度表现，二者不能混为一谈。

6. 功能

  • 细胞迁移：板状伪足前端聚合提供推力，后端解聚回收材料。
  • 极性建立：踏车速率的局部差异可以打破对称，帮助细胞”定头尾”。
  • 胞质分裂：收缩环中的 actin 持续周转，环才能缩小（见 有丝）。
  • 内吞与吞噬：actin 斑块与吞噬杯的快速组装—解聚依赖踏车。
  • 病原体运动：Listeria 表面蛋白 ActA 招募 Arp2/3、VASP 与 profilin，在细菌后端组装彗尾；彗尾”加头去尾”把细菌推向前方。
  • 机械做功：聚合本身可以产生皮牛级力，足以推动膜或推动负载。

7. 能量学

  • 踏车是非平衡稳态：ATP 水解释放的能量维持”两端浓度差 + 极性排列”。
  • 每个亚基循环消耗 1 个 ATP；细胞在迁移时 actin 周转极快，ATP 消耗可观。
  • 能量一部分用于做功（聚合推力），一部分以热耗散。
  • 若去除 ATP（或用 latrunculin 螯合单体），纤维会迅速解聚，踏车停止。

8. 研究方法与工具药

方法/药物作用
pyrene-actin 荧光体外实时监测聚合/解聚动力学
TIRF 单纤维成像直接观察两端加/减
荧光斑点显微镜（FSM）在活细胞中追踪 actin 网络的流动
FRAP测量 actin 周转速率
latrunculin A螯合 G-actin，促使纤维解聚
jasplakinolide稳定 F-actin，抑制踏车
cytochalasin D封住 + 端，抑制延伸
phalloidin稳定 F-actin（多用于固定细胞染色）
nocodazole / paclitaxel分别破坏 / 稳定微管

9. 病理与应用

  • 肿瘤侵袭：癌细胞依赖 actin 踏车与伪足突出进行迁移；相关蛋白（cofilin、profilin、Arp2/3 复合体）常被上调。
  • 病原体感染：Listeria、Rickettsia、牛痘病毒利用宿主踏车系统；ActA 缺失的菌株失去胞内运动能力。
  • 药物靶点：actin 与微管靶向药（细胞松弛素、紫杉醇、长春碱）在肿瘤治疗与实验研究中广泛使用。
  • 发育：原肠胚形成、神经管闭合、伤口愈合都依赖 actin 踏车与皮层收缩。

10. 常见误区

  1. “踏车就是纤维在移动”：纤维位置基本不变，移动的是亚基。
  2. “踏车需要 myosin”：体外纯化 actin 即可踏车，myosin 只是体内网络流动的参与者。
  3. “踏车等于动态不稳定”：前者两端同时加/减、长度恒定；后者随机生长与灾变。
  4. “两端同时加亚基”：踏车的定义就是一端加、另一端减。
  5. “ATP 水解是聚合必需”：水解发生在聚合之后，主要作用是标记”旧亚基”。
  6. “踏车不耗能”：它是耗能的非平衡稳态。
  7. “所有 actin 结构都在踏车”：微绒毛、肌节等稳定结构周转极慢。
  8. “逆行流就是踏车”：逆行流是网络尺度现象，踏车是分子尺度机制。
  9. “微管不会踏车”：体外可踏车，体内有极向流等类似表现。
  10. “踏车速率等于聚合速率”：踏车速率是净通量，不等于单端加合速度。

11. 一页速记

  • 定义：一端加、一端减，长度不变，亚基单向流。
  • 前提：纤维极性 + Cc+​<Cc−​ + ATP 水解。
  • actin：ATP-actin 从 + 端进，ADP-actin 从 − 端出；profilin 送货、cofilin 拆旧。
  • 微管：GTP 加于 + 端、GDP 失于 − 端；体内典型为动粒微管极向流。
  • 与逆行流：踏车是分子机制，逆行流是网络表现；离合器决定”推膜”还是”打滑”。
  • 功能：迁移、极性、胞质分裂、内吞、Listeria 彗尾。
  • 工具药：latrunculin 拆、jasplakinolide 稳、cytochalasin 封端。
