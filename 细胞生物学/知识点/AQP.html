水通道蛋白（Aquaporin, AQP）

核心命题：水通道蛋白是跨越细胞膜的水专用通道，属于 MIP（Major Intrinsic Protein）超家族。人类基因组编码 13 个 AQP 成员（AQP0–AQP12）。

三条主线：

  • 结构上极度保守：全部为 6 次跨膜螺旋（6-TM），含两个NPA 基序构成的水通道桶
  • 功能上分为两大类：水选择性水通道（aquaporin，只过水）与甘油通道（aquaglyceroporin，过水+甘油/小溶质）
  • 分布上高度组织特异：每个组织只表达特定几种，与该组织的生理功能精确对应

一、家族概览

1.1 基本特征

项目内容
家族命名AQP（Aquaporin）；属于 MIP（Major Intrinsic Protein）超家族
亚型数量人类 13 个（AQP0–AQP12）；γ-TIP 为植物液泡膜通道（Tonoplast Intrinsic Protein）
蛋白大小约 250–320 个氨基酸（30–35 kDa）
跨膜结构⭐ 6 次跨膜α-螺旋（TM1–TM6）；N 端和 C 端均在胞质侧
关键基序⭐ 两个 NPA 基序（Asn-Pro-Ala，天冬酰胺-脯氨酸-丙氨酸），构成水通道的”桶壁”
选择性滤器ar/R（aromatic/arginine）基序——决定只过水还是也过甘油
寡聚状态同源四聚体（AQP1 晶体结构证实）；单体的”通道”与四聚体在膜上共存
转运方式被动、不耗 ATP；渗透压驱动的顺水势扩散
底物① 纯水通道：H₂O；② 甘油通道：H₂O + 甘油 + urea + 小溶质

二、组织分布总表（教材核心表 + 现代补全）

2.0 分布示意图

📌 分布即功能：每个组织只表达它需要的那几种通道，结构与生理需求精确对应。

  • 分泌型上皮（集合管、泪腺、汗腺）→ AQP2/3/5/6：负责分泌液体
  • 中枢神经→ AQP4：负责 K⁺/水稳态，但对脑水肿双向作用
  • 代谢组织→ AQP7（脂肪）/AQP9（肝、中性粒）：负责甘油输出与免疫 ROS 爆发
  • 终身使用的部位→ AQP0（晶状体）：演化出 C 端切除加工换取长期稳定性

三、结构：6 次跨膜与 NPA 桶

上半部分（单体结构）：紫色为 6 条跨膜螺旋，橙色为两个胞质环中的 NPA 基序（各自形成伸入膜内的半螺旋 Pa / Pb）。两个 NPA + Pa/Pb + TM2/TM5 共同围成”水通道桶”；胞外侧的 ar/R 滤器（芳香族残基 + 精氨酸）是底物选择的关卡。

下半部分（选择性）：⭐ 一个氨基酸决定底物谱——甘油通道的 NPA 中 N 被缬/异亮/苯丙氨酸替换（疏水、体积大），滤器变宽 → 容许甘油通过。AQP1 单点突变 N→V 即可从水通道转为甘油通道。

3.1 拓扑结构

上图：6-TM 拓扑——环 B / 环 D 的两个 NPA 各自形成伸入膜内的半螺旋 Pa / Pb，与 TM2、TM5 共同围成水通道桶（water-filled pore）。

结构域位置关键要素
TM1–TM6跨膜两组三联体对称排列；TM2/TM5 + Pa/Pb + NPA 围成桶
环 A / 环 C / 环 E胞外含 ar/R 选择性滤器（芳香族 + 精氨酸）；对水/甘油的选择性决定于此
环 B胞质，含 NPA形成半螺旋 Pa，伸入膜内
环 D胞质，含 NPA形成半螺旋 Pb，伸入膜内
N 端 / C 端胞质决定亚细胞定位（质膜 vs 胞器膜）、调节活性

3.2 ar/R 选择性滤器：水 vs 甘油的决定者

ar/R 滤器位于胞外端，由芳香族残基（F165 / W188 / Y202，侧链窄）与精氨酸 R207（带正电）构成；滤器下方再按 NPA 中第三个残基分流：

类型NPA 中的 N残基性质滤器孔径可通过的底物
水选择性 AQP（如 AQP1 / AQP4）天冬酰胺（N）极性、小窄只容许单个水分子
甘油通道（AQP3 / AQP7 / AQP9）缬氨酸 / 异亮氨酸 / 苯丙氨酸疏水、体积大变宽容许甘油等小溶质通过

🎯 经典结论：AQP1 单点突变（NPA 中 N → V）即可把它从水通道转变为甘油通道。这是”一个氨基酸决定底物选择性“的最有力证据。

四、各亚型详解

4.1 AQP0（MIP）——“晶状体专用，不存在于其他组织”

维度内容
分布⭐ 仅晶状体纤维细胞（lens fiber cells）——哺乳动物组织中分布最局限的 AQP
功能维持晶状体透明性与水稳态；晶状体无血管，水分靠 AQP0 被动平衡
独特之处⭐ AQP0 在表达后被切除 C 端 12 个氨基酸（蛋白水解成熟）→ 转变为更稳定的通道，寿命极长（晶状体蛋白半衰期数十年）
病理🔴 AQP0-KO 小鼠发生 cataracts（白内障）**，晶状体蛋白聚集、液化
临床白内障的潜在治疗靶点（AQP0 突变/表达下调与年龄相关白内障）

🧠 记忆点：AQP0 = 只在眼睛的晶状体里。它为了”终身使用”演化出了 C 端切除加工——这是教科书级的”蛋白加工增加稳定性”案例。

4.2 AQP1——“最广泛的水通道”

维度内容
分布红细胞、肾近曲小管、睫状上皮、大脑脉络丛、肺泡上皮细胞（教材原表）；此外毛细血管内皮、脑星形胶质细胞足突、血管平滑肌
功能① 红细胞：调节红细胞体积与变形性，通过肾小球滤过
② 肾近曲小管：重吸收滤液中 ~90% 的水（等渗重吸收）
③ 肺泡上皮：清除肺泡内多余水分，维持气体交换表面干燥
④ 脉络丛：分泌脑脊液
病理🔴 AQP1-KO 小鼠表现出尿量增多但浓缩能力正常（集合管代偿）、血管通透性改变、肿瘤生长与血管生成异常
🔴 AQP1 表达↑与肿瘤血管生成、转移相关（多个肿瘤模型）
研究地位⭐ AQP1 是第一个被克隆的水通道（1992, Agre 实验室）；X 射线晶体结构（1996, Science）——结构生物学的里程碑

4.3 AQP2——“抗利尿激素的效应器”

维度内容
分布⭐ 肾集合管主细胞（严格而言：连接细胞与主细胞的顶端膜）
调控⭐ 完全由抗利尿激素（ADH/加压素, vasopressin）控制——见下方级联
病理🔴 肾性尿崩症（NDI）：AQP2 突变或 V2R 信号缺陷 → 多尿、烦渴（治疗：氨甲环酸+噻嗪类，或托VP 类似物去氨加压素）
🔴 Aq2-BI 抗体（自身免疫性 NDI）

ADH → AQP2 的调控级联

flowchart TD
    A["抗利尿激素（ADH / vasopressin）"] -->|"结合集合管主细胞顶端膜的 V2 受体"| B["Gs 蛋白 → 腺苷酸环化酶 → cAMP↑"]
    B --> C["PKA 激活 → 磷酸化 AQP2（Ser/Thr 位点）"]
    C --> D["AQP2 从囊泡（GSV）插入顶端膜"]
    D --> E["集合管水通透性↑↑ → 水被重吸收回血液"]
    E --> F["尿液浓缩（可达 800–1200 mOsm/kg）"]
    F --> G["ADH 撤除 → AQP2 内吞回收 → 尿液稀释"]

⚠️ 核心机制：AQP2 不改变表达量，只改变定位——从胞内囊泡转位到顶端膜。这是”急性调控“的经典范例（与 GLUT4 转位类似，但分子完全不同）。

4.4 AQP4——“中枢神经系统的水通道（双刃剑）”

维度内容
分布⭐ 中枢神经系统——星形胶质细胞足突（与毛细血管接触）、室管膜细胞；此外肾集合管、呼吸道支气管上皮（教材原表）；骨骼肌、视网膜
靶点⭐ AQP4 抗体（抗 AQP4-IgG）——视神经脊髓炎谱系疾病（NMOSD / Devic病）的特异性自身抗体靶点
对脑水肿的双向作用🔴 促进细胞毒性脑水肿（cytotoxic edema）：水从血液→细胞内，细胞肿胀、神经元死亡
🟢 限制血管源性脑水肿（vasogenic edema）：阻止水从血管→细胞间隙
→ AQP4-KO 小鼠结果：细胞毒性水肿减轻，但血管源性水肿加重——⭐ 说明 AQP4 在不同水肿类型中作用相反
生理意义⭐ 脑K⁺/水稳态维持、神经兴奋性调控；AQP4 表达↓会增加癫痫易感性
其他参与运动神经肌肉接头（AQP4 在肌膜/肌腱连接处，与肌肉收缩力相关）

🔑 关键理解：AQP4 在 CNS 是双向的——它既是水进入脑细胞的”通道”，也是把水排出脑组织的”排水渠”。这解释了为什么 AQP4 抑制剂不能用于治疗脑水肿——不同水肿类型需要相反的作用方向。

4.5 AQP5——“分泌型水通道”

维度内容
分布⭐ 角膜、泪腺、汗腺（教材原表）；此外唾液腺、乳腺、气管支气管腺
功能① 泪腺：分泌层液（泪液的三层：脂质层/水层/黏液层，AQP5 提供水层）
② 汗腺：汗液分泌（主要是离子型汗，经汗管时 AQP5 回收水分）
③ 角膜：维持角膜含水量与透明度（角膜需约 75% 含水）
④ 唾液腺：唾液的水分分泌
病理🔴 AQP5-KO 小鼠：严重泪腺分泌减少、唾液腺分泌减少、角膜上皮异常
🔴 Sjögren 综合征（干燥综合征）：泪腺/唾液腺 AQP5 表达↓ → 干眼、口干；AQP5 是干燥综合征的候选生物标志物
🔴 COPD（慢阻肺）：气道黏液脱水、AQP5 表达↓

4.6 AQP3与 AQP7——“甘油通道与代谢”

AQP3

维度内容
分布⭐ 肾集合管、呼吸道支气管上皮细胞（教材原表）；此外结肠、皮肤、胃肠道、免疫细胞
功能① 汗腺：分泌汗液（甘油通道 + 水通道）
② 结肠：水与甘油吸收
③ 支气管黏液的水化
④ 表皮：经皮水分吸收（配合 AQP5）
病理🔴 Sjögren 综合征（AQP3 表达↓）
🔴 特应性皮炎（AD）：皮肤 AQP3 表达↓ → 屏障功能受损

AQP7

维度内容
分布⭐ 脂肪组织、汗腺、肝（教材原表）
核心功能⭐ 甘油输出——⭐ 这是 AQP7 在脂肪组织中存在的根本原因：
脂肪甘油三酯（TAG）水解产生游离甘油，AQP7 把甘油运出脂肪细胞 → 经血液到肝 → 糖异生
→ AQP7 = 脂肪动员（脂解）的关键通道
机制意义肾上腺素 → cAMP/PKA → ABL（脂肪甘油三酯脂肪酶） 脂解 → 甘油释放 → AQP7 导出。缺乏 AQP7 时甘油无法离开脂肪细胞 → 堆积在细胞内造成脂毒性
表型AQP7-KO 小鼠：体重减轻、脂肪堆积减少（但高脂饮食下体重↑）；抗高胰岛素血症

🧠 记忆点：AQP7 = 脂肪组织的甘油出口。理解它只需记住”脂解产生的甘油必须被运走“——这与 GLUT4 是肌肉的葡萄糖入口正好对称。

4.7 植物的 γ-TIP

维度内容
全称γ-TIP（Tonoplast Intrinsic Protein）
分布⭐ 植物液泡膜（tonoplast）（教材原表）
功能调节液泡与胞质之间的水交换——维持细胞膨压（turgor）；植物气孔开闭也依赖液泡水进出
意义植物中没有 GLUT 类的质膜水通道，水跨膜主要靠TIP；是植物抗旱/抗逆研究的重要对象（TIP2;1 等参与 ABA 信号）

五、水通道的调控

5.1 调控层级总表

调控层级代表机制例子
急性：囊泡转位胞内囊泡 ↔ 质膜⭐ AQP2（ADH → PKA → 转位）；AQP4（脑水肿、癫痫）
急性：pH 门控pH 敏感性⭐ AQP6（pH < 6.5 才打开）；AQP1（低 pH 抑制）
化学修饰：磷酸化PKA / PKC / 蛋白激酶AQP2（Ser/Thr）；AQP1（Thr）
抑制：汞与硫醇Hg²⁺、金盐与半胱氨酸共价结合，堵塞通道⭐ HgCl₂ 抑制 AQPs（实验工具）；病理：汞中毒肾损伤
抑制：脱水收缩高渗 → 细胞脱水AQP1、AQP3 表达下调
长期：转录调控转录因子 + 激素AQP2（ADH 长期 → 表达↑）；AQP8（肝再生）；HNF4A → AQP9（肝癌）；AQP5（Sjögren、COPD）
蛋白降解泛素化 / 蛋白酶体AQP2（AQP2 内吞后降解）；AQP0（反向：C 端切除提高稳定性）

5.2 AQP6 的 pH 门控（特例）

AQP6 是唯一的高选择性子（subselectivity）AQP：在**酸性 pH（pH 6.5）**时才被激活。

生理位置：位于肾近曲小管，紧邻 AE1（anion exchanger 1，氯-碳酸氢盐交换器）。近曲小管细胞内 pH 偏酸 → AQP6 打开 → 甘油/尿素/水通过

意义：这是通道活性严格由环境 pH 门控的罕见范例，也是**“亚选择性（subselectivity）“**概念的经典案例。

6.2 AQP4 与脑水肿的双向作用（重要概念）

flowchart TB
    BBB["血脑屏障（毛细血管）"]
    BBB --> C["细胞毒性水肿（cytotoxic edema）"]
    BBB --> V["血管源性水肿（vasogenic edema）"]
    C --> C1["正常：水分均衡"]
    C1 --> C2["屏障受损时：水从血管进入细胞内"]
    C2 --> C3["AQP4 允许水进入 → 细胞肿胀 → 神经元死亡"]
    C3 --> C4["AQP4-KO → 减轻"]
    V --> V1["正常：水分均衡"]
    V1 --> V2["毛细血管通透性↑时：水从血管进入细胞间隙"]
    V2 --> V3["AQP4 把水排出到细胞内 → 保护细胞内不被稀释"]
    V3 --> V4["AQP4-KO → 加重"]

🎯 结论：AQP4 抑制剂不能用于治疗所有脑水肿——它在细胞毒性水肿中是有害的（促进水进入），在血管源性水肿中是有益的（排水）。治疗策略必须按水肿类型区分。

九、常见误区澄清

误区正确认识
❌ “水通道能主动泵水”❌ 完全被动，靠渗透压梯度。耗 ATP 的是水通道的调控（如 AQP2 转位）而非转运本身
❌ “所有 AQP 都只过水”❌ AQP3/7/9/10 是甘油通道，还过尿素、H₂O₂、NO 等小溶质
❌ “AQP2 是泵水”❌ AQP2 本身只是通道；它由 ADH 通过 V2R-cAMP-PKA 调控转位——这是”调控”而非”泵”
❌ “AQP4 能治脑水肿”❌ ⭐ AQP4 对脑水肿是双向的：促细胞毒性水肿、抑血管源性水肿。必须按水肿类型区分
❌ “AQP 在所有细胞表达”❌ 分布高度特异：AQP0 只在晶状体；AQP2 只在集合管
❌ “AQP0 就是普通的 AQP”❌ 它表达后 C 端被切除 12 个氨基酸——加工成更稳定的通道（终身使用的特化）
❌ “AQP7 是水通道”⚠️ 它是甘油通道。在脂肪组织中它的功能是导出脂解产生的甘油，而非”过水”
❌ “汞盐抑制是可逆的”❌ Hg²⁺/pCMBS 与半胱氨酸共价结合，不可逆，必须透析彻底去除
❌ “AQP9 只是代谢通道”❌ 它在中性粒细胞中参与 ROS 爆发（先天免疫），是免疫功能通道
❌ “TIP 是植物的 GLUT”❌ TIP 是液泡膜通道，负责膨压调节与气孔运动；植物质膜水通道另有PIP 家族

总结 AQP 家族的核心逻辑是”分布即功能”——每个组织只表达它需要的那几种通道，分子结构与生理需求精确对应：

  • 分泌型上皮（集合管、汗腺、泪腺）→ AQP2/AQP3/AQP5，负责分泌液体；AQP2 额外受 ADH 急性调控（只转位，不改表达）
  • 中枢神经→ AQP4，负责K⁺/水稳态；但对脑水肿双向——所以不能一刀切用抑制剂
  • 代谢组织→ AQP7（脂肪）/AQP9（肝、中性粒），负责甘油输出与免疫 ROS 爆发
  • 特殊部位→ AQP0 只在晶状体（终身使用，故演化出 C 端切除加工）

结构上，6-TM + 两个 NPA 基序 + ar/R 滤器是全家族的统一模板；而 NPA 中一个氨基酸的替换（天冬酰胺 → 疏水残基）就足以把”水通道”变成”甘油通道”——这是结构决定功能最简洁的证明。
