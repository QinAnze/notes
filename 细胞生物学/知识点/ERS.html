ERS：内质网应激中的三个反应

内质网（ER）是”造蛋白”和”造脂”两条流水线的车间，所以 ER 出问题时也分两类根源：蛋白（折不出、搬不动）与脂（胆固醇/磷脂不足或过量）。细胞给出的对应反应就是三个：

反应感知什么核心解决
UPR未折叠/错误折叠蛋白折叠能力、降解能力
EORER 腔内蛋白负荷超载ER 体积、分泌通量
固醇调节级联ER 胆固醇水平胆固醇合成与摄取

三者共享 NF-κB / ATF 等转录枢纽，因此常同时被激活、互相串扰，不能简单当成三条平行线。

一、总览对比

维度UPR（未折叠蛋白反应）EOR（ER 超载反应）固醇调节级联（SREBP 通路）
触发信号未折叠蛋白（UPs）积聚蛋白合成速率 > ER 加工/分泌能力（即使折叠正确）ER 胆固醇↓、甘油三酯↓、脂肪酸代谢变化
触发方式BiP 被占满 → 释放 PERK/ATF6/IRE1折叠正确的蛋白太多，不经过 BiP-UPR 轴SREBP/SCAP 感知胆固醇 → 移位
主要传感器BiP（GRP78）NF-κB / TRAF2 等，尚在研究中SCAP 的 SSD 域
反应核心先停翻译、后扩产能、不行就凋亡扩大 ER 膜面积 + 上调分泌通路上调 HMG-CoA 还原酶、LDLR 合成
时间尺度秒~小时（可逆）小时级小时~天
典型诱导剂Tunicamycin（阻断 N-糖基化）、Thapsigargin、DTT单纯过表达正确折叠的分泌蛋白（如过表达胰岛素原、白蛋白、免疫球蛋白）甲羟戊酸缺乏、LDL 缺乏、环糊精抽提胆固醇
结局适应 / 凋亡适应为主（较少凋亡）代谢稳态恢复
关键转录因子ATF6、XBP1s、ATF4/CHOPNF-κB、ATF6（重叠）SREBP-2（胆固醇）、SREBP-1（脂肪酸/甘油三酯）

二、UPR（未折叠蛋白反应）

详见 Bip。这里只作定位性总结。

核心逻辑：BiP 结合位点被未折叠蛋白占满 → 三个 ER 膜感受器（PERK、ATF6、IRE1）获得自由 → 三条支路。

支路传感器分子事件功能
ATF6ATF6（90 kDa）运至高尔基体，被 S1P/S2P 双切成活性片段 → 入核上调 BiP、PDI、ERp57、钙网蛋白
IRE1IRE1α/β寡聚化 → 内切核酸酶活性 → 剪接 XBP1 mRNA（移码）XBP1s 上调折叠酶、ERAD、脂质合成
PERKPERK自磷酸化 → 磷酸化 eIF2α → 全局翻译抑制少数 mRNA 逃逸翻译：ATF4 → CHOP（凋亡开关）

关键特征：UPR 感知的是 BiP 的占用率，不是蛋白总量。折叠有问题的蛋白少而正确时，UPR 不激活——这正是 EOR 存在的理由。

三、EOR（ER Overload Response，内质网超载反应）

3.1 定义与核心特征

EOR 指 分泌蛋白合成速率超过 ER 加工与分泌能力时启动的反应，关键点在于这些蛋白本身折叠正常。

特征说明
不经过 UPR/BiP 轴蛋白折叠正确，不占用 BiP 折叠位点
激活 NF-κB通过非经典通路（常涉及 p50/p65 核易位）
与 UPR 有交集两者都上调 BiP、部分共享 ATF6
诱导 ER 扩张增加 ER 膜面积以提升分泌通量
可独立于 CHOPEOR 通常不引发凋亡，以适应性为主

3.2 触发与实验证据

经典实验：在细胞中过表达正确的分泌蛋白（如胰岛素原、白蛋白、Ig 轻链），观察到：

  • ER 膜面积显著扩张；
  • BiP 与 PDI 表达上调；
  • NF-κB 活化；
  • 但不伴随 UPR 标志性变化（如 XBP1 剪接、eIF2α 磷酸化程度较轻）。

生理对应：浆细胞大量分泌抗体、胰腺 β 细胞大量分泌胰岛素、肝细胞分泌白蛋白时的产能瓶颈——蛋白本身没问题，是”订单量“压垮了车间。

3.3 与 UPR 的关系

flowchart TD
    A["蛋白合成超载"] --> B["蛋白折叠正确"]
    A --> C["蛋白折叠错误"]
    B --> D["EOR（ER 扩张、NF-κB）"]
    C --> E["UPR（停翻译、折叠/降解、CHOP）"]
    D --> F["共同结果：ER 产能提升（BiP、PDI、钙网蛋白上调）"]
    E --> F

易混点：很多教材把 EOR 直接归入 UPR 讨论。严格说二者是平行且可重叠的两套反应——UPR 问”折得好不好”，EOR 问”订单多不多”。

四、固醇调节级联（SREBP 通路）

4.1 核心逻辑：胆固醇多了就”不许再合成”

细胞需要精确控制膜胆固醇水平，感知点在 ER——但合成车间在胞质（HMG-CoA 还原酶）。ER 如何远程调控？答案是 SREBP/SCAP 穿梭机制。

flowchart TD
    A["ER 胆固醇充足"] --> B["SCAP 与胆固醇结合 → SCAP 与 INSIG 锁定"]
    B --> C["SREBP 被扣留在 ER → 不下调任何基因 → 关闭"]
    D["ER 胆固醇降低"] --> E["SCAP 释放 → SCAP–SREBP 复合物被 COPII 包裹"]
    E --> F["运至高尔基体"]
    F --> G["S1P 切一次（去除腔内结构域）"]
    F --> H["S2P 切第二次（释放 N 末端）"]
    G --> I["活性 SREBP（成熟形式）入核"]
    H --> I
    I --> J["结合 SRE（固醇调节元件）"]
    J --> K["HMG-CoA 还原酶 ↑ 自身合成"]
    J --> L["LDL 受体（LDLR）↑ 从血浆摄回胆固醇"]
    J --> M["PCSK9（负调控 LDLR）↑ 促 LDLR 降解"]

4.2 SREBP 家族分工

成员主要调控靶基因
SREBP-1a胆固醇 + 脂肪酸兼而有之
SREBP-1c脂肪酸 / 甘油三酯合成脂肪酸合成酶、ACC、SCD1
SREBP-2胆固醇HMG-CoA 还原酶（HMGCR）、LDLR、PCSK9

4.3 三种 SREBP 加工方式（注意区分）

加工方式触发条件切割酶产物
经典固醇调节ER 胆固醇↓S1P + S2P（在高尔基体）核形式 nSREBP
应激应急加工ER 应激、ER 胆固醇耗竭S1P + S2P（直接在 ER 膜上）核形式 nSREBP
ER 应激降解ER 应激、胆固醇正常蛋白酶体（ERAD 相关）被降解，通路关闭

关键易混点：ERS 条件下 SREBP 的命运取决于胆固醇水平。胆固醇耗竭 → 应急加工、上调合成；胆固醇正常而 ER 应激 → SREBP 被降解。这就是”脂应激”与”蛋白应激”在 SREBP 层面的分岔。

靶点/药物作用意义
他汀类（抑制 HMGCR）阻断胆固醇合成第一线降脂药
依折麦布抑制肠道胆固醇吸收减少外源摄入
PCSK9 抑制剂（单抗）阻止 LDLR 降解LDL 大幅下降

六、要点速记

ER 出问题分两类：蛋白问题和脂问题。

  1. UPR：蛋白折坏了 → BiP 占满 → PERK/ATF6/IRE1 → 停翻译、扩产能、不行凋亡
  2. EOR：订单太多但折得好 → NF-κB + ER 扩张 → 不经过 BiP 轴
  3. 固醇调节级联：ER 胆固醇降 → SCAP 释放 SREBP → 运高尔基体被 S1P/S2P 切开 → 上调 HMGCR、LDLR

一个关键分岔：ERS 下 SREBP 命运取决于胆固醇水平——不够就活化，够就被降解。

一对共用的刀：S1P/S2P 既切 ATF6（UPR）也切 SREBP（固醇调节）。
