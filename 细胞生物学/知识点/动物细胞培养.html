动物细胞培养

动物细胞培养（Animal Cell Culture）是将离体动物组织或细胞置于人工条件下，提供适宜环境以保持存活、生长或增殖的过程。它是细胞生物学、药物开发、疫苗生产和再生医学的核心工具。

〇、四个阶段总览：原代 → 传代 → 细胞系 → 细胞株

这是动物细胞培养最核心的一条主线。四个术语代表细胞来源、处理历史、遗传稳定性的不同层级。

纵向看：寿命从”有限 → 有限 → 无限 → 无限”，均一性从低到高（④ 是单克隆来源），但遗传稳定性递减——这正是”越传代越偏离原始组织表型”的根源（P1 最接近原组织，P5+ 需警惕漂变）。

横向对比：① 与 ② 的共同点是寿命有限，区别在于② 已脱离”直接分离”状态；② 与 ③ 的分水岭是获得不朽性；③ 与 ④ 的分水岭是单克隆化带来的遗传均一性。

一、阶段①：原代细胞（Primary Cells）

来源与定义

直接从活体组织或器官分离获得的细胞，是”第一次传代之前”的全部细胞。分离方式包括组织块法（剪碎后自然贴壁或酶解）与酶解/机械消化法。

特点

维度特点
遗传背景正常 2n，接近原有组织的遗传背景
表型保留组织特异性功能：肝细胞糖原合成、肾细胞尿素合成、神经元电信号转导、巨噬细胞吞噬
寿命有限，受 Hayflick 限制（约 50 次群体倍增 / 1–30 代），随后衰老、失去克隆能力、最终死亡
克隆能力高，但需要基质/配基（如透明质酸）辅助贴壁
均一性差，组织中多种细胞混杂（成纤维细胞、上皮细胞、内皮细胞、免疫细胞）
代次标记P0 = 原代直接分离；P1 = 首次传代后

培养方法

（a）基质与配基

组分作用常用浓度/说明
聚二甲基硅氧烷（PDMS）抗粘附、易后处理适用于特定培养与细胞分离

胶原 / 纤维连接蛋白 / 层粘连蛋白提供贴壁信号原代上皮/内皮常用
Matrigel3D 培养支架类器官（Organoid）、干细胞

（b）培养基成分

类别常见组分作用与浓度
基础培养基DMEM、RPMI 1640、Ham’s F-12基础盐 + 缓冲 + 碳源
血清10–15% 胎牛血清（FBS）（原代常用 10%）提供生长因子、贴附因子；稳定预期效果
无机盐类NaCl、KCl、Mg²⁺、Ca²⁺、磷酸盐维持渗透压与 pH
水溶性维生素维生素 A、B、C、D、E（约 1 mg/L）促进存活与分裂；血清中已含

抗生素青霉素 100 U/L、庆大霉素 10 mg/L、链霉素防止细菌污染

参数条件

细胞来源特征功能重要性

二、阶段②：传代（Passaging / Subculture）

定义

当培养皿/瓶达到 80–90% 汇合度（Confluence） 时，用胰酶/EDTA消化使细胞脱离基质，收集、离心，重悬并接种至新容器的过程。记录记为 P+1。

目的

延长存活时间、扩大培养规模、建立连续培养体系。

标准操作

步骤操作参数
1. 弃液吸去培养液，PBS 轻洗 1–2 次去除残余血清（中和胰酶）
2. 消化加 0.25% 胰蛋白酶 + EDTA37°C，1–2 min；镜下观察细胞变圆、间隙增大即停
3. 终止加含 10–20% FBS 的培养基血清胰酶抑制剂中止消化
4. 吹打吹打成单细胞悬液动作轻，避免机械创伤
5. 离心800–1,000 rpm，10 min（或 300×g，5 min）弃上清
6. 重悬/接种重悬至新容器传代比（Split Ratio）常用 1:2 ~ 1:10

关键控制点

问题后果处理
过早传代细胞未充分扩增，浪费培养基、细胞量不足等到 80–90% 汇合度
过晚传代接触抑制引发衰老或凋亡及时传代；原代细胞尤为敏感
传代比过大稀释过度、适应期延长悬浮/快速增殖细胞可加大传代比
消化过度细胞损伤、活力下降镜下monitor，1–2 min 足够
胰酶浓度过高表面蛋白被降解，影响贴壁用 0.05–0.25%，血清及时中和

关键节点：原代 → 细胞系的转折

原代细胞首次传代（P1）后，若仍保持有限寿命 → 仍属原代系列；若连续传代后获得持续增殖能力（>20–30 代）→ 进入细胞系阶段。

⚠️ P1 是最接近原始状态的实验材料。传代过多（P5+）常已发生明显表型漂变。

三、阶段③：细胞系（Cell Line）

定义

经连续传代（通常 >20–30 代，或达到稳定增殖期）后形成的、可持续培养的细胞群体。

两种类型

类型定义寿命代表
有限细胞系
Finite Cell Line		已脱离原代直接状态，但仍有一定传代限制有限某些人源成纤维细胞系（BJ、MRC-5）
无限细胞系
Immortalized / Continuous Cell Line		获得不朽性（Immortality）无限HeLa、HEK293、CHO、COS-7、NS0

不朽性的三条获得途径

途径机制代表细胞
自然癌变体内肿瘤组织直接建立HeLa（宫颈癌，Henrietta Lacks）
病毒转化病毒基因整合/表达改变细胞周期HEK293（腺病毒 E1A/E1B）、COS-7（SV40 大 T 抗原）
化学/物理诱导特定处理诱导永生化部分成纤维细胞系

📌 HEK293 是腺病毒 E1 基因转化的（不是 SV40）；HEK293T 进一步表达 SV40 大 T 抗原，转染效率更高。COS-7 表达 SV40 大 T 抗原。三者常被混淆。

特点

维度特点
增殖无限分裂，倍增时间稳定（HEK293 ~24 h）
形态相对均一，生长曲线简洁（对数期快）
遗传遗传异质性增加，随代数累积突变；染色体可能异常（数目与结构畸变）
表型可能发生表型漂变（Phenotypic Drift）；异质性增加
血清依赖部分细胞（HeLa、HEK293）无血清也可存活；多数仍需 10% FBS
生长特性接触抑制减弱（失去密度依赖性抑制）

常用培养条件

  • 基础培养基：DMEM、RPMI 1640、Ham’s F-12、McCoy’s 5A
  • 血清：10% FBS / 10% 冷冻血清 / 无血清（表达用 CD-CHO、FreeStyle 293）
  • 血清替代与添加：胰岛素、维生素、氨基酸、脂肪酸、透明质酸
  • 温度 37°C；CO₂ 5–10%；湿度 95–98%
  • 悬浮培养：加入抗剪切保护剂 PVA/明胶，控制溶氧 DO 10–30%、pH 7.0–7.4、渗透压 280–320 mOsm/kg

四、阶段④：细胞株（Cell Strain / Subclone）

定义

从细胞系中经单克隆分离（Single Clone / Limiting Dilution / Colony Picking / FACS）获得的、遗传结构均一的亚群体。强调克隆均一性与遗传稳定性。

与细胞系的关系

概念本质是否均一
细胞系整体连续培养群体❌ 可能含多克隆混合
细胞株细胞系中的亚克隆（Subclone / Subline）✅ 均一

单克隆分离方法

方法原理效率/准确性
有限稀释法0.5–1 细胞/mL，每孔 0.1 mL最常用；需重复 2–3 轮，通常加饲养细胞（腹腔巨噬细胞、NIH 3T3）
软琼脂集落法0.8% 琼脂铺底 + 0.4% 半固体上层单细胞形成独立圆形集落，克隆环挑取
FACS 单细胞分选抗 IgG 荧光标记 + Index Sorting可同时筛选产量与特异性；需流式仪
显微操作法倒置镜下玻璃微吸管挑单细胞100% 单克隆，极耗时

常见细胞株举例

细胞株所属细胞系亚株特征
HEK293THEK293含 SV40 大 T 抗原，转染效率更高
CHO-K1CHO适合贴壁培养
CHO-S / CHO-DG44CHO适合悬浮培养，便于无血清重组蛋白生产
HepG2 vs HepaRG人肝癌系分化状态不同：HepG2 较低分化，HepaRG 更接近正常肝细胞

重要意义

  • 标准化实验：同一细胞株 → 实验可重复性
  • 基因工程：构建稳定转染株必须经单克隆筛选
  • 生产一致性：生物制药强制要求使用固定细胞株
  • 细胞库体系：
    • 原始细胞系
      • MCB（Master Cell Bank，主细胞库）——早期代次，量小、备用
        • WCB（Working Cell Bank，工作细胞库）——日常使用
          • 生产/实验用细胞 选 HEK293T + MCB/WCB 是 GMP 生物制品的通行做法。

目标推荐

污染类型显微镜特征来源处理
细菌培养基迅速变黄/浑浊，小圆点或杆状运动操作不洁、血清/培养基污染弃培养、器械高压灭菌、环境消毒

支原体光镜下不可见；细胞生长缓慢、脱落、形态异常血清、操作者口腔、交叉污染PCR/荧光染色（Mycoplasma PCR Kit） 检测；阳性用高温法（41°C）或抗生素法（Minocycline / Plasmocin / Tylosin）清除，或直接弃用

九、冷冻保存与复苏标准流程

冷冻保存

  1. 取对数生长期细胞，汇合度 80–90%
  2. 胰酶消化 → 离心（300×g, 5 min）→ 弃上清
  3. 冻存液：90% FBS + 10% DMSO（或商业化无血清冻存液）
  4. 调整浓度 1–5×10⁶ cells/mL，分装冻存管（1 mL/管）
  5. 程序降温：−80°C 冰盒（~1°C/min）过夜 → **液氮罐（−196°C）**长期保存
  6. 记录：细胞名、代次(P数)、日期、浓度、冻存液配方、罐位

⚠️ DMSO 在慢降温时毒性大（防止细胞内冰晶 + 减少 DMSO 渗透伤害），必须慢降温。液氮气相保存比液相更安全（防爆管）。

复苏

  1. 液氮取出 → 37°C 水浴快速摇动融化（<1 min）
  2. 转移至 15 mL 离心管，缓慢加入**预温培养基（含 10% FBS）**稀释 DMSO
  3. 离心（300×g, 5 min）→ 弃上清（去除 DMSO）→ 重悬新鲜培养基
  4. 接种培养瓶，首日不换液以利贴壁；次日换液观察状态
  5. 活力检测：Trypan Blue / AO-PI，>70% 可接受，理想 >90%
  6. 传代 1–2 次后再用于正式实验

状态显微特征处理

凋亡细胞皱缩（shrinkage）、染色质浓缩、膜起泡（blebbing）、凋亡小体弃用；检查诱导因素
坏死细胞肿胀、膜破裂、内容物外溢、碎片增多弃用；多为物理损伤或营养耗尽

方向性原则：原代细胞对换液频率和密度更敏感 → 需密切监测；无限细胞系容错度高 → 但仍需定期 STR 与支原体检。

总结

  • 原代细胞：保留组织特异性功能，但寿命有限、耗时长、成本高、血清依赖 → 用于毒理学、安全性评估、疾病模型。
  • 细胞系：可无限增殖，培养条件稳定，便于大规模生产，但可能表型漂变、遗传异质性增加 → 用于生物制品、病毒生产、基因表达。
  • 细胞株：由细胞系单克隆化而来，遗传均一、标准可重复，是工业生产一致性与实验可重复性的核心保障。
  • 传代：贯穿全过程的放大手段，但次数越多越偏离原始表型（P1 最接近原组织，P5+ 需警惕漂变）。

记住：细胞培养 是一个系统化过程，优质的细胞是成功的基础，而正确的培养方法是成功的保障。选择的目标决定了你该用原代细胞（要真实）还是细胞株（要可控、可重复、能规模化）。
