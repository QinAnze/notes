膜电位变化与跨膜转运

核心命题：膜电位的变化有三个层次，每一层都由特定的跨膜转运装置驱动：

  • 快速层（毫秒级）：电压门控离子通道开放 → 产生动作电位各阶段
  • 稳态层（秒~分钟级）：离子泵与交换体维持/恢复离子梯度
  • 极化层（持续性）：Na⁺/K⁺-ATP 酶长期维持静息梯度

一句话：通道负责”快速改变电位”，泵负责”长期维持梯度”。动作电位后膜电位靠通道自身复原，靠的不是泵——这是最常见的误解。

一、前提：静息膜电位的建立

1.1 离子分布与电化学梯度

离子细胞外细胞内平衡电位（Nernst,哺乳动物）驱动力方向（静息时）
Na⁺145 mM10–12 mME ≈ +60 mV⬇️ 强烈内流趋势
K⁺4–5 mM140 mME ≈ −90 mV⬆️ 强烈外流趋势
Cl⁻110 mM5–30 mME ≈ −65 mV决定静息电导
Ca²⁺1–2 mM~100 nM（10⁻⁷ M）E ≈ +120 mV极强内流趋势
Na⁺/K⁺ 泵3 Na⁺ 出2 K⁺ 入—⭐ 唯一的净电荷外流源

⭐ 静息电位的核心矛盾：Na⁺ 想进、K⁺ 想出，但细胞膜对两者都有泄漏通道。若只有泄漏，膜电位会稳定在两大泄漏电导的加权平均附近（“极化电位（chord conductance）”），并非任何单一离子的E 值。

1.2 静息电位的建立：哪一层的贡献？

flowchart TD
    A["静息电位（−70 mV）"] --> B["两个来源"]
    B --> C["主力：K⁺ 漏通道（静息时膜的主要电导）· 设定电位接近 E_K（约 −90 mV）"]
    B --> D["次要：Na⁺/K⁺ 泵（净外排 +1 电荷/循环）· 贡献约 −5 ~ −10 mV"]
    C --> E["两者共同决定最终的静息电位"]
    D --> E
    E --> F["再叠加 Na⁺ 漏通道 + Cl⁻ 通道的少量贡献"]

关键数值

  • Na⁺/K⁺ 泵仅贡献静息电位的约 5–10%（5–10 mV）
  • 维持梯度的 90%+ 工作量由 Na⁺/K⁺ 泵完成
  • 但设定电位的 90%+ 由 K⁺ 漏通道完成

🎯 区分两个概念：

  • 谁贡献静息电位的数值 → K⁺ 漏通道（主导）
  • 谁维持静息电位所依赖的梯度 → Na⁺/K⁺ 泵（唯一）

二、动作电位的五个阶段

2.1 总览：阶段与驱动装置

2.2 五阶段详解与对应的转运装置

阶段时间尺度电位变化主导转运装置离子方向
① 静息态
Resting		持续稳定于 −70 mVK⁺ 漏通道（KCNK/Kir）为主
+ Na⁺/K⁺ 泵维持梯度		K⁺ 少量外流
② 去极化
Depolarization		~1 ms−70 → +30 mV⭐ 电压门控 Na⁺ 通道（Nav）爆发开放Na⁺ 大量内流
③ 复极化
Repolarization		~1–2 ms+30 → −70 mV⭐ 电压门控 K⁺ 通道（Kv）开放
+ Na⁺ 通道失活		K⁺ 外流
④ 超极化
Hyperpolarization		~10 ms−70 → −80~−90 mVK⁺ 通道延迟关闭（仍在开放）K⁺ 持续外流（过量）
⑤ 后超极化
Undershoot / AHP		~10–100 ms回到 −70 mVK⁺ 通道关闭；Ca²⁺ 通道/K⁺ 通道失活；
Ca²⁺ 激活的 K⁺ 通道（BK）		K⁺ 外流减少，Ca²⁺ 排出

⚠️ 易错点：Na⁺ 通道”失活”和”K⁺ 通道开放”共同复极化——不是单靠 K⁺ 外流。电压门控 Na⁺ 通道有独立的失活闸门（inactivation gate），即使膜仍在去极化状态它也会失活，这是通道特有的现象（其他离子通道无此机制）。

2.3 各阶段的分子细节

② 去极化：正反馈”点火”

flowchart TD
    A["阈值约 −55 mV"] --> B["少量 Na⁺ 内流（漏通道）"]
    B --> C["膜电位去极化到阈值"]
    C --> D["电压门控 Na⁺ 通道被激活"]
    D --> E["Na⁺ 大量内流"]
    E --> F["膜电位进一步去极化"]
    F --> G["更多 Na⁺ 通道被激活"]
    G -->|"正反馈（Hodgkin 循环）"| E
    G --> H["直到 Na⁺ 驱动力被通道密度限制（膜电位接近 E_Na ≈ +60 mV）"]
  • 正反馈是动作电位”全或无”的分子基础
  • 峰值电位不会达到 E_Na（+60 mV），因为 Na⁺ 通道开始失活

④ 超极化的”过量 K⁺ 外流”

flowchart TD
    A["K⁺ 通道是电压依赖且慢激活的"] --> B["去极化后需要几十毫秒才充分开放"]
    B --> C["复极化时 K⁺ 通道才刚开到最大"]
    C --> D["此时 K⁺ 外流过量"]
    D --> E["膜电位短暂低于静息电位（−80~−90 mV）"]
    E --> F["直到 K⁺ 通道关闭才恢复"]

💡 这解释了为什么动作电位有”回落”（undershoot）——不是泵在工作，纯粹是 K⁺ 通道关闭滞后。

三、膜电位与跨膜转运的联系（核心）

3.1 三类转运装置与时间尺度的分工

类别装置开关机制时间尺度在膜电位中的角色
离子通道
Ion channel		电压门控、配体门控、机械门控、漏通道门控机制，毫秒级μs–ms⭐ 直接产生快速电位变化（动作电位各阶段）
载体转运体
Carrier / Transporter		Na⁺/Ca²⁺ 交换器、NHE、CAT、葡萄糖转运体构象循环（交替进入）ms–s缓慢、持续地移动电荷或物质；参与稳态维持
离子泵
Pump（ATPase）		Na⁺/K⁺-ATP 酶、Ca²⁺-ATP 酶、H⁺/K⁺-ATP 酶、CFTRATP 水解驱动s–min⭐ 长期维持/恢复离子梯度；不参与快速相位

⭐ 核心区分：

  • 通道 = 被动 + 快速（顺电化学梯度，毫秒级）
  • 泵 = 主动 + 慢速（逆梯度，耗 ATP，秒~分钟级）
  • 交换器 = 被动 + 中速（利用另一离子的梯度驱动）

3.2 膜电位对转运的三重影响

flowchart TD
    A["膜电位（Vm）"] --> B["① 驱动"]
    A --> C["② 改变驱动力"]
    A --> D["③ 反馈调节"]
    B --> B1["被动转运，顺电化学梯度 · 例：Na⁺ 经漏通道内流（V 越负，Na⁺ 内流驱动力越大）"]
    C --> C1["主动转运的能量成本可被 V 显著改变 · 例：Na⁺/K⁺ 泵速率依赖 Vm"]
    D --> D1["膜电位依赖的转运体，表达量或活性受 V 调控 · 例：胞外高 K⁺ 时的「外向泵」电流（cardiac）"]
影响机制生理意义
① 被动转运的驱动力驱动力 = Vm − E_ion。Vm 越负，阳离子内流驱动力越大去极化时 Na⁺/Ca²⁺ 内流猛增；超极化时 K⁺ 外流增加
② 主动转运的能量成本逆梯度转运需能量，Vm 贡献了膜两侧电位差的一部分Vm 改变 → Na⁺/glucose 同向转运的净驱动力改变
③ 反馈调节某些泵/通道受 Vm 调控Na⁺/K⁺ 泵的外向泵电流依赖 Vm；Ca²⁺ 通道受 Vm 门控

3.3 动作电位后，膜电位是怎么恢复的？（关键澄清）

这是最常见的误解点。不是 Na⁺/K⁺ 泵把电位”拉回来”。

真相：恢复靠通道，靠泵只会”越来越糟”

flowchart TD
    A["一次动作电位的净离子流"] --> A1["Na⁺ 内流：约 10 pmol/cm²"]
    A --> A2["K⁺ 外流：约 10 pmol/cm²（更多）"]
    A1 --> B["⚠️ 结果：膜内 Na⁺ 微增，K⁺ 微减"]
    A2 --> B
    B --> C["如果不处理 → 梯度被侵蚀"]
    C --> D["但膜电位已经恢复（因为 K⁺ 通道关闭了）"]
    D --> E["⚠️ 关键：电位恢复 ≠ 梯度恢复"]

三条恢复途径的分工

途径作用性质速度
电压门控 K⁺ 通道关闭⭐ 直接把膜电位拉回静息值被动、毫秒级快
Na⁺/Ca²⁺ 交换器（NCX）排 Na⁺、摄Ca²⁺（3:1 电生性）→ 产生向外电流被动、较慢中
Ca²⁺-ATP 酶（PMCA）排出胞内 Ca²⁺主动慢
Na⁺/K⁺-ATP 酶⭐ 恢复 Na⁺/K⁺ 梯度（真正的长期负责者）主动慢

数值对比（同一时间尺度上）

装置一个动作电位期间能搬运的电荷
电压门控 K⁺ 通道⭐ ~10 pmol/cm²（瞬间完成，主要恢复电位）
Na⁺/K⁺ 泵仅约 0.001 pmol/cm²（慢两个数量级）

🎯 结论：膜电位的快速恢复（后超极化结束）完全由通道完成；Na⁺/K⁺ 泵的作用尺度慢得多（秒~小时），它负责的是”把被侵蚀的梯度补回来”，而不是”把电位拉回来”。

3.4 典型的电生性与电中性转运体

转运体化学计量比电荷净移动类型功能
Na⁺/K⁺-ATP 酶3 Na⁺ 出/ 2 K⁺ 入净 +1 出⭐ 电生性（electrogenic）维持基础梯度；产生外向泵电流
Na⁺/Ca²⁺ 交换器（NCX）3 Na⁺ 入 / 1 Ca²⁺ 出净 +2 入⭐ 电生性排出 Ca²⁺；参与后超极化；心肌重要
Ca²⁺-ATP 酶（PMCA）1 Ca²⁺ 出（1 ATP）净 +1 出电生性精确排钙；可产生外向电流
Na⁺/H⁺ 交换器（NHE1）1 Na⁺ 入 / 1 H⁺ 出净 0电中性（electroneutral）pH 稳态；无直接电贡献
Na⁺-K⁺-2Cl⁻ 同向转运（NKCC1）1 Na⁺ + 1 K⁺ + 2 Cl⁻ 入净 0电中性细胞容积调节
H⁺/K⁺-ATP 酶（胃壁细胞）1 H⁺ 出 / 1 K⁺ 入净 0电中性胃酸分泌（虽然耗 ATP，但电荷平衡）
Cl⁻/HCO₃⁻ 交换（AE1）1:1 交换净 0电中性CO₂ 运输；红细胞
Ca²⁺ 信号（胞内）1 Ca²⁺ 入胞质+1 入电生性参与后超极化、肌肉收缩

⚠️ “电生性 vs 电中性”很重要：因为膜电位是带符号的量，只有在转运体搬运净电荷时才会直接影响 Vm。电中性转运体（多数）不直接产生电流，它们只搬运特定底物。

3.5 特殊情形：Ca²⁺ 的双重身份

flowchart TD
    A["胞外"] --> B["Ca²⁺ 通道（电压门控 / 配体门控 / 机械 Piezo）"]
    B -->|"Ca²⁺ 内流（电生性 → 促去极化）"| C["胞质 Ca²⁺ ↑ · ~100 nM → 1–10 μM"]
    C --> D["三种「驱逐」途径"]
    C --> E["⭐ Ca²⁺ 静息浓度极低（10⁻⁷ M），所以排 Ca²⁺ 的装置密度极高"]
    D --> F["NCX（交换）3:1"]
    D --> G["PMCA（泵）1 Ca²⁺/ATP"]
    D --> H["Ca²⁺ 通道反转（PMCA 外）"]
    D --> I["线粒体 / ER"]
  • Ca²⁺ 的静息浓度比 Na⁺ 低 10⁴倍，因此排钙装置（NCX、PMCA、Ca²⁺ 泵）在细胞膜上密度极高
  • PMCA 亲和力高（低 Ca²⁺ 也能工作）、容量小；NCX 亲和力低、容量大（大量 Ca²⁺ 时才启用）
  • → 这就是为什么 NCX 参与后超极化：胞内 Ca²⁺ 升高时 NCX 被激活，净转入 2 个正电荷 → 加深超极化

3.6 膜电位与转运的临床关联

场景机制应用
洋地黄（地高辛）抑制 Na⁺/K⁺ 泵 → 胞内 Na⁺↑ → NCX 反转 → Ca²⁺↑ → 强心心衰；同时高钾血症副作用
SGLT2 抑制剂抑制 Na⁺-glucose 共转运 → 尿糖↑；同时 Na⁺/H⁺ 交换↑、K⁺ 重吸收↓降糖 + 降尿酸
电压门控 Na⁺ 通道阻断剂局麻药（利多卡因）、河豚毒素麻醉；动作电位传导阻断
AQP 与膜电位水通道是被动，孔隙大，不显著贡献 Vm但转运改变细胞容积 → 影响膜张力
凋亡中的膜电位K⁺ 通道激活 + 泵抑制 → Vm 超极化；同时 PS 外翻凋亡标志

四、要点速记

要点内容
静息电位主力K⁺ 漏通道（贡献 90%+ 的数值）；Na⁺/K⁺ 泵只贡献 5–10 mV
梯度的唯一维持者⭐ Na⁺/K⁺-ATP 酶（3 Na⁺ 出/ 2 K⁺ 入，电生性）
静息电位设定K⁺ 漏通道 + Na⁺/K⁺ 泵 + 少量 Na⁺/Cl⁻ 通道的加权平均（chord conductance）
动作电位五阶段静息 → 去极化（Nav，Na⁺ 入）→ 复极化（Kv，K⁺ 出 + Nav 失活）→ 超极化（K⁺ 通道延迟关闭）→ 后超极化（Ca²⁺ 激活 BK）
关键机制⭐ Na⁺ 通道的”失活”是通道特有的，复极化靠”Kv 开放 + Nav 失活”共同完成
正反馈Na⁺ 内流 → 去极化 → 更多 Nav 开放 → 更多内流（Hodgkin 循环）→ “全或无”
通道 vs 泵 vs 交换体通道 = 被动+快（μs–ms）；泵 = 主动+慢（s–min）；交换体 = 被动+中速
⭐恢复电位的真相靠 K⁺ 通道关闭，不是靠 Na⁺/K⁺ 泵；泵慢2 个数量级，负责长期补梯度
电生性Na⁺/K⁺ 泵（+1 出）、NCX（+2 入）、PMCA（+1 出）、Ca²⁺ 内流（+1 入）
电中性NHE1（1:1）、NKCC1（1-1-2）、H⁺/K⁺ 泵（1:1）、AE1（1:1）——不直接产生电流
Ca²⁺ 双重身份既是第二信使（电生性入流），又因静息浓度极低（10⁻⁷ M）需高密度排钙装置（NCX+PMCA）
NCX 的角色Ca²⁺ 升高时激活，净入 +2 → 参与后超极化；洋地黄利用此机制
药物靶点洋地黄（抑制泵）、局麻药/河豚毒素（阻断 Nav）、SGLT2 抑制剂（Na⁺-糖共转运）

五、常见误区澄清

误区正确认识
❌ “动作电位后Na⁺/K⁺ 泵大量工作把电位恢复”⭐ 错。电位恢复靠K⁺ 通道关闭（毫秒级）；泵慢两个数量级，只负责长期补梯度
❌ “静息电位由 Na⁺/K⁺ 泵建立”⚠️ 不准确。数值由 K⁺ 漏通道决定；泵只贡献 5–10 mV
❌ “复极化只是 K⁺ 外流”⚠️ 还包括 Na⁺ 通道失活（通道特有的闸门机制）。两者共同完成
❌ “Na⁺ 通道只会开不会关”⚠️ 有独立的失活闸门（inactivation gate），去极化时自动关闭，与复极化无关
❌ “超极化是泵在工作”❌ 纯由K⁺ 通道延迟关闭造成。此时泵仍在运行，但贡献极小
❌ “所有转运体都产生电流”❌ 只有电生性转运体搬运净电荷。多数（NHE、NKCC、AE1）是电中性
❌ “电生性 = 主动”❌ 是两个独立概念。NCX 是电生性但被动；H⁺/K⁺ 泵是主动但电中性
❌ “膜电位只由 K⁺ 决定”❌ 是所有电导的加权平衡；Na⁺、Cl⁻ 通道也有贡献
❌ “Ca²⁺ 通道不产生电流”❌ Ca²⁺ 带 +2 电荷，内流是强电生性事件，是去极化的重要贡献者
❌ “AQP 参与膜电位”❌ 水通道孔隙大、选择性水，几乎不贡献 Vm；影响主要是容积/膜张力

总结 膜电位变化的本质是”通道开放的时序程序”，而跨膜转运提供的是”梯度的长期保障与缓慢恢复”。

  • 快速层：电压门控通道按阈值 → Na⁺ 通道爆发 → 失活 + K⁺ 通道开放 → K⁺ 延迟关闭的时序，产生去极化、复极化、超极化、后超极化四个相位；Na⁺ 内流的正反馈保证”全或无”
  • 稳态层：Na⁺/K⁺ 泵以 3:2 的电生性方式长期维持梯度；它慢两个数量级，不参与快速相位，却贡献了静息电位的 5–10 mV
  • 反馈层：NCX、PMCA 在 Ca²⁺ 升高时参与后超极化，并在洋地黄机制中被利用

记住一句话：通道负责”快速改变电位”，泵负责”长期维持梯度”——把这两者混为一谈是理解膜电位的最大障碍。
