线粒体和叶绿体（Mitochondria and Chloroplasts）

讲义：第七章-线粒体和叶绿体.pdf

线粒体是细胞的「能量工厂」：它用内膜上的电子传递链把氧化还原能转成质子梯度，再由 ATP 合酶把梯度转成 ATP。本章的主线是形态动态 → 区室化 → 分子马达 → 氧化磷酸化。叶绿体部分课堂未展开，仅在质子驱动力一节保留其在图中的位置。

一、形态与动态调控

1.1 形态与数目

  1. 形态为颗粒状 / 短线状。
  2. 分布与细胞的能量需求密切相关。
  3. 数目动态变化，接受调控。
  4. 数目与细胞类型相关，随细胞分化而分化。

为什么强调「动态」

线粒体不是固定不变的孤立细胞器，而是不断融合、分裂的网络。形态与数目的改变，直接对应细胞对能量需求和应激状态的响应。

1.2 融合与分裂的分子基础

过程分子要点
融合Fzo果蝇精细胞的线粒体融合基因，编码一个 GTPase，位于线粒体外膜
线粒体融合素（mitofusin）哺乳动物，由 Mfn 编码
dynamin 蛋白也是一种 GTPase
分裂Dnm1、Drp1线粒体分裂必需基因

下图把遗传学证据与分子模型并排放在一起：左侧是果蝇精细胞发育过程中的电镜照片，右侧才是 Fzo 蛋白本身的跨膜示意。读图先看左侧——野生型（WT）中线粒体互相融合、形成一个大体积的球形线粒体，而 fzo 突变体中线粒体只是彼此聚集、并不融合。这个对比说明 Fzo 管的是「融合」这一步，而不是「让线粒体靠近」。

再看右侧的分子模型：橙色球是 GTPase 结构域，位于胞质侧；NH3+​ 与 COO− 两端也都伸向胞质；蛋白靠两段卷曲螺旋跨过线粒体外膜，把 GTP 水解引起的构象变化传到膜上。因此 Fzo 是「跨外膜、两头在胞质」的大分子 GTPase。这也解释了为什么融合要由外膜蛋白执行——先让两层外膜贴合、融合，内膜才可能随后融合；机器装在膜外侧，才够得着对面那条线粒体的外膜。

图：左侧为野生型（WT）与 fzo 突变体果蝇精细胞线粒体的电镜对比——WT 融合成大体积球形线粒体，fzo 突变体中线粒体聚集但不融合；右侧为 Fzo 的模式结构，胞质侧 GTPase 结构域与 NH3+​、COO− 两端均在胞质，卷曲螺旋跨膜段穿过线粒体外膜。

1.3 分裂装置

  1. 线粒体的融合与分裂装置。
  2. 线粒体分裂环：环绕线粒体的缢缩结构。
  3. 分裂三阶段：早期、中期、后期。

分裂不是一步完成的「一剪两断」，而是几套环按顺序装配、逐级收紧。下图从左到右三格正好对应早期、中期、后期：Phase 1 时胞质中的 dynamin 先聚成斑块（dynamin patch），线粒体内部出现一圈蓝色的 FtsZ 环，此时外膜（OM）与内膜（IM）还是平直的；Phase 2 出现 MD 环，线粒体中部凹出缢痕，内外膜一起向内缩；Phase 3 dynamin 在缢缩处装配成 dynamin ring 并收缩，最终把线粒体断成两段。

一个容易被忽略的读图细节：红色小点（dynamin）始终画在环的外侧，即从胞质面套上去；蓝环则画在膜内。这与 1.2 中 Fzo 从胞质侧跨外膜是同一套逻辑——融合与分裂的机器都在外膜外侧操作，内膜的形态变化是跟着发生的。

图：线粒体分裂的三阶段。Phase 1 为 dynamin 斑块与 FtsZ 环出现；Phase 2 形成 MD 环、出现缢痕；Phase 3 dynamin 环装配并收缩，完成断离。图中 IM 为内膜、OM 为外膜。

Phase 1dynamin patch、FtsZ 环外膜与内膜仍平直，尚未缢缩
Phase 2MD 环中部出现缢痕，内外膜一起内凹
Phase 3dynamin ring环收缩，线粒体断离

1.4 生物学意义

  1. 通过不断融合分裂，平衡线粒体基质中氧化自由基对 DNA 的损伤——融合可稀释受损内容物，分裂可隔离损伤。
  2. 调控线粒体的大小、数目、分布。
  3. 植物线粒体数目远多于其线粒体 DNA 的拷贝数，因此依赖融合与分裂实现遗传信息的共享。
  4. 调节细胞代谢状态：营养缺失时线粒体延伸自身长度，产能效率提高；营养过剩时分裂活跃，ATP 产量下降，避免能量浪费。

形态即功能

同一套融合/分裂机器，在营养缺乏与营养过剩时给出相反的形态输出：拉长 = 提高产能效率，分裂活跃 = 降低 ATP 产量。形态不是被动的结果，而是代谢调控的执行环节。

二、超微结构

下图是一张「标签式」的模式图，重点不在形状，而在每个标签对应哪一层结构。读图时可以按「由外向内」走一遍：最外面是外膜，膜上画着一排绿色小颗粒，标注 porins（无柄颗粒，stalkless particle）；再往里是内膜，内膜向基质反复折叠形成嵴；内外膜之间是膜间隙；被内膜围起来的空间是线粒体基质。基质里标出的东西很密：核糖体、mRNA 与多聚核糖体、环状 DNA 分子，以及磷酸钙颗粒（granule）。

另一组标签挂在内膜上：ATP 合酶（有柄颗粒，stalked particle） 和 ETC（电子传递链）。这两个名字是成对记的——「有柄」指 ATP 合酶带一个伸向基质的柄状头部，「无柄」指外膜孔蛋白只是一个嵌在膜上的小颗粒。注意两者位置不同：有柄颗粒在内膜，无柄颗粒在外膜，这正是内膜负责能量转换、外膜负责通透性的形态证据。

内膜折叠成嵴并不是为了「好看」：氧化磷酸化的全部机器（ETC 与 ATP 合酶）都嵌在内膜上，把膜面积做大，就等于在同一体积里装下更多产能装置。

图：线粒体超微结构模式图。外膜上排布孔蛋白（porins，无柄颗粒）；内膜向基质折叠成嵴，嵴上分布 ATP 合酶（有柄颗粒）与电子传递链（ETC）；膜间隙在内外膜之间；基质含环状 DNA、核糖体、mRNA 与多聚核糖体，以及磷酸钙颗粒（granule）。

图中名称本质位置
有柄颗粒（stalked particle）ATP 合酶内膜（嵴），柄伸向基质
无柄颗粒（stalkless particle）孔蛋白（porin）外膜
区室标志分子特征与功能
外膜孔蛋白、单胺氧化酶通透性高
内膜ATP synthase、细胞色素氧化酶不透性，向内折叠成线粒体嵴，进行氧化磷酸化
膜间隙腺苷酸激酶位于内外膜之间
线粒体基质苹果酸脱氢酶含 DNA、RNA、核糖体及转录翻译必需分子

区室化是能量转换的前提

外膜通透性高、内膜不透性，两者差异使膜间隙与基质可以维持不同的质子浓度——这正是后面质子驱动力与 ATP 合成的物理基础。

三、ATP 合酶（ATP Synthase）

第一张图把「生化分离」和「结构模型」并排放。A 是用超声波处理线粒体内膜、得到小膜泡后负染的电镜图：小泡表面一颗颗带柄的突起，就是 ATP 合酶（箭头指示，两个标尺分别是 200 nm 与 30 nm）。B 是把这些突起拆成零件的分子模型：F1​ 头部由 α、β、γ、δ、ε 组成，F0​ 基部由 a、b、c 组成，柄插在膜里。

读 A 时要抓住「柄」：每个颗粒都是「球 + 柄」的组合，而且球在膜泡外侧。超声处理会把这些小泡翻成内外翻转的形态，所以头部朝外——反推回完整的线粒体，头部就是朝向基质。这一点很关键：方向决定了 ATP 在哪一侧释放、质子从哪一侧来。

图：A 为负染电镜下的亚线粒体小泡，表面排布着带柄的 ATP 合酶（箭头所指，标尺 200 nm / 30 nm）；B 为分子结构模式图，F1​ 头部由 α、β、γ、δ、ε 组成，F0​ 基部由 a、b、c 组成。

第二张图是大肠杆菌 F1​F0​ 的完整剖面，可当作「同一台机器装在不同膜上」的对照。膜上方是蓝紫色的 α3​β3​ 六聚体，中央插着绿色的 γ，旁边贴着 ε；紫色 δ 与灰色 b 组成外周的「柄」，一直伸到膜里与粉色 a 相接；粉色的 c 环埋在膜中。右侧标 ADP + P 进入、ATP 释出，左下角标 H+ 从质子通道进入。

注意图的方位标注：上方是 Matrix（基质），下方是 Intermembrane space（膜间隙）。也就是说 H+ 从膜间隙（P 侧）进入、经 c 环转到基质（N 侧），而 ATP 在基质一侧生成——这与上一张图「头部朝向基质」完全一致。

图：大肠杆菌 F1​F0​ ATP 合酶剖面模型。α3​β3​ 头部在基质侧，γ、ε 构成中央转子，δ 与 b 构成外周定子臂，a 与 c 环埋在膜内构成质子通道；箭头示 H+ 由膜间隙经质子通道进入，ADP + P 进入、ATP 释出。

由球形头部和基部组成，头部朝向基质。

部分组成角色
头部：偶联因子 1（F1​）α3​β3​γεδ催化 ADP + Pi 合成 ATP
基部：偶联因子 0（F0​）由 a、b、c 三种亚基按 ab2​c10∼12​ 组成嵌在内膜中形成质子通道
转子γ、ε随质子流旋转

定子与转子的分工

质子流经 F0​ 带动 γ、ε 旋转；a、b 与 δ 把 F1​ 的 α3​β3​ 固定住。转子转、定子不转，两者相对运动才使 β 亚基的构象被依次拧动。

这张图回答的是「质子流怎么变成旋转」。左图用颜色区分两种角色：橙色部分是静止的（a、b2​ 与 δ），绿色部分是转动的（c 环与 γ、ε），图上还标了两个 H+ 箭头与「Proton half-channel」（质子半通道）。

右图把 a 亚基与 c 环的接触面放大，这是全图最值得细看的地方：两个半通道并不直通，各自只朝膜的一侧开口。因此质子无法一口气穿过膜，必须先「搭」在 c 环的 Asp-61 上（图中标「Proton bound to negative charge on Asp-61」），被 c 环带着转过去，再从另一个半通道释放。五步循环写在图上：① 质子从半通道 I 进入；② Arg-210 被置换；③ 质子从半通道 II 释放；④ c 环旋转；⑤ 过程重复。

这样设计的后果很重要：质子转运与旋转是同一件事，不是「先泵质子、再顺带转一下」。没有质子结合与释放，c 环转不起来；环不转，γ 也带不动 F1​。

图：F0​ 的质子转运机制。左图橙色为静止部分（a、b2​、δ），绿色为旋转部分（c 环、γ、ε），标尺 10 nm。右图为质子经半通道 I 结合 Asp-61 → Arg-210 置换 → 经半通道 II 释放 → c 环旋转 → 过程重复的五步循环。

角色图中颜色包含亚基
静止（stator）橙a、b2​、δ
旋转（rotor）绿c 环、γ、ε

作用过程：

下一张图把「结构」和「三步反应」并排放。A 是剖面：F0​ 埋在膜内，F1​ 伸向细菌胞质（或线粒体基质）；图右侧标出 H+ 的进出方向，左侧标 ADP + Pi​ 与 ATP 的位置——合成发生在 F1​，不在膜内。B 把催化拆成三步循环：ADP + Pi​ 结合 → 由 ADP + Pi​ 生成 ATP → ATP 释放；相邻两步之间 γ 转过一个角度（图中标 120°）。

三步与三个 β 亚基是一一对应的：每转 120° 就有一个 β 走完一步，转到下一个 120° 时轮到下一个 β。这也是为什么三个 β 永远处于不同状态。

图：A 为 F1​-ATP 合酶剖面，F0​ 位于膜内、F1​ 伸向细菌胞质（或线粒体基质），标出 H+ 通路与 ADP + Pi​、ATP 的位置；B 为合成机制三步——ADP + Pi​ 结合、生成 ATP、释放 ATP，γ 每步转 120°。

三种构象：

构象含义
Lloose，松弛构象
Ttight，紧密构象
Oopen，开放构象

「结合变构」这个名字本身就在提示读法：变的是结合力的强弱，而不是催化中心的形状。L 态对 ADP + Pi​ 结合得松，所以能装进来；T 态结合得紧，紧到 ADP 与 Pi​ 之间能自发成键；O 态几乎不结合，ATP 于是被放开。下图把三个 β 画成一个环、中央是 γ，外圈分别标 L / T / O，箭头标出 H+ 流驱动的旋转方向。

按箭头走一圈，每个 β 都会依次经历 L → T → O，而任一时刻环上三个 β 恰好各占一种状态——所以「三个 β 同时处于不同构象」不是巧合，而是旋转结构的必然结果。

图：ATP 合酶的「结合变构」模型。L 为松散构象（结合 ADP + Pi​）、T 为紧密构象（生成 ATP）、O 为开放构象（释放 ATP）；H+ 流驱动 γ 旋转，三个 β 亚基依次在三种构象间循环。

最后一张是同一模型的六步分解。它把两类动作分开画：标 1、3、5 的箭头是 γ 的旋转步，标 2、4 的步骤旁注着「Reaction (no rotation)」——意思是先转，再让化学步骤在静止的 β 上完成，然后再转。三个 β 用 β1​、β2​、β3​ 区分，可以看出每一步里三者状态各不相同，转完一圈后每个 β 都走遍了 O、L、T。

图：结合变构模型的六步循环。1、3、5 为 γ 的旋转步，2、4 为「Reaction (no rotation)」的静止反应步；β1​、β2​、β3​ 在任一步中分别处于 O、L、T 三种构象，随旋转依次轮换。

记忆顺序

催化循环按 O → L → T 推进：开放态释放 ATP、松散态结合 ADP + Pi、紧密态完成合成。三个 β 亚基同时处于不同构象，任一时刻都有一个在催化。

四、氧化磷酸化与质子驱动力

线粒体通过氧化磷酸化进行能量交换，过程见下图与 氧化磷酸化。下面三张图是同一件事的三个尺度：第一张回答「通路发生在哪个区室」，第二张回答「三大营养物质怎么汇进来」，第三张回答「膜上到底发生了什么」。

第一张是全景图，把糖、脂、蛋白的氧化分成 Stage I–IV 四个阶段，并标出每一步所在的区室。读图先看边框：最外一圈灰色是外膜，旁注 permeable to metabolites（对代谢物通透）；里圈是内膜，才是真正的屏障；两者之间是膜间隙，被内膜围住的是基质。

再按阶段读：Stage I 单独画在左侧方框里——葡萄糖经糖酵解变成丙酮酸（生成 NADH 与 ATP），脂肪酸则被活化成脂酰 CoA。Stage II 标在基质内：丙酮酸氧化成乙酰 CoA 并进入三羧酸循环，产出 NADH、FADH₂ 与 CO2​。Stage III 标在内膜上：电子传递链把电子交给 O2​，同时把 H+ 泵出。Stage IV 就是 F0​F1​ 复合物，让 H+ 回流合成 ATP。

图上还画了几个转运体（丙酮酸、脂肪酸、ATP/ADP、Pi​、OH−）。它们回答了「内膜既然不透，代谢物怎么进出」：靠内膜上专一的转运蛋白，而不是靠自由扩散。

图：氧化磷酸化的四个阶段。Stage I 为糖酵解与脂肪酸活化；Stage II 在基质中进行丙酮酸氧化与三羧酸循环，生成 NADH、FADH₂ 与 CO2​；Stage III 电子传递链把 H+ 泵至膜间隙；Stage IV F0​F1​ 复合物合成 ATP。外膜对代谢物通透，内膜上分布着丙酮酸、脂肪酸、ATP/ADP 与 Pi​ 的转运体。

Stage IV内膜（F0​F1​ 复合物）ADP、Pi​、回流的 H+ATP

第二张是中文框架图，把上图的细节压成一条主线：脂肪、多糖、蛋白质分别降解为脂肪酸与甘油、葡萄糖等单糖、氨基酸，三者汇入同一个节点——乙酰 CoA。乙酰 CoA 进入 TCA 循环，碳骨架被彻底氧化并以 CO2​ 排出；脱下的电子（e−）沿 e− 箭头交给左侧的「电子传递（氧化）」框，O2​ 是最终电子受体。

读这张图要盯住左侧方框里的两个词：「氧化」与「磷酸化」。框内是电子传递、框外向上是磷酸化，二者由 e− 与 H+ 串起来——氧化放出的能量不直接存进 ATP，而是先变成质子梯度，再由磷酸化取用。这条三段式（氧化 → 梯度 → 磷酸化）就是化学渗透假说的骨架。

图：三大营养物质氧化的框架。脂肪、多糖、蛋白质分别降解为脂肪酸与甘油、葡萄糖等单糖、氨基酸，汇入乙酰 CoA；乙酰 CoA 进入 TCA 循环释放 CO2​，脱下的电子交给电子传递链，O2​ 参与氧化，释放的能量经磷酸化使 ADP + Pi​ 生成 ATP。

第三张是「化学渗透」的标准示意图，三层标注最关键：上方膜间隙、中间内膜、下方基质。左侧 NADH 在复合物处交出电子，右侧 FADH₂ 在另一处交出电子；电子沿膜内的电子载体（橙色箭头）依次传递，最后交给 O2​，与 H+ 结合生成 H2​O。

与电子流垂直的是绿色的 H+ 箭头：电子传递释放的能量被用来把 H+ 从基质泵到膜间隙，于是膜两侧出现 H+ 浓度差。H+ 无法自由穿膜，只能经右侧的 ATP 合酶回流；回流时带动 ADP + P 生成 ATP。

图底部有两个大括号，分别标 Electron Transport Chain 与 Chemiosmosis，而两者合起来才叫 OXIDATIVE PHOSPHORYLATION。这个层级关系要分清：氧化磷酸化是总称，化学渗透专指「靠 H+ 梯度驱动 ATP 合成」的那一环。

图：电子传递与化学渗透。NADH 与 FADH₂ 分别交出电子，电子经载体链传至末端并还原 O2​ 生成 H2​O；电子传递释放的能量把 H+ 泵入膜间隙，形成跨内膜的 H+ 梯度，H+ 经 ATP 合酶回流驱动 ADP + P → ATP。图中 Electron Transport Chain 与 Chemiosmosis 合称 Oxidative Phosphorylation。

4.1 亚线粒体小泡

用超声粉碎线粒体，得到颗粒朝外的小膜泡，称为亚线粒体小泡；它仍具备电子传递和磷酸化的功能，是研究氧化磷酸化的简化体系。

4.2 质子驱动力（Proton Motive Force）

线粒体合成 ATP 的前提是膜间隙与基质之间的质子浓度梯度。

读下图之前先定命名规则：N 侧 = negative 侧 = H+ 低的一侧；P 侧 = positive 侧 = H+ 高的一侧。这两个名字说的是「电荷」，不是「膜内/膜外」，所以三种体系要分别对应。三格画法完全相同，读法也一样：H+ 从 P 侧经 ATP 合酶回到 N 侧，ATP 在 N 侧生成（图上 ATP 箭头都画在 N 侧这边）。

差别只在「谁是 P 侧」：线粒体把质子泵出基质，所以膜间隙是 P 侧；叶绿体把质子泵进类囊体腔，所以腔内是 P 侧、基质反而是 N 侧；细菌则把质子泵到膜间隙（图中画在细胞膜与细胞壁之间）。

三格对照还能得出一条统一规律：ATP 合酶的头部总朝 N 侧。线粒体头部朝基质（N 侧），叶绿体头部朝叶绿体基质（同样是 N 侧）——两者的差别不在头部朝哪边，而在 P 侧是谁：线粒体是膜间隙，叶绿体是类囊体腔。

体系N 侧（低 H+）P 侧（高 H+）
线粒体基质膜间隙
叶绿体基质类囊体腔
细菌（E. coli）胞质膜间隙

图：三种体系的质子驱动力。线粒体：基质为 N 侧、膜间隙为 P 侧；叶绿体：基质为 N 侧、类囊体腔为 P 侧；细菌：胞质为 N 侧、膜间隙为 P 侧。H+ 均由 P 侧经 ATP 合酶流向 N 侧，ATP 在 N 侧生成。

其他作用：褐色脂肪的 UCP1 使质子驱动力变为热能，而不是用来合成 ATP。

UCP1 的作用方式可以借上图直接理解：它提供的是一条绕过 ATP 合酶的质子回流通道。质子照样从 P 侧回到 N 侧，梯度的能量照样被释放，只是没有经过 F1​ 头部、没有被转成 ATP，而是以热的形式散出。因此「产热」与「产能」不是两套装置，而是同一个梯度的两个出口。

同一个梯度，两种出口

质子回流有两条路：经 ATP 合酶 → 化学能；经 UCP1 → 热能。所谓「解偶联」，本质就是让质子绕过 ATP 合酶回流，把能量以热的形式散掉。

五、电子传递链（Electron Transport Chain）

电子载体

接受和释放电子的分子。常见 5 种：黄素蛋白、细胞色素、泛醌、铁硫蛋白、铜原子。

排序依据：按氧化还原电位从低到高排列——电子自发从低电位流向高电位，释放的自由能用于泵质子。

电子传递链（呼吸链）

由电子载体组成的电子传递序列。

读下图要同时跟三条线：电子流（红色箭头）、质子流（上方的 H+ 箭头）、以及每个复合物的分工。电子从 NADH 进入复合物 I；复合物 II 则从琥珀酸（succinate → fumarate）收取电子，经 FAD 与 Fe-S 交给泛醌。泛醌（UQ） 是膜内可移动的脂溶性载体，把电子从 I、II 一并送到复合物 III；复合物 III（细胞色素 bc1​）再交给 Cyt c，Cyt c 是在膜间隙一侧移动的小蛋白，把电子送到复合物 IV；复合物 IV（细胞色素 c 氧化酶）把电子交给 O2​，生成 H2​O。

图上方累计标出 4H++4H++2H+=10H+，即一对电子走完全链泵出的质子数。看数字就能读出一条重要差别：复合物 II 完全没有质子箭头——它不跨膜泵质子，只是把电子转交给泛醌。

这带来一个直接推论：由 FADH₂ 进入的电子绕过了复合物 I，因此少泵 4 个 H+，最终合成的 ATP 也少。同一条链、同样的氧，产能效率却取决于电子从哪个入口进来。

图：线粒体内膜的电子传递链。NADH 在复合物 I（含 FMN、Fe-S）交出电子，泵出 4H+；复合物 II 经 FAD、Fe-S 从琥珀酸取电子，不泵质子；泛醌在膜内移动；复合物 III 泵出 4H+，Cyt c 在膜间隙侧传递电子；复合物 IV 泵出 2H+ 并把 O2​ 还原为 H2​O；合计 10H+，形成跨内膜的电化学梯度。

复合物 II琥珀酸脱氢酶FAD、Fe-S否0
复合物 III细胞色素 bc1​Cyt b、Cyt c1​、Fe-S、UQ是4H+
复合物 IV细胞色素 c 氧化酶CuA​、Cyt a、Cyt a3​、CuB​是2H+

三个易错点

  1. 把复合物 II 也算作泵质子——它由琥珀酸取电子，直接交给泛醌，全图没有它的质子箭头；把它算进去会把总数误记成 14H+。
  2. 把泛醌、Cyt c 当成复合物——它们是移动的电子载体，不是固定在内膜上的复合物。正因为可移动，才能把电子「串」到下一个复合物。
  3. 以为编号顺序就是分子大小或重要性顺序——排序依据是氧化还原电位由低到高；复合物 II 之所以「插队」，是因为它从琥珀酸这个独立入口取电子，并不在 NADH 的主线上。

六、叶绿体（Chloroplast）

课堂未展开

本节课只讲到线粒体，叶绿体的结构与光合作用相关内容未展开，需自行结合讲义与 PPT 补充。

可确认的只有质子驱动力图中的位置：叶绿体的类囊体腔为 P 侧（高 H+）、基质为 N 侧，类囊体膜上同样有 ATP 合酶（F 型质子 ATP 合成酶）。

从质子驱动力那张图能读出的结构关系只有一条，但很关键：类囊体腔是一个被膜围起来的封闭腔，所以它可以像线粒体的膜间隙那样成为 P 侧。线粒体靠内膜把质子隔在膜间隙，叶绿体靠类囊体膜把质子隔在腔内——两者都是「用一层膜隔出两个 H+ 浓度不同的空间」，只是「外侧」与「内侧」的角色对调了。

推导时要小心方向：两种细胞器的 ATP 合酶头部都朝基质、也都朝 N 侧，结论相同；真正被对调的是 P 侧——线粒体在膜间隙，叶绿体在类囊体腔。所以记图时以 N/P 为准，不要以「膜内/膜外」为准：若按「膜内/膜外」记，叶绿体就会记反。

与生物工程的联系

（1）发酵与细胞培养的能量代谢：细胞培养和发酵过程的 ATP 供应主要来自线粒体氧化磷酸化。营养缺失时线粒体延伸、产能效率提高；营养过剩时分裂活跃、ATP 产量下降。工艺上可通过补料策略调控细胞的能量状态，而不是只盯葡萄糖浓度。

（2）电子传递链与 ATP 合酶作为药物/毒物靶点：复合物 I–IV 与 ATP 合酶是能量代谢的串联节点，抑制任一环节都会切断 ATP 供应，因此既是研究氧化磷酸化的工具，也是药物毒性评价与代谢调控研究的靶点。

（3）线粒体质量控制与工程细胞株稳定性：融合/分裂平衡可稀释自由基对 mtDNA 的损伤，并调控线粒体数目与分布。长期培养的工程细胞株若出现线粒体形态异常或 mtDNA 拷贝数漂移，可作为细胞株质量控制的观察指标。

（4）UCP1 与能量分流：褐色脂肪用 UCP1 把质子驱动力转为热能，提供了「让质子绕过 ATP 合酶」的天然范例；在代谢工程中，这类解偶联思路可用于把还原力导向非 ATP 产物或产热过程。
