# 导入笔记到 QuartzNotes

新笔记进来后按 **6 步**走，顺序不要跳。每步都有「完成标志」，没达到就停下问鱼。

> ⛔ **动手前必读** `.workbuddy/memory/MEMORY.md`。
> 那里是血泪教训（含 mermaid 渲染不出来、callout 不能放表格、子路径前缀不能写死等），
> 本文件只重复最常踩的几条。

---

## 步 1 · 通读全部笔记，摸清这门课

**做什么**：递归 glob `notes/content/**/*.md` 把新导入的这批全读一遍
（⚠️ 必须递归，`content/*/index.md` 会漏掉没有 index.md 的同级目录）。

读的时候记三件事：

1. **章节序列与教学顺序** —— 哪些是主线、哪些是复习/拓展；
2. **核心概念与前置依赖** —— 后一章依赖前一章的哪个概念；
3. **和另外几门课的接缝** —— 哪些概念在别的课里也出现（为步 5 埋线）。

**产出**：一份「课程地图」先在回复里给鱼确认（章节表 + 核心概念链 + 你发现的疑点），
**不要一上来就改文件**。鱼确认后再进步 2。

> ⚠️ 如果这批笔记是用 `scripts/import-*.sh` 搬进来的：
> **`import-biology.sh` 不能重跑**（`cp` 不是 `mv`，会用 `dev/` 旧版覆盖手工加的 callout）。

---

## 步 2 · 知识排查，出审校报告

**做什么**：逐篇排查五类问题，**结果写成一份报告放到项目底下**，不要零散地直接改。

| 类别 | 查什么 |
|---|---|
| **根本性错误** | 概念说反、机理讲错、数值/单位错、结论张冠李戴 |
| **错别字 / 笔误** | 同音错字、缺字、多字、上下标错位 |
| **TeX 公式** | `$`/`$$` 是否成对、`\mathrm{}`/`\text{}` 闭合、`\xrightarrow` 参数个数、花括号配平 |
| **图** | **代码块 / ASCII 字符画画的图一律取缔** → 读上下文判读图意 → 改用 SVG（见硬规则） |
| **术语一致性** | 同一术语在文件内/文件间是否自相矛盾 |
| **可疑但不确定** | 拿不准的、可能是老师原话也可能抄错的 —— 归到 P2 让鱼定夺 |

分级（照抄 `tex-audit-backlog.md` 的口径）：

- **P0** KaTeX 必错、页面直接坏掉
- **P1** 根本性错误 / 术语矛盾 —— 内容错，会误导人
- **P2** 格式与观感问题（超长比大小序列、callout 里塞表格等）

**产出位置**：`.workbuddy/memory/audit-<课程名>.md`，用
`assets/审校报告模板.md` 起头。**已修的条目划掉并标 ✅，未修的原样留着。**

> ⚠️ **报告里必须有一节「明确不是问题的」**，把容易误判的写法列出来
> （例如 `\mathrm{A > B > C}` 花括号是平衡的、不算未闭合）。
> 没有这一节，下一轮会有人把已经对的地方改坏。

> ⚠️ **别信任何「已修正」的声明**（包括 subagent 说的）。搬运长文档时
> 它会把自己重录打错的字说成「修正原稿错误」，而且**行数完全对得上**，对比行数抓不到。
> 只能靠**语义合理性审查**：术语是否存在、同一术语是否自相矛盾。

## 步 3 · 内容拓展

在**不改变原有结论**的前提下补内容。优先级从高到低：

1. **补「与生物工程的联系」** —— 每篇知识点笔记末尾一个 `> [!example]` callout，
   给**具体工程实例**（不是空泛的「可用于医药」）。
   这是本知识库的特色主线，缺了整库就散了。有机那篇是范本：
   `知识点/反应类型/加成.md` 的 `## 与生物工程的联系`（6 个实例 + 期末考试重点就在里面）。
2. **补「相关笔记」** —— 裸 wikilink + 一句话说明，指向**真的存在**的笔记。
3. **中英双语术语** —— 关键术语首次出现时标英文：`亲电加成（Electrophilic Addition）`。
4. **补表格** —— 对比、活性顺序、试剂表。⚠️ 表格放**框外**，见下方硬规则。
5. **补图** —— 文字真的表达不了的才画。三条路，先问「这是示意图还是定量图」：

   | 情况 | 走哪条 |
   |---|---|
   | 示意图（机理、能量高低、流程、构象） | **内联 SVG**（默认） |
   | **有真实数据**、需要坐标轴的定量图 | **matplotlib** 出图 → `图片保存/` + `![[x.svg]]` |
   | 画不出定量图但需要真图/真显微图 | **权威机构现成图**（RCSB / PubChem / NIH / Wikimedia…） |

   ⚠️ **不凭空造数据**：没有数值就别画「定量」的图，画成示意图并标注「示意，非按比例」——
   一条平滑曲线会暗示不存在的定量精度。外部图必须说清来源和许可，说不清就不用。
   完整规矩（含 matplotlib 模板与中文/暗色/许可的坑）见 `references/科研配图.md`。

   ⚠️ 别用 ASCII 字符画（窄屏必错行），别碰 mermaid（渲染不出来）。
   发现已有的 ASCII 图要**主动取缔**替换，流程见硬规则。

排版细则见 `references/风格规范.md`。

## 步 4 · 结构可视化（分子 / 蛋白 / 3D）

数据全在 `notes/static/molecules.json`，**加条目只改这个 JSON，不碰任何 `.ts`**。

**做什么**：通读新笔记时把值得画的结构挑出来（官能团、构型、环系、有教学点的中间体），
每条写 `name / smiles / formula / note / group / tip`，蛋白质写 `pdb` 代替 `smiles`。

**硬标准**（用户明确要求过）：

- ⛔ **不用任何在线 API** 查 SMILES（太慢）。用知识库直接写。
- ⛔ **每条必须带 `formula`，并自己把 SMILES 的原子数数一遍核对。数不准就别加** —— 宁缺勿错。
  历史上手写的 5 处错（甲硫氨酸/谷氨酰胺多一个 CH₂、PIPES 分子式、柠檬酸根少一个负电荷…）
  全靠这一步抓出来。
- ⛔ **不收「过于简单」的** —— 画出来只有一两个原子、看不出教学点的全剔。
  例外：该结构本身就是那篇笔记的主题时保留。
- `note` 填**目标笔记的文件名**（不含 `.md`、不带路径）。填对才在这篇笔记的侧栏出现。
- 一个蛋白可以挂多篇笔记（`note` 是一对多）。
- ⚠️ **删条目别删数组最后一条**（尾逗号一去，数组以 `,` 结尾，JSON 直接失效）。

渲染/降级链、emitter、主题配色那些坑见 `references/结构可视化.md`。

## 步 5 · 跨学科串联

**先看** `notes/content/跨学科/index.md` 和已有的 6 条主线，再决定加什么。

**找法**：不要从公式出发找串联点，从**一个具体的工程问题**出发
（例：「发酵罐里怎么把 pH 稳住」「传感器怎么读到细胞内的电化学状态」）。
一个问题在三门课里各有面貌，那才值得串。

**产出**两种，二选一或都做：

- **补进已有主线** —— 新笔记里有段落能加深某条已有主线，直接加进去；
- **开一条新主线** —— 三个以上课程段落能围成一个新的「物理化学问题」，
  写成 `跨学科/<主题>主线-<副标题>.md`，**同时在 `跨学科/index.md` 的索引表里加一行**。

**红线**：`跨学科/` 的笔记**只链过去、不改原笔记** —— 反向链接靠 Quartz 自动生成 Backlinks。

格式见 `references/跨学科串联.md`。

## ⛔ 硬规则（违反就是返工）

来自 `MEMORY.md`，这里是最常踩的几条：

- **callout（`> [!xxx]`）里不许放表格。** callout 有内边距，表格会被压到不可读、横向溢出。
  要「提示框 + 对照表」就**拆两段**：上面一段纯文字，下面一段独立表格。
- **发现用代码块 / ASCII 字符画（`┌─┐│└┘`）画的图，一律取缔。**
  流程：**先读上下文 + 判读这张图到底在表达什么** → 决定画法 → **优先 SVG**
  （mermaid 排第二，但本站渲染不出来，实际就是 SVG）→ 改完把旧围栏删干净
  → 宽屏 / 窄屏 / 暗色各验一遍。
  ⚠️ **不要把 ASCII 的格子 1:1 复刻成 SVG** —— 那只是把难看的图换个难看的画法。
  五步流程 + ASCII 符号破译表见 `references/SVG画图.md` 第六节。
- **⛔ mermaid 渲染不出来，已放弃。别动。** 但 **SVG 可以画** ——
  `parse.ts` 有 `allowDangerousHtml: true` + `ofm.ts` 挂了 `rehype-raw`，内联 `<svg>` 会正常渲染。
  反应机理图、能量剖面、流程/层级、立体示意 → **用 SVG**。
- **超长的「比大小」序列**（5 项以上 `$$A>B>C>...$$`）横向必溢出 → 改成竖排两列表格提到框外。
- **正文内链用裸 wikilink**（`[[某章节.pdf]]`），**禁 `../`**；前提是全库文件名唯一。
- **`index.md` 里的链接必须写从 `content/` 根起的完整路径**
  （如 `有机化学笔记/知识点/反应类型/加成`），不要写绝对 URL，文件夹名不算唯一匹配。
- **PDF 链接写连字符形式**（`2 生命的化学基础.pdf` → `2-生命的化学基础.pdf`），否则 404。
- **主题 CSS 变量只有** `--light --lightgray --gray --darkgray --dark --secondary --tertiary --highlight`
  和三个字体变量。**没有** `--bg` `--text` `--border` `--font-mono`，用了不报错但样式直接失效。
- **子路径前缀不要写死 `/notes`** —— 本地 `npx quartz build --serve` 不加 `--baseDir` 时
  `public/` 挂在根上，写死必 404。运行时反推（`siteRoot()`）。
