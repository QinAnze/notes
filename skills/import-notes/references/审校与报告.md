# 知识排查：清单与报告口径

素材：`.workbuddy/memory/tex-audit-backlog.md`（有机化学 37 篇的审计结论，可作判例库）。

**原则：先出报告，再改文件。** 直接边看边改会把「根本性错误」和「格式洁癖」混在一起，
鱼分不清哪些是他老师原话、哪些是 AI 手滑。

---

## 一、排查清单（逐文件过，别抽样）

### A. 根本性错误（P1，最要紧）
- [ ] **概念说反** —— 机理方向、活化能高低、稳定性排序
- [ ] **数值 / 单位错** —— pKa、℃、nm、kDa、mol%、pH、缓冲浓度
- [ ] **张冠李戴** —— 这个反应的试剂/产物写到相邻反应头上了
- [ ] **适用范围过宽** —— 「NaBH₄ 能还原酯」这种绝对化表述
- [ ] **因果倒置** —— 先说结论再编理由

> ⚠️ **不要相信任何「已修正」的声明**（尤其 subagent 说的）。
> 它会把自己重录时打错的字说成「修正原稿错误」，而且**行数完全对得上**，对比行数抓不到。
> 唯一可靠的是**语义合理性审查**：术语是否存在、同一术语在文件内是否自相矛盾。

### B. 错别字 / 笔误（P1）
- [ ] 同音错字（苯/萘、羟/氧、酮/脂、酚/稀）
- [ ] 缺字 / 多字（句子缺宾语、定语后置）
- [ ] **上下标错位** —— $\mathrm{C_2H_5}$ 写成 $\mathrm{C_2H_5}$ 之外的形态、$n$ 与 $m$ 混
- [ ] 术语中英混用不一致（同一节里 `羰基` 和 `碳基` 并存）
- [ ] 标点：中文段落里混英文逗号、全角/半角括号混用

### C. TeX / KaTeX（P0 优先）
- [ ] `$` 与 `$$` 是否**成对**（单双混用最容易漏）
- [ ] `\mathrm{}` `\text{}` `\dfrac{}` 等**花括号配平**
- [ ] **反斜杠写重了** —— `\\text{无水酸}`（`加成.md` 之外，`醛酮.md:194/215` 就是这样）
- [ ] `\xrightarrow{A}{B}` 参数个数错 —— 单条件必须写成 `\xrightarrow[B]{A}`（`不饱和烃和共轭体系.md:376`）
- [ ] `\underbrace` / `\overbrace` 配对
- [ ] `^` `_` 后面没内容

### D. 中文进 math mode（P1）
```markdown
❌ \xrightarrow{燃烧}          \xrightarrow[\Delta]{\text{高温/催化}}
❌ \mathrm{苯}              \mathrm{蒽 + 顺丁烯二酸酐}
✅ \xrightarrow{\text{燃烧}}   \mathrm{\text{苯}}
```
判据：**只要中文出现在 `$$...$$` 里面而没被 `\text{}` 包住，就是问题。**

### E. 排版 / 观感（P2；其中「ASCII 图」要主动取缔）
- [ ] **代码块 / ASCII 字符画画的图 → 一律取缔**，按 `SVG画图.md` 第六节五步走：
      ① 读上下文（前后各两段）② 判读这张图在表达什么 ③ 选型（**能一行文字说清就别画图**）
      ④ **优先 SVG**（mermaid 排第二，本站渲染不出来）⑤ 宽屏 / 窄屏 / 暗色各验一遍
      ⚠️ **不要把 ASCII 的格子 1:1 复刻成 SVG** —— 那是把难看的图换个难看的画法
- [ ] **ASCII 字符画** —— 窄屏必错行
- [ ] **mermaid 围栏** —— 本站渲染不出来，会显示成代码块
- [ ] **SVG 常见错**：漏 `viewBox`、`height` 写死、颜色写死没跟随主题、
      `<marker>` 的 `id` 与同页其他图撞了
- [ ] **替换后残留的半截代码块围栏** —— 页面看起来像坏了但构建不报错；
      验收时对一下「代码块数量比替换前少了」
- [ ] **callout 里有表格 / 有图** —— 会压到不可读或变形，拆到框外
- [ ] 超长「比大小」序列（≥5 项 `$$A>B>C>D>E>F$$`）—— 横向溢出，改竖排表格
- [ ] 行内长公式 —— 撑破栏宽，改独立成行
- [ ] 标题层级跳跃（h2 直接跳 h4）
- [ ] 中英文之间缺空格（`KcsA的` → `KcsA 的`）
- [ ] 死链（`[[xxx]]` 指向不存在的文件）——**Quartz 不报错，只能靠核对文件名清单**

### F. 配图（正确性优先于好看）

> 三条路：内联 SVG（示意图）/ matplotlib 出图（有数据的定量图）/ 权威机构现成图。
> 完整规矩见 `科研配图.md`。

- [ ] **图上的数值/单位/方向和正文一致** —— 图和文字打架时改图
- [ ] **没有凭空造的数据** —— 每条曲线都能指回正文/表格的具体数值；
      只有定性关系时已标「示意，非按比例」
- [ ] **外部图说清来源与许可** —— 机构 + license（CC-BY 必须署名）；说不清 → 不用
- [ ] **没用禁用来源** —— 商业网站 / 题库 / 搜索结果里的图，一律不算
- [ ] 外部图**已下载到 `图片保存/`**，没有外链；文件名带来源便于追溯
- [ ] 图注有出处（自绘 → 数据来源；外部 → 机构 + 许可）
- [ ] matplotlib 图：中文不是豆腐块（字体已配）、暗色模式下看得见、坐标轴带单位
- [ ] 暗色模式 / 窄屏 / 100% 缩放下都读得清

### G. 链接与索引
- [ ] `index.md` 里的链接是**从 `content/` 根起的完整路径**（不是 `../`，不是绝对 URL）
- [ ] PDF 链接是**连字符形式**（`2 生命的化学基础.pdf` → `2-生命的化学基础.pdf`）
- [ ] 正文内链用的是**裸 wikilink**（不是 `../`）
- [ ] 全库**文件名唯一** —— 两门课都有「绪论」就会让 shortest 解析失效

## 二、分级口径

| 级别 | 含义 | 例子 |
|---|---|---|
| **P0** | KaTeX 必错 / 页面直接坏掉 | `$` 不配对、`\\text`、`\xrightarrow` 参数错 |
| **P1** | 内容错，会误导人 | 机理说反、pKa 数值错、中文进 math、术语自相矛盾 |
| **P2** | 观感与格式 | callout 塞表格、超长序列、行内长公式、死链 |
| **P2+** | **ASCII / 代码块图 → 主动取缔** | 用户明确要求：见下面 E 节，替换成 SVG |

**P0/P1 要主动改**（改完在报告里划掉标 ✅）；**P2 先列出来让鱼定夺**，别擅自大改版式。
**唯一例外是 ASCII / 代码块图 —— 那条要主动改**（用户 2026-10-11 明确「一律取缔」）。

## 三、报告里必须有「明确不是问题的」这一节

**没有这一节，下一轮会有人把已经对的地方改坏。** 直接抄 `tex-audit-backlog.md` 的判例：

- `$\ tert\text{-}Bu\ \mathrm{OH} \approx 18$` —— `$` 是成对的，问题只是前导多余空格 + `tert` 没包 `\mathrm{}`。
  属格式洁癖，**非错误**。
- `I > Br > Cl > S > F > O > N > C > D > H` —— 是**普通粗体文本**，根本没写 TeX。
- `\mathrm{A > B > C}` —— 花括号**平衡**的写法，只要 `$` 数对、命令参数位置对就合法，
  不能算「未闭合」。

**规律**：判断「未闭合」要同时看三件事 —— `$` 数量、`{` 数量、命令参数位置。
只数 `$` 会把合法的 `\mathrm{A>B>C}` 误报。

不要和「问题」混在一起，否则鱼分不清哪些是必须改的。
