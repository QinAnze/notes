# 结构可视化：分子 / 蛋白 / 3D

数据源：`notes/static/molecules.json`（约 410 条 / 55 篇笔记 / 含 21 个蛋白 PDB）。
**加条目只改这个 JSON，不碰任何 `.ts`。**

侧栏「结构演示」组件会按当前页面的 slug 去匹配条目，匹配不到就整块隐藏 ——
所以 `note` 字段填错，条目就等于没加。

---

## 一、字段

```json
{
  "name": "1,3-丁二烯",
  "smiles": "C=CC=C",
  "formula": "C₄H₆",
  "note": "不饱和烃和共轭体系",
  "group": "有机",
  "tip": "s-cis 与 s-trans 构象决定了 1,2/1,4 加成的选择性。"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 显示名 |
| `smiles` | 小分子 ✅ | 蛋白质条目**不给**，改用 `pdb` |
| `pdb` | 蛋白质 ✅ | `"1MBO"`（RCSB 实验结构）或 `"AF-P01308-F1"`（AlphaFold 预测） |
| `formula` | ✅ | 直接写死。RDKit MinimalLib 的 descriptors 不保证带分子式 |
| `note` | ✅ | **目标笔记的文件名**（不含 `.md`、不带路径），大小写不敏感 |
| `group` | ✅ | 分类标签 |
| `tip` | 推荐 | 一句话教学点 —— 这是侧栏里最有价值的字段 |
| `src` | 可选 | `manual` = 人工书写并核对了原子数 |

## 二、收录判据（用户明确要求过）

**要放**：有官能团、有构型、有环系、能看出教学点的结构。
典型：苯环衍生物、顺/反异构体、构象异构、鎓离子/碳正离子中间体、常见试剂。

**不放**：画出来只有一两个原子、看不出教学点的。

> 甲烷、乙烷、乙醇、甲醇、水、氢气、氨、CO / CO₂ / SO₂ / O₃、N₂、
> 卤素单质、常见金属离子 —— 全部剔除。

**例外**：该结构本身就是那篇笔记的主题时保留
（无机 S2 讲 VSEPR 时的 CO₂ / SO₂、S1 讲离子半径的 Na⁺ / Cl⁻、拓展-生物电化学讲能斯特的 K⁺ / Na⁺ / Ca²⁺）。

**宁缺勿错** —— 分子式核不准的条目会直接教错人。

## 三、⛔ 三条硬禁令

1. **不用任何在线 API 查 SMILES**（Cactus / PubChem 等）。用户明确要求：太慢。
   用知识库直接写。
2. **每条必须带 `formula`，并自己把 SMILES 的原子数数一遍核对。**
   这是唯一能机械防错的手段。历史上手写的 5 处错全靠这一步抓出来：
   甲硫氨酸 / 谷氨酰胺多一个 CH₂、PIPES 分子式、柠檬酸根少一个负电荷、环丙烯正离子。
   **数不准就别加。**
3. **删条目别删数组最后一条** —— 尾逗号一去，数组就以 `,` 结尾，JSON 直接失效。
   要删最后一条就把上一条的尾逗号一起处理。

在**步 2 排查的同时**顺手记，别等到步 4 回头重读一遍。

一份新笔记里，下面这些通常值得画：

| 笔记类型 | 值得画的 |
|---|---|

## 五、渲染链路（出问题时的排查顺序）

```
static/molecules.json
  → quartz/plugins/emitters/moleculeData.ts   （自定义 emitter，把根 static/ 拷进产物）
  → 运行时：siteRoot() 反推站点根 → staticUrls() 多候选 → fetchFirst() 逐个试到 200
  → RDKit(WASM) 画 2D → preprocessSvg() 换成 currentColor → CSS var(--dark) 上色
```

已知的坑（都在 `MEMORY.md` 里，改这块前先看）：

- ⚠️ 上游 `Plugin.Static` 只复制 `quartz/static/`，**项目根的 `static/` 会被整个忽略**
  → 必须有 `moleculeData.ts`（已在 `quartz.config.ts` 注册，重装 Quartz 要重打）。
- ⚠️ `getRDKit()` 必须先 `loadScript` 再 `initRDKitModule`，少了第一步整块显示「渲染错误」。
- ⚠️ RDKit 的颜色藏在**两处**：属性 `stroke='#000000'` **和**内联 `style='...;fill:#000000'`（原子字母）。
  `preprocessSvg()` 用 `DOMParser` 遍历 DOM 两处一起换 `currentColor`，**不要用正则**。
- ⚠️ 降级链不能省：RDKit → SmilesDrawer → 纯文本 SMILES（本站 mermaid 踩过的同一个坑）。
- ⚠️ 数据 URL **不要写死 `/notes`**：本地 `npx quartz build --serve` 不加 `--baseDir` 时
  `public/` 挂在服务器根上，写死必 404。
