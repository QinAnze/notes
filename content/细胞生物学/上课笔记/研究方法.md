# 细胞生物学研究方法（Research Methods in Cell Biology）

> 讲义：[[第二章-细胞生物学研究方法.pdf]]

> [!summary] 本章解决什么问题
> 研究细胞要同时解决三件事：**看得见**（显微成像，分辨率决定能看到多小的结构）、**分得开**（离心、免疫标记、原位杂交、流式分选，把目标分离出来或定位到原位）、**养得活、改得动**（细胞培养与细胞工程，让细胞在体外持续增殖并被改造）。本章按这三条线组织，末尾补上观察动态过程的方法与模式生物。

## 一、显微成像的物理下限

### 1.1 光镜的组成

| 拆法 | 部件 |
|---|---|
| **五部分** | 目镜、物镜、准焦螺旋、载物台、反光镜 |
| **三系统** | 光学放大系统（物镜 + 目镜）、照明系统（光源 + 聚光镜）、镜架与样品调节系统 |

> [!note] 为什么有两种拆法
> 五部分拆法按“手能摸到的零件”分，便于操作；三系统拆法把**成像**与**照明**分开，因为分辨率不只看镜头——照明方式（明场、暗场、相差）决定了样品的对比度从哪里来。

### 1.2 分辨率

**分辨率**指能区分两个质点的最小距离，这个数值越小，分辨能力越强。

$$R=\frac{0.61\lambda}{N\sin\frac{\alpha}{2}}$$

其中 $\alpha$ 是镜口角（样品对物镜镜口的张角），$N$ 与介质的折射率有关。

> [!important] 为什么 R 越小越好，又为什么不能无限小
> R 与波长 $\lambda$ 成正比：波长越短，能分辨的间距越小。电镜用电子束代替可见光，正是把 $\lambda$ 压下去的做法，所以最佳状态可达 0.2 nm；光镜受可见光波长约束，分辨率有物理上限。增大镜口角同样能改善 R，这也是高倍物镜要做成“短焦、大开口”的原因。

### 1.3 光学显微镜的类型

| 类型 | 能看什么 | 关键点 |
|---|---|---|
| **普通光学显微镜**（正置 / 倒置） | 染色后的固定样品 | 制样流程：取材 → 固定 → 包埋 → 切片 → 染色 → 观察 |
| **相差、微分干涉显微镜** | **非染色活细胞** | 把光程差转成明暗差，所以不必染色即可成像 |
| **暗视野显微镜** | 浅色样品 | 背景黑，样品在暗背景下显亮 |
| **荧光显微镜** | 特定分子 | 荧光分**自发荧光**与**诱发荧光**；可定位分子、做定性研究；核心部件是滤光片系统（激发滤光片 + 阻断滤光片）与专用物镜；制样用免疫荧光技术或荧光素直接标记（如 GFP） |
| **共焦显微镜**（讲义分列“荧光扫描共焦”与“激光扫描共焦”） | 厚样品的光学切片 | 以激光为光源，分辨率高于普通荧光显微镜 |
| **超高分辨率显微术** | 突破衍射极限的结构 | 全内反射荧光（TIRFM）；基于单分子成像的 PALM / STORM；4Pi 与 STED；结构照明显微术（SIM） |

> [!warning] 两个“共焦”条目别当成两台仪器
> 讲义把“荧光扫描共焦显微镜”和“激光扫描共焦显微镜”并列。共同点是激光光源 + 扫描成像、分辨率高于普通荧光显微镜；讲义没有展开两者的差别，答题时按同一类仪器理解即可。

> [!tip] 选显微镜先问两个问题
> 1. **样品是死的还是活的？** 活的且不染色 → 相差 / 微分干涉；活的但要标记特定分子 → 荧光或共焦。
> 2. **要内部结构还是表面形貌？** 内部 → 透射光路；表面立体感 → 扫描电镜；只要表面起伏 → STM。
> 另外，观察非染色活细胞是相差类显微镜的看家本领，别错答成荧光显微镜。

## 二、电子显微镜

### 2.1 与光镜的根本差别

| 项目 | 光学显微镜 | 电子显微镜 |
|---|---|---|
| **光源** | 可见光 | 电子束 |
| **聚焦** | 玻璃透镜 | 电磁透镜 |
| **光路环境** | 常压 | 镜筒高度真空 |
| **分辨率** | 受波长限制 | 最佳状态可达 0.2 nm |

高度真空不是可选项：电子在空气中会被气体分子散射，光路无法成立，所以电镜样品必须先固定、脱水。

### 2.2 基本构造

由**电子束照明系统**、**成像系统**、**真空系统**、**记录系统**四部分组成。

### 2.3 制样技术

| 技术 | 做法 | 用途 / 特点 |
|---|---|---|
| **超薄切片** | 取材 → 固定 → 包埋 → 切片 → 染色 → 观察 | 常规透射观察的基础流程 |
| **负染色** | 重金属盐沉积在铜网上，**样品本身未被染色** | 观察线粒体、核糖体、蛋白质颗粒、细胞骨架纤维、病毒 |
| **冷冻蚀刻** | 冰冻断裂 + 蚀刻复型 | **不需要固定包埋**，避开化学处理带来的假象 |
| **三维重构与低温电镜** | 低温制样 + 多角度成像重建 | 解析三维结构 |
| **扫描电镜（SEM）** | 样品用 $\mathrm{CO_2}$ 临界点干燥，观察前喷镀一层金膜 | 得到表面的**立体样貌** |

> [!important] 负染色为什么是“反着染”
> 样品没有被染上，重金属盐只堆积在样品周围。电子穿过时被盐挡住，于是**背景暗、样品亮**——对核糖体、病毒、蛋白颗粒这类小颗粒，反而比正染更容易看清轮廓。

## 三、扫描隧道显微镜（STM）

> [!note] STM 的五个特点
> 1. 只观察**表面**样貌
> 2. 利用**隧道效应**
> 3. 高分辨率
> 4. **非破坏性**测量
> 5. 可在多种环境下工作

与电镜的根本差别在成像所依据的物理量：电镜靠电子束成像，STM 靠探针与样品表面之间的隧道效应，因此不必把样品放进高真空镜筒，也能做非破坏性观测。

## 四、组分分离：离心

| 方法 | 分离依据 | 结果 |
|---|---|---|
| **差速离心** | 质量与密度不同 | 按先后顺序把不同组分沉淀下来 |
| **密度梯度离心** | 沉降率不同 | 在梯度介质中形成**沉降带**，分速度沉降与等密度沉降两种 |

> 差速离心用的是“谁先沉”，密度梯度用的是“谁沉到哪一层”。后者能分开沉降率相近的组分，所以亚细胞组分精细分离要靠它。

## 五、特异分子的定位与定性

### 5.1 免疫标记

原理只有一条：**抗原与抗体的特异结合**。

| 技术 | 做法 | 特点 |
|---|---|---|
| **直接免疫荧光** | 荧光分子直接与抗体偶联，标记抗原 | 步骤少 |
| **间接免疫荧光** | 先让第一抗体与抗原反应，再加入与荧光分子偶联的、抗第一抗体的第二抗体 | 多一层放大，一个抗原可结合多个二抗 |

| 免疫电镜技术 | 与抗体结合的标志物 |
|---|---|
| **免疫铁蛋白技术** | 铁蛋白 |
| **免疫酶标技术** | 酶 |
| **免疫胶体金技术** | 胶体金 |

> [!warning] 两种“区分”不要混
> 直接 / 间接免疫荧光的区别在于**用了几层抗体**；三种免疫电镜技术的区别在于**标志物种类**。两者是不同维度的分类，题目常把它们并列来做干扰项。

### 5.2 原位杂交

用标记过的**核酸探针**，通过分子杂交确定特定核苷酸序列在细胞内的**位置**。

| 水平 | 标记方式 |
|---|---|
| **光镜水平** | 同位素或荧光素标记探针 |
| **电镜水平** | 生物素标记的探针，与“连接抗生物素抗体的胶体金”结合 |

> [!important] 抗体认蛋白，探针认核酸
> 免疫标记定位的是**蛋白质**，原位杂交定位的是**核酸序列**。要回答“这个基因的 mRNA 在哪个细胞里”，只能用原位杂交；要回答“这个蛋白分布在哪”，用免疫标记。

## 六、亚细胞组分分析与分选：流式细胞术

流式细胞术让细胞逐个通过检测区，因此可以**定量测定单个细胞**中 DNA、RNA 或某一特异蛋白的含量；在此基础上加上分选模块，就能把满足条件的细胞群体**分离**出来。前者用于分析，后者用于建株。

## 七、细胞培养与细胞工程

### 7.1 动物细胞

- **四个概念**：原代细胞 → 传代细胞 → 细胞系 → 细胞株，按“来源 → 能否传代 → 是否稳定”逐级递进，详见 [[动物细胞培养]]。
- **基本形态**：成纤维样细胞、上皮样细胞。
- **培养方式**：贴壁培养、悬浮培养。

### 7.2 植物细胞

- **单倍体细胞培养**：利用花药。
- **原生质体培养**：利用去掉细胞壁的原生质体。

### 7.3 细胞工程

| 技术 | 内容 |
|---|---|
| **细胞融合** | 灭活病毒、化学物质（如 PEG）、电融合 |
| **单克隆抗体** | 杂交瘤制备与筛选，见 [[单抗]] |
| **细胞拆合** | 拆成**胞质体**与**核体**；物理法用机械法或短波光，化学法用细胞松弛素 |
| **显微操作与克隆** | 在显微镜下直接操作单个细胞，是核质重组与克隆的技术基础 |

> [!tip] 悬浮培养为什么是工业主流
> 贴壁培养受培养面积限制，放大就要堆叠更多培养瓶；悬浮培养把细胞分散在液体中，体积可以直接放大，取样与换液也更容易。这是单抗、疫苗等细胞产品走向规模化的前提。

## 八、动态过程与相互作用的研究

| 方法 | 看什么 |
|---|---|
| **荧光漂白恢复（FRAP）** | 漂白一片区域后观察荧光恢复，反映分子（如膜蛋白）的流动与扩散 |
| **酵母双杂交** | 蛋白质与蛋白质的相互作用 |
| **荧光共振能量转移（FRET）** | 一个蛋白的荧光可激发另一个发出荧光，用于判断两个分子是否靠近 |
| **放射自显影** | 利用氯化银或溴化银的感光作用标记 |

四条思路可归为两类：**看运动**（FRAP）与**看相互作用**（酵母双杂交、FRET），放射自显影则负责把“哪里有放射性标记”显影出来。汇总见 [[动态方法]]。

## 九、模式生物

模式生物的共同特点：**个体小、容易培养、操作简单、生长繁殖快**。

> 这四个特点指向同一个目的：在有限的时间与空间里得到足够多的个体和世代，才能做遗传学与功能研究。条件苛刻的物种再“典型”，也无法承担模式生物的角色。

## 与生物工程的联系

> [!example] (1) 单抗生产 = 细胞融合 + 选择 + 培养放大
> 细胞融合提供杂交瘤，流式或有限稀释完成克隆化，悬浮培养完成规模放大，三步正好对应本章的三类技术（详见 [[单抗]]）。

> [!example] (2) 疫苗生产的细胞基础
> 病毒只能在活细胞内增殖，因此疫苗制备依赖细胞培养：贴壁或悬浮、原代或传代细胞系的选择，直接决定了能否稳定、批量地提供宿主细胞。

> [!example] (3) 流式分选 → 高产细胞株的筛选
> 把荧光强度与分选模块结合，可一次从一个混合群体中挑出表达量高的单细胞，再经克隆化成为稳定细胞株——这是重组蛋白与单抗上游开发的标准动作。

> [!example] (4) 显微操作与细胞拆合 → 核质重组与克隆动物
> 把核体与胞质体重新组合，或直接把供体核移入去核卵母细胞，都建立在显微操作之上；细胞松弛素处理则用于松弛细胞骨架、便于拆合。
