# 细胞分裂时期的详述
0# 细胞周期四时相详述：G1 · S · G2 · M

> **一句话**：一个细胞周期 = **G1（生长与决策）→ S（DNA 复制）→ G2（质检与备料）→ M（核分裂 + 胞质分裂）**。前三者合称**间期**，占全程 90% 以上时间；M 期最短却形态变化最剧烈。核心逻辑是：**间期负责"复制一份"，M 期负责"平分两份"**。
>
> **两个变量要分开记**：**C = DNA 含量**（单倍体基因组为 1C），**N = 染色体组数 / 倍性**。S 期只变 C 不变 N；后期只变 N 不变 C。这是全篇最容易混的地方。

---

## 一、总览

| 时相 | 时长（人培养细胞，约 24 h） | DNA 含量 | 染色体数（人 2N=46） | 核心事件 | 主要检查点 |
|---|---|---|---|---|---|
| **G1** | **10–12 h**（变异最大） | 2C | 2N（46 条，每条 1 单体） | 细胞长大、RNA/蛋白合成、**R 点决策**、复制许可 | G1/S（DNA 损伤）、R 点 |
| **S** | **6–8 h** | **2C → 4C** | 2N 不变（46 条 → 每条 2 单体） | 半保留复制、组蛋白合成、中心体复制、黏连建立 | Intra-S（复制叉停滞） |
| **G2** | **3–4 h** | 4C | 2N（46 条，每条 2 单体） | 修复、M 期蛋白合成、中心体成熟、**pre-MPF 蓄势** | **G2/M**（复制完成 + 损伤修复） |
| **M** | **约 1 h** | 4C → 每个子细胞 2C | 后期暂时 4N（92 条）→ 子细胞 2N | 凝缩、核膜解体、排列、分离、去凝缩、胞质分裂 | **SAC**（中期） |

> ⚠️ **"Gap（间隙）"是历史遗留的误导性名字**：G1/G2 不是空白等待期，而是代谢最活跃、合成最旺盛的阶段。当年只是因为在光镜下"看不到染色体变化"才叫间隙。

## 二、G1 期（DNA 合成前期 / 第一间隙期）

### 2.1 在做什么

| 类别 | 事件 |
|---|---|
| **体积恢复** | 分裂后子细胞只有母细胞约一半大，G1 要重新长大（mTORC1 感知营养与生长因子，驱动核糖体生物合成、蛋白与脂质合成） |
| **转录活跃** | rRNA、mRNA、tRNA 大量合成；核仁明显；细胞器（线粒体、ER、高尔基）增殖 |
| **命运决策** | 继续循环 / 退出到 **G0**（静息）/ 分化 / 衰老 / 凋亡 |
| **复制许可** | 低 CDK 环境下装载 MCM2-7，为 S 期做准备（见 2.3） |

### 2.2 ★ 限制点（R point / 酵母 START）

- 位于 G1 中晚期。**越过 R 点之前**依赖生长因子；**越过之后**即使撤掉生长因子，细胞也照走完本周期。
- 分子链：生长因子 → Ras/MAPK → **cyclin D–CDK4/6** 单磷酸化 **Rb** → **cyclin E–CDK2** 超磷酸化 Rb → **E2F 释放** → 转录 cyclin E/A、Cdc6、MCM、DNA Pol α、TK、DHFR → 正反馈自我维持。
- 刹车：**p16^INK4A**（抑 CDK4/6）、**p21/p27**（抑 CDK2）、TGF-β（上调 p15/p27）。
- 详见 [[MPF和各种周期调控相关蛋白]]。

### 2.3 复制许可（licensing）必须在 G1 完成

低 CDK 活性（APC/C^Cdh1 活跃）→ ORC 结合复制起点 → Cdc6 + Cdt1 装载 MCM2-7 双六聚体 → 形成 pre-RC（许可完成）。

- APC/C^Cdh1 在 G1 降解 **geminin**、cyclin B、Plk1、Skp2，维持"允许装载"的低 CDK 环境。
- **许可（G1）与起始（S）被分到两个不同的 CDK 状态**，这是真核"每周期只复制一次"的根本设计。

### 2.4 G1/S 检查点

| 环节 | 机制 |
|---|---|
| 感知 | DNA 损伤（DSB 由 **ATM**、UV/单链由 **ATR**） |
| 传导 | Chk1 / Chk2 → **p53 稳定化**（摆脱 MDM2 降解） |
| 效应 | p53 → **p21** ↑ → 抑制 cyclin E/A–CDK2 → Rb 保持低磷酸化 → E2F 不释放 → **停在 G1** |
| 快速通路 | Chk1 → SCF^βTrCP 降解 **Cdc25A** → CDK2 立刻失活（不依赖 p53 转录） |
| 结局 | 可修复 → 暂滞；不可修复 → 凋亡（Bax/PUMA）或衰老（p16） |

> **临床意义**：**p53 突变使 G1 检查点失效**，肿瘤细胞因此更依赖 S/G2 检查点；这正是 **Wee1 抑制剂 + DNA 损伤药合成致死** 的理论基础。

### 2.5 时长、G0 与特殊情形

- **G1 是四个时相中变异最大的**：同一种细胞在不同营养条件下，周期长短差几乎全来自 G1。
- **G0（静息期）**：从 G1 退出、不再循环，但代谢仍活跃。
  - 终末分化、不可逆：神经元、心肌细胞、骨骼肌
  - 可逆（可被召回）：肝细胞（损伤后再生）、淋巴细胞（抗原激活）、成纤维细胞（血清刺激）
  - 分子特征：Rb 低磷酸化、p27 高、cyclin D/E 低、rRNA 转录低
- **早期胚胎卵裂（爪蟾、果蝇、海胆）几乎没有 G1/G2**：只有 **S ↔ M 交替**，靠母源 mRNA 与母源 cyclin 驱动；细胞**不生长、只越分越小**；到**中期囊胚转换（MBT）** 才加入 G1/G2 与合子转录。

### 2.6 实验判据

| 方法 | G1 表现 |
|---|---|
| 流式 PI（DNA 含量） | **2C 峰** |
| EdU / BrdU 掺入 | 阴性 |
| 标志蛋白 | Rb 低磷酸化、p27 高、cyclin E 低、MCM 已装载但无 PCNA 焦点 |
| 同步化 | **血清饥饿** → G0/G1；双胸苷阻断 → G1/S 边界 |

## 三、S 期（DNA 合成期）

### 3.1 核心事件

- **全基因组半保留复制，精确一次且仅一次**。
- DNA 含量 **2C → 4C**；**染色体数仍是 2N**，只是每条染色体从 1 条染色单体变成 **2 条姐妹染色单体**（由 **cohesin** 黏连）。
- 光镜下**看不到明显形态变化**，核膜、核仁都在，转录总体继续（但复制叉经过处局部受抑）。

### 3.2 起点发放与复制时序

| 要点 | 内容 |
|---|---|
| 起点数量 | 人类约 **3 万–5 万个**复制起点，成簇激活形成 **replication factory**（复制灶） |
| 时序 | **常染色质、活跃基因早复制**；异染色质、着丝粒、端粒、失活 X 染色体**晚复制** |
| 激活 | **CDK2–cyclin E/A** + **DDK（Cdc7–Dbf4）** → 组装 **CMG 解旋酶**（Cdc45–MCM2-7–GINS）→ 双向叉 |
| 一周期一次 | 许可在 G1、起始在 S，两个 CDK 状态互斥；Cdc6 出核/降解、Cdt1 被 geminin 抑制并由 CRL4^Cdt2 降解、ORC 磷酸化、MCM 随叉离开 |

### 3.3 与复制同步发生的四件事（容易被漏）

1. **组蛋白合成与核小体组装**：组蛋白基因无内含子、带 STEM-loop，由 **SLBP** 调控；新组蛋白经 **CAF-1 / ASF1** 沉积到子链，旧 H3-H4 四聚体随机分配。
2. **表观遗传信息复制**：**DNMT1** 识别半甲基化 CpG 补齐甲基化；组蛋白修饰由"读–写"酶（如 PRC2、SUV39H）在新生链上重建。
3. **中心体复制**：一轮且仅一轮，依赖 CDK2–cyclin E/A 与 **Plk4**（母中心粒上只长一个子中心粒）；G2 成熟，M 期形成两个纺锤体极。
4. **姐妹染色单体黏连建立**：cohesin 装载后由 **Eco1/Ctf7（ESCO1/2）** 乙酰化 Smc3 建立 cohesion —— **S 期建立，直到后期才被 separase 切开**。
5. **端粒复制**：末端复制问题与端粒酶（见 [[端粒与端粒酶]]）。

### 3.4 Intra-S 检查点（复制检查点）

- 主传感是 **ATR–Chk1**（不是 ATM–p53）：停滞叉暴露的 ssDNA 被 **RPA** 包被 → 招募 ATR-ATRIP → 激活 Chk1。
- 效应：① 抑制晚期起点发放；② **稳定停滞的复制叉**、防止坍塌成 DSB；③ 抑制 CDK1 防止带未复制完的 DNA 提前进 M；④ 上调 dNTP 供应（RNR）。
- 与 G1 检查点的区别：**G1 用 ATM–p53–p21 拦在复制前，intra-S 用 ATR–Chk1 护住正在复制的叉**。

### 3.5 实验判据

| 方法 | S 期表现 |
|---|---|
| 流式 PI | **2C 与 4C 之间**的连续分布 |
| **EdU / BrdU 掺入** | **阳性**（金标准） |
| 标志蛋白 | PCNA 焦点、MCM 与 CMG 结合、cyclin A 升高、磷酸化 RPA |
| DNA fiber assay | 测叉速、起点间距、叉对称性 |
| 同步化 / 阻断 | 双胸苷阻断（G1/S）、**羟基脲**（耗 dNTP）、**阿非迪霉素**（抑 Pol α） |

## 四、G2 期（DNA 合成后期 / 第二间隙期）

### 4.1 在做什么：质检 + 备料

| 类别 | 事件 |
|---|---|
| **质检** | 确认 DNA 已全部复制、修复残余损伤。**同源重组（HR）在 S/G2 最活跃**，因为有姐妹染色单体可作无误模板（G1 只能用易错的 NHEJ） |
| **备料** | 大量合成 M 期蛋白：**微管蛋白、cyclin B、Plk1、Aurora A/B、凝缩素**；储备 ATP |
| **中心体成熟** | 招募 γ-TuRC、pericentrin 等 PCM 组分，提高微管成核能力；两极开始分离 |
| **继续长大** | 细胞体积在 G2 达到最大 |

### 4.2 ★ MPF 蓄势但不放行（pre-MPF）

cyclin B 已积累充足 → 与 CDK1 结合，CAK 磷酸化 Thr161（激活位，已就绪）→ 但 Wee1 / Myt1 给 CDK1 加上 Thr14、Tyr15 抑制磷酸 → 形成 **pre-MPF**：蓄势待发、无活性 ★ → Cdc25C 被 Chk1 磷酸化（Ser216）后与 14-3-3 结合、滞留胞质。

> 所以 **G2 → M 不是靠 cyclin B 合成到位，而是靠 Cdc25 松开刹车**；正反馈（MPF 激活 Cdc25、抑制 Wee1，Plk1 助阵）让这一步成为全或无的双稳态开关。详见 [[MPF和各种周期调控相关蛋白]]。

### 4.3 G2/M 检查点

| 项目 | 内容 |
|---|---|
| 感知 | 未复制完的 DNA、未修复的损伤 |
| 传导 | ATM/ATR → **Chk1/Chk2** → 磷酸化 **Cdc25C（Ser216）** 使其失活 + 稳定 **Wee1** |
| 结果 | CDK1 保持 Thr14/Tyr15 磷酸化 → MPF 不激活 → **停在 G2** |
| 废除 | 咖啡因、**UCN-01**（Chk1 抑制剂）、**AZD1775**（Wee1 抑制剂）→ 带损伤强行入 M → **有丝分裂灾难** |
| 人为阻断 | **RO-3306**（CDK1 抑制剂）停在 G2/M 边界，洗脱后集体同步入 M |

### 4.4 时长与特例

- 通常 3–4 h，比 G1 稳定得多。
- **DNA 损伤时 G2 可显著延长**（放疗/化疗后常见的 "G2 阻滞" 表型），因为细胞在此做最后的修复尝试。
- 早期胚胎几乎无 G2；某些肿瘤因 G1 检查点缺陷而**特别依赖 G2/M 检查点**。

### 4.5 实验判据（⚠️ G2 与 M 都是 4C）

| 标志 | G2 | M |
|---|---|---|
| 流式 PI | **4C** | **4C**（分不开！） |
| EdU | 阴性 | 阴性 |
| **磷酸化 H3（Ser10）** | **阴性** | **阳性** ★ 关键判别 |
| CDK1 Tyr15 磷酸化 | **阳性**（pre-MPF） | 阴性（已活化） |
| cyclin B1 定位 | 胞质 | **入核** |
| 形态 | 核完整、染色质弥散 | **染色体凝缩**、核膜解体 |

> **实验坑**：只用 PI 染 DNA 会把 G2 和 M 混成一个 4C 峰。**必须加 p-H3(Ser10) 或看染色体形态**才能区分。

## 五、M 期（核分裂 + 胞质分裂）

M 期约 1 h，但包含 **5 个核分裂阶段 + 胞质分裂**。分子开关详见 [[MPF和各种周期调控相关蛋白]]，阻断剂详见 [[阻断]]。

![[mitosis-five-stages.svg]]

### 5.1 前期（Prophase）

| 事件 | 分子机制 |
|---|---|
| **染色体凝缩** | **condensin I/II**（SMC2/4）、拓扑异构酶 II、**组蛋白 H3 Ser10 磷酸化**（Aurora B） |
| **纺锤体雏形** | 中心体向两极移动（**Eg5 / kinesin-5** 推开），γ-TuRC 成核星状微管 |
| 核仁消失 | rRNA 转录停止，核仁蛋白弥散 |
| 高尔基 / ER 碎裂 | CDK1 磷酸化 GM130、GRASP65 |
| ★ **染色体臂 cohesin 移除** | **prophase pathway**：Plk1 / Wapl 移除染色体臂上大部分 cohesin；**着丝粒区 cohesin 由 Sgo1–PP2A 保护**留到后期 |

> 核膜此时**仍然完整** —— 核膜解体是下一阶段（前中期）的标志。

### 5.2 前中期（Prometaphase）

- **核膜解体（NEBD）**：CDK1 磷酸化 **lamin A/C/B** → 核纤层解聚；核孔复合体拆解；核膜碎成小泡。
- **动粒成熟 + 微管捕获**：两极微管以 "search-and-capture" 随机探索，捕获动粒形成 k-fiber。
- **错误连接纠正**：Aurora B 磷酸化动粒底物，使**无张力**的连接（syntelic / merotelic）解离重连；只有双向附着产生张力才稳定。
- **染色体向赤道板聚集（congression）**：CENP-E 沿微管运输 + 极排斥力（chromokinesin）平衡。
- **SAC 激活**：未附着动粒 → Mps1 → Mad2/BubR1/Bub3 → **MCC 抑制 APC/C^Cdc20** → 不许进后期。

### 5.3 中期（Metaphase）

- 所有染色体排列在**赤道板**，姐妹动粒**双向附着（amphitelic）**并产生张力。
- 染色体凝缩到最短最粗、形态最清晰 → **核型分析**用 **Colcemid / 秋水仙素**把细胞卡在这里（见 [[阻断]]、[[染色体带]]）。
- 纺锤体三类微管：动粒微管（牵拉）、极性微管（撑开两极）、星状微管（定位分裂面）。
- **SAC 沉默**：dynein 把 Mad1/Mad2 从动粒剥离、**p31^comet** 解离 MCC → **APC/C^Cdc20 活化**。

### 5.4 后期（Anaphase）

APC/C^Cdc20 泛素化 securin → 降解 → separase 释放活化 → 切 cohesin 的 Rad21/Scc1 → **姐妹染色单体分离** ★

| 阶段 | 机制 |
|---|---|
| **后期 A** | **动粒微管缩短**，染色体向两极移动（kinesin-13/MCAK 促解聚、dynein） |
| **后期 B** | **极性微管滑动伸长**（Eg5）、**星状微管被皮层 dynein 牵拉** → 两极进一步分开 |

> ★ **染色体数在后期短暂加倍**：姐妹单体一旦分离就各自成为独立染色体，整个细胞内暂时 **4N（人 92 条）**；但**细胞总 DNA 仍是 4C**，直到分裂完成，每个子细胞才回到 2N 2C。

### 5.5 末期（Telophase）

- **cyclin B 被 APC/C 降解 → CDK1 活性骤降**；**PP1 / PP2A** 把 MPF 底物去磷酸化。
- 染色体**去凝缩**、H3 Ser10 去磷酸化、condensin 解离。
- **核膜重建**：lamin 去磷酸化重新聚合，核孔复合体组装，膜泡围绕染色体融合（ESCRT-III 参与最终封闭）；核仁重现、rRNA 转录恢复。
- 高尔基 / ER 重组。
- **APC/C^Cdh1 接管**，降解 cyclin B、Plk1、Aurora A、Cdc20、geminin，把细胞锁进低 CDK 的 G1。

### 5.6 胞质分裂（Cytokinesis，与末期重叠）

| 步骤 | 机制 |
|---|---|
| 分裂面指定 | 中央纺锤体 **centralspindlin**（MKLP1 + CYK-4）与星状微管信号 → 赤道皮层局部激活 **RhoA** |
| 收缩环 | RhoA → ROCK、formin/mDia → **F-actin + myosin II** 聚合成环，收缩形成**分裂沟** |
| 中体与脱离 | 收缩至 **midbody** → **ESCRT-III / Vps4 / CEP55 / ALIX / TSG101** 执行 **abscission** |
| 安全监控 | **NoCut / Aurora B** 在存在染色质桥时延迟脱离，防止切断 DNA |
| **植物不同** | 无收缩环；由**成膜体（phragmoplast）** 引导高尔基囊泡在中央融合成**细胞板**，离心扩展 |
| 失败后果 | **双核 / 多核细胞**（细胞松弛素 B/D 抑肌动蛋白、blebbistatin 抑 myosin II），见 [[阻断]] |

### 5.7 M 期各阶段时长（哺乳动物培养细胞，参考值）

| 阶段 | 约时长 | 变异来源 |
|---|---|---|
| 前期 | 15–20 min | 凝缩速度 |
| 前中期 | 10–15 min | 动粒捕获效率 |
| **中期** | **10–20 min（变异最大）** | **SAC 何时满足** |
| 后期 | ~5 min | 相对恒定 |
| 末期 + 胞质分裂 | 20–30 min | 脱离时机 |
| **合计** | **约 1 h** | — |

## 六、★ DNA 含量与染色体数全周期表（最常考）

以人二倍体细胞（2N = 46）为例：

| 时相 | DNA 含量 | 染色体数 | 染色单体数 | 每条染色体含 DNA 分子 |
|---|---|---|---|---|
| **G1** | **2C** | 2N（46） | 46 | 1 |
| **S（进行中）** | 2C → 4C | 2N（46） | 46 → 92 | 1 → 2 |
| **G2** | **4C** | 2N（46） | 92 | 2 |
| 前期 / 前中期 / 中期 | 4C | 2N（46） | 92 | 2 |
| **后期**（姐妹单体分离后） | 4C | **4N（92，暂时）** | 92（各自成为染色体） | 1 |
| 末期 / 每个子细胞 | **2C** | 2N（46） | 46 | 1 |

> **一句话记牢**：
> - **S 期只变 C，不变 N**（DNA 加倍，染色体数不变，只是每条从 1 条单体变 2 条姐妹单体）
> - **后期只变 N，不变 C**（姐妹单体分开成为独立染色体，数目暂时加倍，但细胞总 DNA 没变）
> - **DNA 减半发生在"细胞分裂完成"，不是在后期**

## 七、间期 vs M 期

| 维度 | 间期（G1/S/G2） | M 期 |
|---|---|---|
| 时长占比 | **90%+** | ~5–10% |
| 染色质 | 弥散、可转录 | 高度凝缩、**转录基本停止** |
| 核膜 / 核仁 | 完整 | 解体（前中期–后期）/ 末期重建 |
| 微管骨架 | 间期网络（长、稳定） | 纺锤体（短、动态极高，半衰期 10–30 s） |
| DNA 代谢 | 复制、修复、转录活跃 | 复制与修复基本停止，只做分配 |
| CDK1 活性 | 低 | **峰值** |
| 光镜可见性 | 除核仁外几乎"没变化" | 染色体清晰可辨 |
| 主要风险 | 复制错误、突变 | 染色体错分离、非整倍体 |

## 八、特殊周期（不是所有细胞都走标准四时相）

| 类型 | 特点 |
|---|---|
| **早期胚胎卵裂** | 无 G1/G2，仅 S↔M 交替；母源 mRNA/cyclin 驱动；不生长、越分越小；**MBT** 后才加入 G1/G2 与合子转录 |
| **卵母细胞减数分裂** | 长期停滞在**减数第一次分裂前期**（人可达数十年）；排卵后停在 **MII**，由 **CSF** 维持，受精才解除 |
| **内复制（endoreduplication）** | 反复 S 期、跳过 M → **多倍体／多线染色体**：果蝇唾腺、植物胚乳、哺乳动物巨核细胞、肝细胞、胎盘滋养层 |
| **合胞体** | 核分裂不伴胞质分裂：果蝇早期胚胎、骨骼肌纤维、某些真菌 |
| **G0 退出** | 神经元/心肌（不可逆）、肝细胞/淋巴细胞（可逆） |
| **肿瘤细胞** | G1 检查点常因 p53 / Rb 通路缺陷失活 → 更依赖 S 与 G2/M 检查点 |

## 九、实验判据速查：怎么知道细胞在哪个期

| 方法 | G1 | S | G2 | M |
|---|---|---|---|---|
| **流式 PI（DNA 含量）** | 2C | 2C–4C | **4C** | **4C**（⚠️ 与 G2 分不开） |
| **EdU / BrdU** | − | **+** | − | − |
| **p-H3（Ser10）** | − | − | − | **+** ★ 区分 G2/M |
| CDK1 Tyr15 磷酸化 | − | − | **+**（pre-MPF） | − |
| cyclin B1 | 低 | 低 | 升高、胞质 | 高、**入核** |
| 形态 | 核完整 | 核完整 | 核完整 | 凝缩染色体 / 分裂沟 |
| 常用同步化 | 血清饥饿 | 双胸苷、羟基脲 | **RO-3306** | **Nocodazole + shake-off** |

> **两个实用提醒**：
> 1. **G2 与 M 都是 4C，单靠 PI 分不开** —— 要加 p-H3(Ser10) 或看染色体形态。
> 2. 做 M 期磷酸化研究优先 **RO-3306 洗脱同步释放**，比 Nocodazole 干净（无药物残留干扰）；详见 [[阻断]]。

## 十、常见误区澄清

| 误区 | 纠正 |
|---|---|
| ❌ "间期是休息期" | ✅ 代谢最活跃、占 90%+ 时间；"间隙"只是光镜下看不到染色体变化的历史命名 |
| ❌ "S 期染色体数加倍" | ✅ **只 DNA 加倍（2C→4C）**，染色体数仍 2N；每条变成 2 条姐妹染色单体 |
| ❌ "后期 DNA 含量减半" | ✅ 单个细胞总 DNA 仍 **4C**；分裂完成后每个子细胞才是 2C |
| ❌ "后期染色体数不变" | ✅ 姐妹单体分离后各自成为染色体，全细胞**暂时 4N** |
| ❌ "核膜在前期解体" | ✅ 严格在**前中期（NEBD）**；前期核膜仍完整 |
| ❌ "cohesin 一直留到后期才移除" | ✅ **染色体臂**上的大部分在**前期**就被 Plk1/Wapl 移除，只有**着丝粒区**由 Sgo1–PP2A 保护留到后期 |
| ❌ "胞质分裂属于末期" | ✅ 是**独立过程**，始于后期末、与末期重叠，由收缩环/ESCRT 执行 |
| ❌ "G2 和 M 可用流式 DNA 含量区分" | ✅ 都是 4C，必须加 **p-H3(Ser10)** 或形态判据 |
| ❌ "所有细胞都走 G1→S→G2→M" | ✅ 早期胚胎无 G1/G2、内复制无 M、G0 退出循环、减数分裂有两次连续分裂 |
| ❌ "G1/G2 只是等待时间" | ✅ G1 做**命运决策 + 复制许可**，G2 做**质检 + 备料 + HR 修复**，都是必需阶段 |
| ❌ "M 期最短所以最简单" | ✅ 形态变化最剧烈、检查点最密集、是多数抗肿瘤药的靶点 |

## 十一、要点速记

> **间期复制一份，M 期平分两份**
>
> 1. **G1**：长大 + **R 点决策** + **复制许可（装 MCM）**；p53–p21 把关；时长变异最大；可退入 G0
> 2. **S**：DNA **2C→4C**、N 不变；多起点时序复制；同步做组蛋白、表观修饰、中心体复制、**cohesin 黏连建立**；ATR–Chk1 护叉
> 3. **G2**：4C；HR 修复、M 期蛋白合成、中心体成熟；**pre-MPF 蓄势但被 Wee1 压住**；Chk1–Cdc25C 把关
> 4. **M**：前期凝缩 → 前中期 **NEBD + SAC** → 中期赤道板 → 后期 **separase 切 cohesin**（后期 A/B）→ 末期重建 → 胞质分裂（收缩环 / 中体）
> 5. **C 与 N 分开**：S 变 C 不变 N；后期变 N 不变 C；DNA 减半在分裂完成
> 6. **方向性**：进入 M 靠可逆去磷酸化，退出靠不可逆的 cyclin B 降解
> 7. **实验坑**：G2 与 M 都是 4C，靠 **p-H3(Ser10)** 区分
