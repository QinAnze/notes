## 🧩 知识点专题

按主题分组（每篇都是独立长文，可从上方「知识点」目录进入）：

| 主题 | 专题 |
|---|---|
| 膜与跨膜运输 | AQP、GLUT、膜电位、胆固醇对脂膜的调节、现象 |
| 内膜系统与分泌 | Bip、ERS、COP、单抗、动物细胞培养 |
| 能量转换 | 氧化磷酸化、电子传递链、ATP合酶 |
| 细胞骨架与运动 | MAP、踏车行为、细胞运动、鞭毛差异 |
| 核与基因表达 | 翻译、fish-trap、染色体带、端粒与端粒酶、表达类型 |
| 周期与分裂 | MPF和各种周期调控相关蛋白、细胞分裂时期的详述、有丝、减数、特殊Meiosis、极体的偏向性、阻断 |
| 分化与疾病 | Ca、革兰氏、快生长和慢生长 |
| 绪论拓展 | 细分、分裂方式、研究内容拓展 |
