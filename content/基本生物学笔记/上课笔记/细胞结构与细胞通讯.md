# 细胞结构与细胞通讯

> 📖 细胞是生命的基本单位。本章涵盖显微镜技术、细胞学说、原核/真核细胞比较、真核细胞的各种细胞器、生物膜、跨膜运输系统和细胞通信机制。

---

## 第一节 细胞概述

### 显微镜技术

| 显微镜类型 | 分辨力 | 用途 | 局限 |
|-----------|--------|------|------|
| **人眼** | 0.1mm | — | — |
| **光学显微镜** | 200nm（人眼的500倍） | 观察细胞基本结构 | 不能观察亚细胞结构 |
| **透射电镜（TEM）** | 0.2nm | 样本**内部**超微结构 | 不能观察活样本 |
| **扫描电镜（SEM）** | 0.2nm | 样本**表面**细微结构 | 不能观察活样本 |

### 细胞的发现历史

| 年份 | 科学家 | 贡献 |
|------|--------|------|
| **1665年** | 胡克（Robert Hooke） | 用显微镜观察软木，发现蜂窝状小格子，命名为"cell"（细胞） |
| **1676年** | 列文虎克（Antony van Leeuwenhoek） | 首次观察到细菌（只会荷兰语的业余科学家，1680年入选英国皇家学会） |
| **1838年** | 施莱登（Schleiden） | 发表论文《论植物发现》，指出细胞是一切植物结构的基本单位 |
| **1839年** | 施旺（Schwann） | 发表论文《动、植物结构与生长相似性的显微研究》，指出动物组织基本单位都是细胞 |
| **1858年** | 魏尔肖（Virchow） | 提出"细胞只能由业已存在的细胞经分裂而产生"，完善细胞学说 |

### 细胞学说（Cell Theory）

1. **细胞是有机体**，是所有动、植物的基本结构单位
2. 每个细胞**相对独立**，一个生物体细胞之间协同配合
3. **新细胞由老细胞繁殖产生**（魏尔肖补充）

> 💡 细胞是生命活动的基本单位，除病毒外，一切生物都是由细胞构成的。

### 细胞的大小与形态

| 数据 | 说明 |
|------|------|
| 最小的细胞 | **支原体**，直径仅100nm |
| 最大的细胞 | **鸟卵**（鸵鸟蛋黄最大），肉眼可见 |
| 动植物细胞 | 20~30μm |
| 真核细胞体积 | 大于原核细胞 |
| 卵细胞 | 大于体细胞 |

**细胞小的原因**：
1. 受**细胞核所能控制范围**的制约（表面积/体积比）
2. 有利于**物质交换和转运**（相对表面积大）

> [!warning] 易错点：细胞大小的三个易混数字
> - **"最大细胞"是人卵细胞，不是鸵鸟蛋**。鸵鸟蛋**是卵，不是细胞** ——
>   蛋黄才是细胞（严格说鸟类的"卵细胞"是不太恰当的说法，鸟类卵是**羊膜卵**，
>   里面才有卵细胞）。考试问"最大的细胞"，答**人卵细胞（直径约 130 μm）**。
> - **"最小细胞"是支原体（Mycoplasma）**，不是病毒。支原体直径约 100 nm，
>   而病毒一般 20–300 nm 但**没有细胞结构**，压根不算细胞。
> - **"细胞体积恒定定律"**指多数细胞**线性尺寸集中在 10~100 μm**，
>   不是"所有细胞都一样大"。

### 各类细胞举例

| 细胞类型 | 特点 |
|---------|------|
| **草履虫** | 形似草鞋，纤毛为运动胞器，螺旋形游泳 |
| **植物气孔保卫细胞** | 气孔开闭与保卫细胞水势有关：水势下降→吸水膨胀→气孔张开 |
| **人类成熟红细胞** | 双凹圆盘状（表面积大，利于O₂运输）；无核、无细胞器（代谢率低，利于气体运输） |
| **巨噬细胞** | 表面皱褶和微绒毛，大量溶酶体 |
| **神经元** | 电可激发细胞，通过突触与其他细胞通信 |
| **酵母细胞** | 真菌，用于发酵研究 |

## 第二节 两类细胞：原核细胞与真核细胞

### 比较表

| 特征 | 原核细胞 | 真核细胞 |
|------|---------|---------|
| **大小** | 1~10μm | 3~100μm |
| **细胞核** | 无真正细胞核 | 有核膜、核仁、核质 |
| **细胞膜** | 有 | 有 |
| **细胞器** | 无以膜为基础的细胞器 | 有多种细胞器 |
| **细胞壁** | 多数有 | 植物和真菌有 |
| **核糖体** | 70S型（30S+50S） | 80S型（40S+60S） |
| **染色体** | 裸露DNA，无组蛋白 | DNA与组蛋白结合 |
| **DNA** | 环状，细胞质中 | 线状，细胞核中 |
| **核外DNA** | 质粒 | 线粒体与叶绿体DNA |
| **RNA与蛋白** | RNA无内含子，转录在细胞质 | RNA有内含子，转录在细胞核 |
| **细胞骨架** | 无 | 有 |
| **细胞分裂** | 二分分裂 | 有丝分裂、减数分裂 |
| **组织** | 主要是单细胞生物 | 多数多细胞，形成组织 |

### 动物细胞 vs 植物细胞

| 特征 | 动物细胞 | 植物细胞 |
|------|---------|---------|
| **细胞壁** | 无 | 有 |
| **叶绿体** | 无 | 有 |
| **大中央液泡** | 无 | 有 |
| **溶酶体** | 有 | 无 |
| **乙醛酸循环体** | 无 | 有 |
| **通讯连接** | 间隙连接等 | 胞间连丝 |
| **中心体** | 有 | 无 |
| **胞质分裂** | 收缩环 | 细胞板 |

### 原核生物类群

| 类群 | 特点 |
|------|------|
| **支原体** | 最小最简单的细胞（0.1~0.3μm），仅为细菌的十分之一；寄生在细胞内繁殖 |
| **细菌** | 大肠杆菌等；环状DNA |
| **蓝藻（蓝细菌）** | 光合作用类似高等植物；无叶绿体但有质膜内陷形成的捕光装置；直径10μm，颤藻可达70μm；有些以丝状群体存在（发菜）；繁殖快，大量消耗水中溶氧 |

> [!example] 生工联系：原核细胞 = 合成生物学的三大优势底盘
> 原核细胞没有核膜包被的细胞核、没有内质网/高尔基体，但**这恰恰是工程上的优点**：
>
> 1. **质粒可自主复制**，不依赖宿主染色体复制时序 → 拷贝数能拉到几十上百份
> 2. **无内含子**，基因组小、遗传背景干净 → 基因改造路径短，插入位点不干扰剪接
> 3. **培养快、传代快**，一个批次几十小时 → 迭代验证快
>
> 代价也明确：**无真核翻译后修饰系统（糖基化）**、**无细胞骨架支持胞内定位**、
> **无法分泌大分子（除非用 Sec/Tat 信号肽，见下文内质网）**。
> 所以"能不能用大肠杆菌"要按目标产物判断（见[[普通生物学绪论#三域特征]]）。

> [!warning] 易错点：原核 vs 真核的三个经典陷阱
> - **"细菌无线粒体"不等于"细菌无细胞器"**。细菌有**核糖体**（70S），
>   还有特化的膜内陷结构如**拟线粒体（bacteroids）、捕光装置**、
>   **磁小体（磁细菌）**。核糖体是细胞器。
> - **"细菌无染色体"是错的**。支原体和细菌的染色体是**环状 DNA**，
>   裸奔、没有核膜包被、**不与组蛋白结合** —— 这才叫"无典型染色体"。
> - **拟核（nucleoid）不是一个有膜的区室**，是细胞内 DNA 集中的区域，
>   没有膜边界。"没有细胞核"≠"没有核区"。

## 第三节 真核细胞的结构

真核细胞的三大系统：
1. 以脂质及蛋白质成分为基础的**生物膜结构系统**
2. 以核酸与蛋白质为主要成分的**遗传信息表达系统**
3. 由特异蛋白分子装配构成的**细胞骨架系统**

### 3.2.1 细胞核 — 控制中心

#### 细胞核的组成

| 结构 | 说明 |
|------|------|
| **核被膜** | 双层膜，具核孔 |
| **核基质（核液）** | 蛋白质纤维网络，染色质附着场所 |
| **染色质** | DNA和蛋白质（组蛋白） |
| **核仁** | 富含蛋白质和RNA，核糖体装配场所（1-2个） |

#### 核被膜

**组成**：外核膜 + 内核膜 + 核周腔 + 核孔

**关键数据**：
- 单层膜厚7-8nm
- 核周腔宽10-50nm
- 外膜常与糙面内质网相连，附着核糖体

**功能**：
- 构成核质间的天然选择性屏障
- 保护DNA不受细胞骨架运动产生的机械力损伤
- 核质间物质交换与信息交流
- 使DNA复制和RNA翻译在时空上分隔

**膜系统途径**：DNA（核）→ mRNA（核）→ 蛋白质（核糖体）→ 转运（内质网）→ 修饰（高尔基体）→ 分泌（质膜）

#### 核纤层

- 核膜内面，由核纤层蛋白组成的纤维状网架
- **功能**：结构支撑、调节基因表达、调节DNA修复、与细胞周期有关

**核被膜动态变化**：
- 前期：核纤层蛋白磷酸化 → 核膜解体为囊泡
- 末期：核纤层蛋白去磷酸化 → 囊泡融合 → 核膜重建

> 💡 **早老综合症（HGPS）**：LMNA基因突变→核纤层蛋白异常→加速衰老，平均寿命7-20年，不影响智力

#### 核孔复合体

- 直径50-100nm
- 数目：几千至上百万个
- **功能**：大分子出入核的主动转运

| 方向 | 物质 |
|------|------|
| **入核** | DNA聚合酶、RNA聚合酶、组蛋白、核糖体蛋白 |
| **出核** | 各种RNA、组装好的核糖体亚基 |

#### 染色质与染色体

> 染色质和染色体是细胞周期不同阶段可以互相转变的形态结构

| 类型 | 状态 | 转录活性 |
|------|------|---------|
| **常染色质（euchromatin）** | 细丝状，DNA展开 | 有转录活性 |
| **异染色质（heterochromatin）** | 深色团块，DNA紧缩盘绕 | 无转录活性 |

**染色质的组成**：
- **DNA**
- **蛋白质**：
  - 组蛋白（碱性，含精氨酸和赖氨酸）：H1、H2A、H2B、H3、H4 共5种
  - 非组蛋白（DNA聚合酶、RNA聚合酶等）
- 少量RNA

#### 染色质组装 — 从DNA到染色体

| 层次 | 结构 | 压缩比 |
|------|------|--------|
| 1 | DNA + 组蛋白八聚体 → **核小体**（直径10nm） | 7倍 |
| 2 | 核小体串珠 → **螺线管**（直径30nm，每圈6个核小体） | 6倍 |
| 3 | 螺线管 → **超螺线管**（直径0.4μm） | 40倍 |
| 4 | 超螺线管 → **染色单体**（长2-10μm） | 5倍 |

> **总压缩比：8400倍**。人体细胞46条染色体含DNA约6×10⁹bp。

> [!tip] 组蛋白的碱性从哪来
> 组蛋白富含**赖氨酸（Lys）和精氨酸（Arg）**，这两个氨基酸的侧链都是**碱性带正电**，
> 所以组蛋白整体带**正电**，才能和带负电的**磷酸骨架**结合。
> 反过来想：DNA 是负电的 → 组蛋白必然是正电的，这就是"组蛋白是碱性蛋白"的由来。
> （顺带解释了为什么组蛋白的**赖氨酸残基可以乙酰化** —— 乙酰化会中和正电荷，
> 削弱与 DNA 的结合，让染色质松开，**这就是表观遗传的"组蛋白密码"**。）

**核小体结构**：
- 核心：4对组蛋白（H2A、H2B、H3、H4各2个），直径10nm
- H1组蛋白：核小体外侧，稳定核小体
- 连接体DNA（linker DNA）：连接核小体
- 一个核小体：146bp + 连接体DNA ≈ 200碱基对

> [!warning] 易错点：染色质层级与核小体数字
> - **"染色质和染色体是同一种物质的不同状态"** —— 不是两种物质，
>   是同一套 DNA-蛋白在**细胞周期不同阶段**的两种形态。这句是送分题的判分点。
> - **组蛋白共 5 种，但一个核小体核心只有 8 个组蛋白分子**（H2A、H2B、H3、H4 **各 2 个**）。
>   H1 **不在核心**，它在外侧连连接体 DNA。常见错误是"H1 也算进八聚体"。
> - **压缩比 8400 倍是四层的乘积**（7×6×40×5）。别写成相加。
> - **常染色质"有转录活性"**、**异染色质"无"**，是"一般情况"；
>   例外是**异染色质中的转录活跃区（.Active gene chromatin）**，答题时可以说"多数"更稳妥。

#### 染色体

- 由两条相同的**姐妹染色单体**构成，以**着丝粒（centromere）**相连
- 着丝粒将染色体分成长臂和短臂
- **着丝点（动粒）**：着丝粒外面的蛋白质板状结构，纺锤丝插入点
- 二倍体（2n）：体细胞有2组同样的染色体（人：23对，46个）
- 单倍体（n）：配子只有1组染色体

**染色体数目**：人46、果蝇8、猫38、狗78、小麦42

**端粒（telomere）**：
- 染色体末端的特化DNA-蛋白质复合体
- 富含G的重复序列（四膜虫：(T₂G₄)ₙ；哺乳类：(TTAGGG)ₙ，重复500-3000次）
- 功能：保持染色体完整性（完整复制、不被降解、不相互黏连）
- **端粒酶**：在造血细胞、干细胞、生殖细胞、癌细胞中有活性（2009年诺贝尔奖）
- **X染色体失活**：雌性哺乳动物一条X染色体→异染色质→巴氏小体（人胚胎16天出现）

#### 核仁

- 圆形或椭圆形，无外膜
- 富含蛋白质和RNA（rRNA）
- **功能**：转录rRNA和组装核糖体亚单位
- 蛋白质合成多的细胞→核仁较大→核糖体较多

### 3.2.2 细胞质与细胞器

#### 内质网（ER）

- 细胞质内囊腔和细管，彼此相通，与核周腔相通
- 占细胞总膜面积的一半

| 类型 | 形态 | 功能 |
|------|------|------|
| **光面内质网（SER）** | 分支管状/小泡状，无核糖体 | 脂类/类固醇激素合成；肝解毒；葡萄糖释放（G-6P→G）；肌细胞贮存Ca²⁺ |
| **糙面内质网（RER）** | 富有核糖体颗粒 | 合成并转运蛋白质 |

**糙面内质网合成的蛋白质类型**：
- 向细胞外分泌的蛋白（抗体、激素）
- 膜蛋白
- 需与其他组分分开的酶（溶酶体水解酶）
- 需修饰的蛋白（糖蛋白）

> [!example] 生工联系：内质网 = 蛋白表达产线的第一道工序
> **大肠杆菌没有 ER**，所以重组蛋白全都留在**胞质**里表达 →
> ① 容易形成**包涵体（inclusion body）**，不溶、无活性；
> ② 无法做糖基化等翻译后修饰 → 工业上用大肠杆菌做重组蛋白时，
> 几乎只用**不含糖基化需求的**产品（如胰岛素原、生长激素、酶制剂）。
>
> **想让蛋白分泌到细胞外**，要给基因加**信号肽（signal peptide）**，路线有两条：
> - **Sec 通路**：N 端信号肽（如 pelB、ompA）→ 被 Sec 通道转位到**周质空间**，
>   再由外膜孔蛋白放出
> - **Tat 通路**：双精氨酸基序 → 直接转运到**周质**，适合已折叠的三聚体蛋白
>
> 大规模培养里，"**信号肽 + 胞内表达 vs 周质表达**"是一个经典权衡：
> 周质表达便于纯化（不用破壁、少处理核酸内毒素），
> 但胞外蛋白酶会降解产物，得用缺失株或换宿主来压住蛋白酶。

#### 核糖体

- 细胞合成蛋白质的场所
- 主要成分：rRNA（50~60%）+ 蛋白质（40~50%）
- 原核：70S（30S+50S）；真核：80S（40S+60S）
- 游离态和结合态结构相同

> [!warning] 易错点：核糖体那些数字别记混
> - **S（Svedberg）是沉降系数，不是加法！** 70S **≠** 50S + 30S（那叫亚基组成）。
>   S 值取决于沉降速度，与大小和形状都有关。
> - **亚基组合**：原核 70S = **50S（大亚基）+ 30S（小亚基）**；
>   真核 80S = **60S（大）+ 40S（小）**。记"大的在前"就不容易颠倒。
> - **线粒体、叶绿体里的核糖体也是 70S / 77S**，接近细菌型——
>   所以**抗生素能选择性打细菌**（链霉素/四环素作用于 30S，氯霉素/红霉素作用于 50S），
>   但也因此**抗生素对线粒体有副作用**。
> - **游离核糖体 vs 附着核糖体：合成蛋白的种类不同，但核糖体本身结构完全相同** ——
>   这是最经典的一句送分话，别为了区分功能就说"结构不同"。

#### 高尔基体

- 1898年由意大利科学家Golgi发现
- 数个扁平囊泡堆叠，高度有极性

| 区域 | 说明 |
|------|------|
| **形成面（顺面/cis）** | 凸出，面向内质网 |
| **成熟面（反面/trans）** | 凹进，面向质膜 |
| **中间膜囊** | 糖基修饰、糖脂形成 |

**功能**：
- 蛋白质加工、分类、包装 → 特定部位或分泌到细胞外
- 多糖合成
- 植物细胞壁形成（纤维素和果胶）
- 膜泡运输枢纽

#### 溶酶体

- 单层膜小泡，由高尔基体断裂产生
- 含60种以上**水解酶**
- pH 5.0（酸性），酶在酸性环境有活性

| 类型 | 特点 |
|------|------|
| **初级溶酶体** | 刚从高尔基体形成，含酶无底物 |
| **次级溶酶体** | 与底物融合 |
| - 自噬溶酶体 | 底物内源性（自身衰老细胞器），"清道夫" |
| - 异噬溶酶体 | 底物外源性（胞吞/胞饮摄入） |
| **残余小体（后溶酶体）** | 消化后不可降解的残渣 |

**功能**：清除无用生物大分子和衰老细胞器；防御（巨噬细胞吞噬病原体）

#### 液泡

- 植物细胞单层膜囊泡，充满细胞液
- 发育：多个小液泡 → 一个大液泡（5% → 95%）
- **功能**：调节细胞渗透压、收集代谢废物、花青素决定花果叶颜色

#### 线粒体

- 细胞呼吸并产生ATP的重要场所
- 形态：粒状/杆状，横径0.2~1μm，长1~2μm，1到几百/千个
- 肝细胞约1300个，占细胞体积20%
- 人类红细胞无线粒体，鸟类红细胞有

**结构**：

| 结构 | 特点 |
|------|------|
| **外膜** | 含孔蛋白（porin） |
| **内膜** | 向内折叠形成**嵴** |
| **膜间隙** | 无定形液体 |
| **基质** | 蛋白质性液态物质 |

> 💡 线粒体是细胞的**"动力工厂"**，通过氧化磷酸化将糖类/脂肪中的化学能→ATP

**半自主性**：
- 有自己的环状DNA、RNA、核糖体、DNA/RNA聚合酶
- 能编码合成13种多肽
- 但大多数蛋白质由核DNA编码 → 受两套遗传系统控制

> [!warning] 易错点：线粒体那几个数字
> - **人类成熟红细胞无线粒体**（且无核），因为没有线粒体就不能有氧呼吸、
>   不能维持自身膜结构的更新；但它靠糖酵解能活。**鸟类红细胞是有线粒体的**，
>   所以"哺乳动物成熟红细胞"这个限定词不能省。
> - **叶绿体数量 20~2025 这个范围很宽**是因为细胞类型差异大；
>   但别把叶绿体和线粒体的数目记混 —— 一般规律是**线粒体远多于叶绿体**。
> - **"半自主性"的准确含义**：能自我复制、编码部分蛋白，
>   但**大部分蛋白仍由核基因编码、再运进来**。所以"半自主"≠"独立"。
> - **线粒体 DNA 是环状、高拷贝、多拷贝**（每个线粒体多份），
>   且**几乎全部由母系遗传** —— 这是 mtDNA 检测能追溯母系谱系的原因。

> [!example] 生工联系：半自主性是"细胞器改造"的入口
> 因为细胞器自带一套基因组，理论上可以做**跨细胞器的基因组移植**，
> 把某个基因从染色体搬到细胞器基因组上表达。目前的进展是：
> - **异源表达叶绿体基因组**：把转基因直接整合进**叶绿体基因组**，
>   一个细胞里能出现**几百个拷贝**，表达量远高于染色体位点，
>   而且**不经过花粉传播**，对转基因生物安全有额外意义（不能通过花粉扩散）。
> - **工程酵母的线粒体呼吸链改造**：提高乙醇耐性、改造呼吸代谢流。

#### 叶绿体

- 植物和藻类含有，光合作用场所
- 形态：透镜状，长径5~10μm，短径2~4μm，厚2~3μm
- 叶肉细胞含20~2025个，占细胞质40%
- 分布与光照有关（照光侧/黑暗→内部）

**结构**：
- 3种膜：外膜、内膜、**类囊体膜**
- 3种腔：膜间隙、基质、类囊体腔
- 类囊体：基粒类囊体 + 基质类囊体（含光合色素和电子传递体）

**功能**：
- 光反应（类囊体膜）+ 暗反应（基质）
- 也是半自主性细胞器（有环状DNA、核糖体）

#### 质体

| 类型 | 存在 | 功能 |
|------|------|------|
| **白色体** | 分生组织/不见光细胞 | 含淀粉、蛋白质或油脂 |
| **有色体** | 果实/花/秋叶 | 类胡萝卜素、番茄红素 |
| **叶绿体** | 光合细胞 | 光合作用 |

#### 微体

| 类型 | 存在 | 功能 |
|------|------|------|
| **过氧化物酶体** | 动植物都有 | 氧化酶氧化脂肪酸（20%在此氧化）；过氧化氢酶分解H₂O₂；25%酒精被氧化 |
| **乙醛酸循环体** | 仅植物 | 乙醇酸→乙醛酸+H₂O₂；萌发种子中脂类→糖 |

### 3.2.3 细胞骨架

| 类型 | 直径 | 组成 | 功能 |
|------|------|------|------|
| **微管** | 外径25nm，内径15nm | α/β微管蛋白二聚体→13条原纤维 | 确定膜性细胞器位置；膜泡运输导轨；鞭毛/纤毛；染色体运动 |
| **微丝** | 7nm | 肌动蛋白（两串右手螺旋） | 维持细胞形态；细胞分裂（收缩环）；肌肉收缩；变形运动；胞质环流 |
| **中间纤维** | 8-10nm | 多种蛋白（角蛋白、波形蛋白等） | 最稳定骨架；张力和抗剪切力；核纤层支撑 |

**微管相关**：
- 中心体发出纺锤体微管
- 马达蛋白：**驱动蛋白（kinesin）**和**动力蛋白（dynein）**介导物质运输
- 鞭毛/纤毛："9+2"微管排列（少而长=鞭毛，多而短=纤毛）

**微丝相关**：
- 细胞松弛素B（使肌动蛋白解聚）
- 鬼笔环肽（防止解聚）

**中间纤维类型**：
- 角蛋白：上皮细胞
- 波形蛋白：成纤维细胞
- 层粘连蛋白：上皮组织基膜

> [!warning] 易错点：中间纤维那一栏
> - **波形蛋白属于中间纤维，不是微丝**。微丝是**肌动蛋白**。
> - **层粘连蛋白（laminin）严格说不是中间纤维蛋白**，它是细胞外基质的糖蛋白
>   （基底膜的主要成分），常被混进这张表。表里写的应是"中间纤维类型"，
>    laminin 更适合归到[[细胞外基质（ECM）]]那一节。
> - **中间纤维最稳定、不参与胞质环流**（微丝和微管才参与）。
>   所谓"细胞骨架三大系统里谁最稳定"，答案就是中间纤维。

## 第四节 生物膜 — 流动镶嵌模型

### 主要成分

- **磷脂双分子层**（基本支架）
- 蛋白质（镶嵌在脂双层中）
- 糖类（糖蛋白、糖脂）

### 磷脂分子

- 由甘油构成的磷脂称为**甘油磷脂**
- 由神经鞘氨醇构成的称为**鞘磷脂**
- 亲水头（磷酸基团+胆碱）+ 疏水尾（两条脂肪酸链）

### 流动镶嵌模型（Singer & Nicolson, 1972）

- 磷脂分子以疏水尾部相对，极性头朝向水相
- 蛋白质嵌在脂双层表面/内部/横跨整个膜
- 突出了膜的**流动性和不对称性**

### 膜的流动性

- 生理状态下膜脂处于**液晶态**（液态流动性+固态有序性）
- 运动方式：侧向扩散、旋转、摆动、伸缩震荡、翻转、旋转异构化
- 温度降低→流动性减小→固化
- **胆固醇**作用：限制磷脂移动→降低流动性；阻碍紧密排列→降低固化温度
- 不饱和脂肪酸多→固化温度低（冬小麦适应寒冷）

### 膜的镶嵌性

- **内在膜蛋白**：穿过脂双层疏水核心，疏水区（非极性氨基酸α螺旋）
- **外在膜蛋白（膜周边蛋白）**：不埋在脂双层中，疏松结合
- 不同膜蛋白质含量：线粒体内膜75%、质膜50%、髓鞘膜25%

**膜蛋白功能**：
1. 物质运输（载体）
2. 酶催化
3. 受体（激素结合）
4. 细胞识别（表面抗原HLA）
5. 细胞骨架附着点

> [!warning] 易错点：流动镶嵌模型的四个点
> - **"流动镶嵌"里的"流动"指膜脂和多数膜蛋白可侧向移动**，
>   但**锚定蛋白、细胞骨架连接蛋白、跨膜受体在特定细胞里是固定不动的**。
>   所以"膜蛋白都能自由流动"是错的。经典反例：
>   **细胞融合实验（人-鼠细胞融合后，膜蛋白先混合、膜脂完全混合）** 就是证明流动性的实验。
> - **不对称性**：膜的内外面不同 —— 外侧有糖萼、内侧有细胞骨架和膜锚定蛋白。
>   这保证了细胞运输的方向性。
> - **胆固醇是"双向调节"**：高温时限制磷脂运动防止过度流动，
>   低温时阻碍紧密排列防止固化。所以它叫**流动性缓冲剂**，
>   别说成"胆固醇降低膜流动性"（只对了一半）。
> - **膜蛋白含量：线粒体内膜 75%**（因为要放电子传递链和 ATP 合酶，
>   蛋白含量极高），**髓鞘膜 25%**（几乎全是脂质，只做绝缘）。

> [!example] 生工联系：流动镶嵌 + 脂双层 = 递送技术的地基
> 脂双层能**自发形成封闭囊泡（LNP）**，且天然可被细胞内吞 ——
> 这就是 **LNP（脂质纳米颗粒）** 能把 mRNA 递送进细胞的原因。
> mRNA 疫苗、siRNA 药物、基因治疗递送，都在用同一套原理：
> **亲水头朝外、疏水尾朝内包住核酸**。所以"磷脂双分子层"这节课的内容，
> 构成了现代核酸药物工业的物理基础（见[[生命的化学基础#DNA双螺旋结构特点]]）。

### 膜糖与细胞识别

- **糖蛋白**：与膜蛋白结合的糖
- **糖脂**：与脂质结合的糖
- 成分：半乳糖、甘露糖、唾液酸等
- **糖萼（glycocalyx）**：细胞外表面寡糖链+蛋白质构成的糖被
- 细胞识别关键在于识别细胞表面的**糖分子**

## 细胞连接（动物细胞）

| 类型 | 结构 | 功能 | 实例 |
|------|------|------|------|
| **锚定连接** | 纽扣状斑块+中间丝 | 牢固连接 | 皮肤/子宫颈上皮 |
| **封闭连接** | 细胞膜紧密靠拢无缝隙 | 阻止物质通过 | 脑血管/肠壁上皮 |
| **通信连接** | 间隙连接（2-3nm通道） | 小分子通过（cAMP等） | 大多数相邻细胞 |

**植物细胞连接**：**胞间连丝**（穿过细胞壁的细胞质通道）

### 细胞外基质（ECM）
- 分布于细胞外空间，由蛋白质和多糖构成网络
- 成分：胶原纤维、蛋白聚糖、纤连蛋白、整联蛋白
- 功能：物理支撑、信号传导、增殖/分化/迁移/修复

## 第五节 物质的跨膜运输

### 被动运输（passive transport）

| 类型 | 特点 | 机制 |
|------|------|------|
| **简单扩散** | 沿浓度梯度，不需能量，无蛋白协助 | O₂、CO₂等小分子直接穿过脂双层 |
| **协助扩散** | 转运速率高，特异性，饱和性 | 离子载体/通道蛋白 |

#### 膜转运蛋白

**载体蛋白（carrier proteins）**：
- 与被运输物质结合 → 构型变化 → 运输
- 高度特异性，可介导被动和主动运输

**通道蛋白（channel proteins）**：
- 亲水通道，被动运输
- 离子选择性，转运速率高
- **门控**：电压门、胞外配体门、胞内配体门、应力激活通道

### 主动运输（active transport）

**特点**：逆浓度梯度、需运输蛋白、需能量、选择性和特异性

| 泵类型 | 说明 |
|--------|------|
| **钠钾泵（Na⁺/K⁺-ATP酶）** | 4聚体（2大+2小亚基），P-type；每周期出3Na⁺、入2K⁺；依赖自磷酸化 |
| **钙泵（Ca²⁺-ATP酶）** | 维持胞内低钙（10⁻⁷M vs 胞外10⁻³M）；P-type每ATP泵出2Ca²⁺；肌质网钙泵占90% |
| **钠钙交换器** | 反向协同，Na⁺梯度驱动Ca²⁺外排 |
| **质子泵** | P-type（植物H⁺泵、胃酸H⁺/K⁺泵）；V-type（溶酶体/液泡）；F-type（ATP合酶） |

### 协同运输（cotransport）

- 间接消耗ATP，利用Na⁺或H⁺浓度梯度驱动
- **同向协同（symport）**：两种物质同方向运输
- **反向协同（antiport）**：两种物质反方向运输

> [!warning] 易错点：主动运输那一栏
> - **钠钾泵每消耗 1 个 ATP 出 3 个 Na⁺、进 2 个 K⁺** —— 3:2，
>   所以它**净带出 1 个正电荷**，是**生电性（electrogenic）**的，也是维持
>   静息电位和渗透压的根本。
> - **"钠钾泵"不是协助扩散，是主动运输**；而"钠钙交换器"是**反向协同**，
>   **不直接耗ATP**，靠钠梯度驱动 → 属于**间接消耗ATP**。
>   这一条最容易混：题目问"哪些不直接消耗ATP"时，答案里有交换器和协同转运。
> - **P-type / V-type / F-type 泵的区别**：P 型靠**自磷酸化**（钠钾泵、钙泵、植物 H⁺泵），
>   V 型靠 ATP 水解旋转（溶酶体/液泡的酸性化），F 型是 ATP 合酶反向工作。
> - **植物 H⁺ 泵（P 型）在根细胞膜上极重要** —— 它把 H⁺ 泵出，
>   建立膜电位和质子梯度，是**矿质离子主动吸收**的动力来源（见[[细胞代谢#主动运输]]相关）。

### 胞吞与胞吐

**胞吞（endocytosis）**：

| 形式 | 说明 |
|------|------|
| **吞噬作用** | 大颗粒（>250nm），专职吞噬细胞，→溶酶体降解 |
| **胞饮作用** | 液体/小溶质（<150nm） |
| **受体介导的胞吞** | 专一性强（如LDL胆固醇摄取） |

**胞吐（exocytosis）**：

| 途径 | 说明 |
|------|------|
| **组成性途径** | 分泌蛋白合成后立即包装→排出 |
| **调节性途径** | 分泌蛋白储存于囊泡，信号刺激后排出 |

**囊泡运输诺贝尔奖（2013）**：Rothman、Schekman、Südhof 发现囊泡运输调节机制

## 第六节 细胞通信

### 定义
一个细胞发出的信息通过介质（配体）→ 另一细胞受体 → 信号转导 → 生物学效应

### 信号通路

```
信号接收（受体）→ 信号转导 → 生物效应
```

### 受体类型

**细胞内受体**：
- 亲脂性信号分子（类固醇激素、甲状腺激素）
- 穿过膜 → 胞质受体结合 → 进入核 → DNA增强子区 → 基因转录

**细胞表面受体**：

| 类型 | 机制 |
|------|------|
| **离子通道偶联受体** | 信号→离子通道开放 |
| **G-蛋白偶联受体** | 7个α螺旋跨膜区；激活G蛋白→效应器→第二信使 |
| **酶偶联受体** | 受体本身有酶活性（如酪氨酸激酶受体） |

### 信号转导

- 蛋白构象变化（磷酸化级联）
- **蛋白激酶**：ATP磷酸化蛋白质（丝/苏氨酸）
- **蛋白磷酸酶**：去磷酸化

### 第二信使

| 第二信使 | 说明 |
|---------|------|
| **cAMP** | 最常见的第二信使；激活PKA（蛋白激酶A） |
| **cGMP** | 视觉信号传导 |
| **Ca²⁺** | 肌肉收缩、神经传递 |
| **DAG（二酰甘油）** | 激活PKC |
| **IP₃** | 内质网释放Ca²⁺ |
| **PIP₃** | PI3K/Akt通路 |

### cAMP信号通路

```
激素→受体→G蛋白→腺苷酸环化酶→cAMP→PKA（无活性→有活性）→磷酸化级联→生理效应
```

> [!warning] 易错点：受体分类与第二信使
> - **"第二信使"不包括蛋白激酶**。PKA 是**下游效应蛋白**，不是第二信使；
>   第二信使是小分子或离子：cAMP、cGMP、Ca²⁺、DAG、IP₃、PIP₃。
> - **Ca²⁺ 的来源要说清**：胞外内流**或**内质网/肌质网释放（由 IP₃ 触发）。
>   只写"胞外进入"是不完整的。
> - **蛋白激酶磷酸化的是"丝/苏氨酸"**（这是原核/真核蛋白激酶的常规底物；
>   **酪氨酸激酶是另一类**，如受体酪氨酸激酶 RTK —— 别混为一谈）。
> - **GPCR 的"7 个 α 螺旋跨膜区"是特征数字**，配合"G 蛋白 = GTP酶"
>   一起记：G 蛋白有** GTP 酶活性**，结合 GTP 时活化、水解为 GDP 时失活，
>   这就是"分子开关"。
> - **类固醇激素受体在胞内**，所以它的作用机制是**直接调控基因转录**（慢，
>   但持久）；而膜受体的第二信使通路**快但短暂**。答题说"快慢差异"是加分点。

> [!example] 生工联系：把"信号转导"装进底盘 —— 代谢工程的核心手段
> 代谢工程的两种经典策略，本质就是**改信号转导**：
> 1. **关闭**：敲除副产物通路的关键基因（竞争分走碳源）
>    —— 如* E. coli * 生产 L-赖氨酸时敲除**二氢dipicolinate合酶（dapA）分支**
>    阻断赖氨酸竞争赖氨酸同系物（dapA路径）把碳流抢回
> 2. **打开**：过表达限速酶 / 强化前体供给
>    —— 如过表达 **pyruvate carboxylase**、强表达前体合酶，把碳流压向目标
>
> 另一条更"细胞通讯"的路子是**群体感应（quorum sensing）**：
> 工程菌用 AHL 这类自诱导分子做"密度感应"开关，
> 到达高密度才启动目标基因表达（如产抗生素、毒力因子）。
> 生物合成里已经有 **autoinducer 类似物添加**做产量自控制的应用。
