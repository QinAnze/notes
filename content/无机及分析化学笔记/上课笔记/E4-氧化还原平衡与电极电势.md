# E4 氧化还原平衡与电极电势

> [[无机及分析化学-课程目录大纲|课程目录]] → 第二部分 化学平衡及其应用 → E4 氧化还原平衡与电极电势

## 1. 氧化还原反应与电极电势

### 氧化还原反应概述

**氧化还原反应**：有电子转移（或偏移）的反应。

- **氧化**：失去电子，氧化数升高
- **还原**：得到电子，氧化数降低
- **氧化剂**：使其他物质氧化，自身被还原
- **还原剂**：使其他物质还原，自身被氧化

**氧化还原反应的实质**：电子的转移。

**氧化还原半反应**：

$$氧化型 + ne^- \rightleftharpoons 还原型$$

例如：$Cu^{2+} + 2e^- \rightleftharpoons Cu$，$Zn^{2+} + 2e^- \rightleftharpoons Zn$

> 🔬 **生物工程应用**：生物体内的呼吸链是一系列氧化还原反应，电子从 $NADH$ 经复合体 I→III→IV 传递到 $O_2$，同时偶联 ATP 合成。细胞色素 c 氧化酶催化 $O_2$ 还原为 $H_2O$。

### 电极电势

**电极电势（$\varphi$）**：金属与其盐溶液之间产生的电势差。

**标准电极电势（$\varphi^\ominus$）**：在标准状态（各物质浓度为 $1\ mol/L$，气体分压为 $100\ kPa$，温度为 298.15 K）下的电极电势。

**标准氢电极（SHE）**：规定 $\varphi^\ominus(H^+/H_2) = 0.000\ V$

**电极电势的测定**：将待测电极与标准氢电极组成原电池，测量电动势。

$$E = \varphi_+ - \varphi_-$$

**标准电极电势表**（部分）：

| 电对 | 半反应 | $\varphi^\ominus$ (V) |
|------|--------|---------------------|
| $Li^+/Li$ | $Li^+ + e^- \rightleftharpoons Li$ | -3.040 |
| $Zn^{2+}/Zn$ | $Zn^{2+} + 2e^- \rightleftharpoons Zn$ | -0.762 |
| $Fe^{2+}/Fe$ | $Fe^{2+} + 2e^- \rightleftharpoons Fe$ | -0.447 |
| $H^+/H_2$ | $2H^+ + 2e^- \rightleftharpoons H_2$ | 0.000 |
| $Cu^{2+}/Cu$ | $Cu^{2+} + 2e^- \rightleftharpoons Cu$ | +0.342 |
| $I_2/I^-$ | $I_2 + 2e^- \rightleftharpoons 2I^-$ | +0.536 |
| $Fe^{3+}/Fe^{2+}$ | $Fe^{3+} + e^- \rightleftharpoons Fe^{2+}$ | +0.771 |
| $MnO_4^-/Mn^{2+}$ | $MnO_4^- + 8H^+ + 5e^- \rightleftharpoons Mn^{2+} + 4H_2O$ | +1.507 |
| $F_2/F^-$ | $F_2 + 2e^- \rightleftharpoons 2F^-$ | +2.866 |

**规律**：$\varphi^\ominus$ 越大，氧化型的氧化能力越强；$\varphi^\ominus$ 越小，还原型的还原能力越强。

> [!warning] 易错点：电极电势这一节
> - **比较氧化性/还原性必须看 $\varphi^\ominus$ 的大小规律，但前提是"同一类型反应"**。
>   $\mathrm{Cu^{2+}/Cu}$ 的 $\varphi^\ominus = +0.342$，
>   所以 $\mathrm{Cu^{2+}}$ 氧化性强、$\mathrm{Cu}$ 还原性强。
>   结论的口诀：**电势高的是氧化剂，电势低的是还原剂**（高价态/高电势容易被还原）。
> - **$\varphi$ 是电势（强度量），不能直接相加；$E$ 才是电动势（可加）**。
>   两个电势相加是错的 —— 但**电子转移数 $n$ 记得同时配上**，
>   算 $\Delta G = -nFE\Delta E$ 时 $n$ 是**总转移电子数**，不是半反应的。
> - **能斯特方程里 $n$ 是该半反应转移的电子数**，
>   配平电子数时漏乘或错乘是这节最常见的计算错误来源。
> - **"氧化剂得电子、还原剂得电子"记反**：氧化剂**得**电子被**还原**，
>   还原剂**失**电子被**氧化** —— 名字是"让别人怎么变"，
>   不是"自己怎么变"。这是最经典的送分错。

> [!example] 生工联系：把 $\varphi^\ominus$ 读懂生物代谢
> E4 的表在生物学里直接就是"谁能给电子、谁收电子"的能量阶梯。
> 拓展篇[[拓展-生物电化学与膜电位]]给了这套表在 pH 7 下的
> **生化标准电势 $\varphi^{\ominus'}$**（如 NAD⁺/NADH 为 −0.320 V，O₂/H₂O 为 +0.815 V），
> 呼吸链就是沿着"从 −0.320 一路升到 +0.815"这条梯度传电子，
> 每一步下降的电势差通过 [[拓展-生物电化学与膜电位#1. 生物氧化还原体系]] 换算成自由能。
>
> 这就是为什么**电势差越大、驱动力越大** —— 和你算电池电动势是同一个道理。

## 2. 影响电极电势的主要因素

### 能斯特方程

**能斯特方程**：描述电极电势与浓度（活度）、温度的关系。

对于半反应：$Ox + ne^- \rightleftharpoons Red$

$$\varphi = \varphi^\ominus + \frac{RT}{nF}\ln\frac{a_{Ox}}{a_{Red}}$$

25°C 时：

$$\varphi = \varphi^\ominus + \frac{0.0592}{n}\lg\frac{[Ox]}{[Red]}$$

其中：
- $R = 8.314\ J/(mol \cdot K)$（气体常数）
- $T$ 为热力学温度
- $F = 96485\ C/mol$（法拉第常数）
- $n$ 为转移电子数

**使用注意事项**：
1. 纯固体、纯液体的活度为 1
2. 气体用相对分压 $p/p^\ominus$ 表示
3. 包含 $H^+$ 或 $OH^-$ 的反应，酸度影响显著

**示例**：$MnO_4^- + 8H^+ + 5e^- \rightleftharpoons Mn^{2+} + 4H_2O$

$$\varphi = \varphi^\ominus + \frac{0.0592}{5}\lg\frac{[MnO_4^-][H^+]^8}{[Mn^{2+}]}$$

可见酸度对 $MnO_4^-/Mn^{2+}$ 电对的电极电势影响很大。

### 条件电极电势

**条件电极电势（$\varphi^{\ominus'}$）**：在特定实验条件下，校正了离子强度、酸效应、配位效应、沉淀效应等外界因素后的实际电极电势。

$$\varphi = \varphi^{\ominus'} + \frac{0.0592}{n}\lg\frac{c_{Ox}}{c_{Red}}$$

**引入条件电极电势的原因**：
1. 活度系数难以准确计算
2. 溶液中可能存在副反应（水解、配位、酸碱反应等）
3. 条件电极电势更能反映实际情况

> 🔬 **生物工程应用**：在生物电化学中，细胞膜电位可以用能斯特方程描述。神经细胞的静息电位约 -70 mV，主要由 $K^+$ 的跨膜分布决定：$\varphi = \frac{RT}{F}\ln\frac{[K^+]_{外}}{[K^+]_{内}}$。

## 3. 电极电势的应用

### 判断氧化还原反应的方向、次序和限度

**反应方向判断**：

$$E = \varphi_{氧化剂} - \varphi_{还原剂}$$

- $E > 0$：反应正向自发进行
- $E = 0$：反应达到平衡
- $E < 0$：反应逆向自发进行

**反应次序**：氧化剂优先与还原性最强的物质反应，还原剂优先与氧化性最强的物质反应。

**反应限度**：

$$\lg K = \frac{nE^\ominus}{0.0592} = \frac{n(\varphi_+^\ominus - \varphi_-^\ominus)}{0.0592}$$

$K$ 越大，反应进行得越完全。

### 计算有关平衡常数

**氧化还原反应的平衡常数**：

$$K = \frac{[Red_1]^{b}[Ox_2]^{d}}{[Ox_1]^{a}[Red_2]^{c}}$$

$$\lg K = \frac{n(\varphi_+^\ominus - \varphi_-^\ominus)}{0.0592}$$

**其他平衡常数**：
- 弱酸解离常数 $K_a$
- 溶度积 $K_{sp}$
- 配合物稳定常数 $K_f$

均可通过设计相应的氧化还原反应，测定电动势后计算。

### 元素电势图

**元素电势图**：将同一种元素不同氧化态的电极电势按氧化数由高到低排列的图。

例如，铁的元素电势图（酸性溶液）：

$$FeO_4^{2-} \xrightarrow{+2.20\ V} Fe^{3+} \xrightarrow{+0.771\ V} Fe^{2+} \xrightarrow{-0.447\ V} Fe$$

**应用**：
1. **判断中间氧化态能否歧化**：若 $\varphi_{右}^\ominus > \varphi_{左}^\ominus$，中间态能发生歧化反应
2. **计算标准电极电势**：

$$\varphi^\ominus = \frac{n_1\varphi_1^\ominus + n_2\varphi_2^\ominus + \cdots}{n_1 + n_2 + \cdots}$$

## 4. 氧化还原滴定法

### 对滴定反应的要求及被测组分的预处理

**对滴定反应的要求**：
1. 反应按确定的化学计量关系进行
2. 反应速率快
3. 有适当的方法指示终点
4. 平衡常数足够大（$K > 10^6$，即 $E^\ominus > 0.36\ V$）

**预处理**：
- **预氧化**：将待测组分氧化到特定价态（如 $Sn^{2+} \rightarrow Sn^{4+}$）
- **预还原**：将待测组分还原到特定价态（如 $Fe^{3+} \rightarrow Fe^{2+}$）
- 预处理要求：反应完全、过量试剂易除去、不引入干扰

### 氧化还原滴定曲线

以 $Ce^{4+}$ 滴定 $Fe^{2+}$ 为例：

$$Ce^{4+} + Fe^{2+} = Ce^{3+} + Fe^{3+}$$

**滴定曲线特征**：
- 滴定前：$\varphi$ 由 $Fe^{3+}/Fe^{2+}$ 电对决定（但 $Fe^{3+}$ 浓度很低，$\varphi$ 不确定）
- 化学计量点前：$\varphi$ 由 $Fe^{3+}/Fe^{2+}$ 电对决定
- 化学计量点：

$$\varphi_{sp} = \frac{n_1\varphi_1^\ominus + n_2\varphi_2^\ominus}{n_1 + n_2}$$

- 化学计量点后：$\varphi$ 由 $Ce^{4+}/Ce^{3+}$ 电对决定

**突跃范围**：$\varphi$ 从 $0.86\ V$ 突跃到 $1.26\ V$（对于上述反应）

### 氧化还原滴定中的指示剂

| 类型 | 原理 | 示例 |
|------|------|------|
| **自身指示剂** | 滴定剂本身有颜色 | $KMnO_4$（紫红色，终点时微红色出现） |
| **专属指示剂** | 与滴定产物产生颜色反应 | 淀粉（与 $I_2$ 形成蓝色配合物） |
| **氧化还原指示剂** | 指示剂的氧化型和还原型颜色不同 | 二苯胺磺酸钠、邻二氮菲亚铁 |

**氧化还原指示剂变色范围**：

$$\varphi = \varphi_{In}^\ominus \pm \frac{0.0592}{n}$$

### 常用氧化还原滴定方法

**（1）高锰酸钾法**：
- 滴定剂：$KMnO_4$
- 半反应：$MnO_4^- + 8H^+ + 5e^- = Mn^{2+} + 4H_2O$，$\varphi^\ominus = 1.507\ V$
- 条件：强酸性（$H_2SO_4$ 介质，不用 $HCl$ 和 $HNO_3$）
- 指示剂：自身指示剂（$MnO_4^-$ 微过量即显粉红色）
- 应用：测定 $Fe^{2+}$、$H_2O_2$、$Ca^{2+}$（间接法）等

**（2）重铬酸钾法**：
- 滴定剂：$K_2Cr_2O_7$
- 半反应：$Cr_2O_7^{2-} + 14H^+ + 6e^- = 2Cr^{3+} + 7H_2O$，$\varphi^\ominus = 1.33\ V$
- 条件：酸性介质
- 优点：标准溶液稳定、可长期保存
- 应用：测定 $Fe^{2+}$、土壤有机质含量等

**（3）碘量法**：
- **直接碘量法**：用 $I_2$ 标准溶液直接滴定还原性物质
  - 条件：中性或弱酸性
  - 指示剂：淀粉
  - 应用：测定 $SO_2$、维生素 C、硫化物等
- **间接碘量法**：利用 $I^-$ 的还原性，氧化剂将 $I^-$ 氧化为 $I_2$，再用 $Na_2S_2O_3$ 滴定生成的 $I_2$
  - 应用：测定 $Cu^{2+}$、$KMnO_4$、$H_2O_2$ 等

> 🔬 **生物工程应用**：
> - 高锰酸钾法测定 $H_2O_2$ 含量（过氧化氢酶活力测定）
> - 碘量法测定维生素 C 含量（食品分析）
> - 重铬酸钾法测定化学需氧量（COD），评价水质污染程度
> - 血糖检测仪基于葡萄糖氧化酶的氧化还原反应

### 滴定结果的计算

**等物质的量规则**：在滴定反应中，反应物之间基本单元的物质的量相等。

$$n_{待测物} = n_{标准溶液}$$

或根据化学计量关系：

$$a \cdot n_A = b \cdot n_B$$

其中 $a$、$b$ 为化学计量系数。

**含量计算**：

$$w = \frac{c_{标} \cdot V_{标} \cdot M_{待测}}{m_{试样}} \times 100\%$$
