# 科研配图：三条路 + 正确性闸门

**正确性优先于好看。** 下面三条路都过同一道闸门。

| 路线 | 什么时候选 | 产物 |
|---|---|---|
| **A · 内联 SVG** | 示意图（机理、流程、构象、能量高低） | 写进 `.md`，跟随主题 |
| **B · matplotlib 出图** | **有真实数据**、需要坐标轴的定量图 | `.svg`（优先）或 `.png` |
| **C · 权威机构现成图** | 画不出定量图、且需要真图/真显微图 | 下载到 `图片保存/`，`![[x.png]]` |

**选哪条先问一句**：这张图是**示意图**还是**定量图**？
示意图 → A（或 B 的「示意模式」）；定量图 → **必须真有数据**才能画，没有数据就只能去 C 找真的。

---

## ⛔ 正确性闸门（三条路通用）

1. **不凭空造数据。** 画曲线的每个点都要能指回笔记正文、表格或教材给的具体数值；
   出图时在图注写明数据出处。
2. **没有数值就别画「定量」的图。** 只有定性关系时，画成**示意图**：
   曲线用虚线/浅色，图注明写「示意，非按比例」——
   **一条平滑曲线会暗示不存在的定量精度**，那是误导。
3. **外部图必须说清来源和许可。** 说不清 → 不用。
4. **图上的符号/单位/方向必须和正文一致。** 图和文字打架时，改图，不改文字的物理含义。
5. **任何图都要在图注里交代来历**（自绘 / 数据出处 / 机构 + 许可）。

### B.2 适合画什么

| 图 | 需要的数据 |
|---|---|
| 能量剖面 | 各步的活化能/中间体相对能量（有数值才画） |
| 分布分数 δ–pH | pKa（笔记里通常有表） |
| 滴定曲线 / 缓冲容量 | Ka、浓度 |
| 速率–温度 / Arrhenius | 活化能 Ea、温度区间 |
| 级数曲线（连续对数） | K、n |
| 极化曲线 | 电化学数据 |
| 光谱示意 | ⚠️ 无真实数据时必须标「示意」 |

### B.3 ⚠️ 四个必踩的坑

1. **中文变豆腐块 □□□** —— matplotlib 默认字体不含中文。必须显式配：
   ```python
   import matplotlib
   matplotlib.rcParams["font.sans-serif"] = ["Noto Sans CJK SC", "Source Han Sans SC", "WenQuanYi Zen Hei", "DejaVu Sans"]
   matplotlib.rcParams["axes.unicode_minus"] = False   # 否则负号变成方块
   ```
2. **暗色模式下隐形** —— 最容易犯。背景别用「透明 + 深色文字」。
   两个可行方案：
   - **浅色卡片**（推荐）：`facecolor="#fbfbfb"`，配一条 `1px` 边框，两种主题下都成立；
   - **真透明 + 中灰线条**（`color="#7a7a7a"`，文字 `#555`），light/dark 都能读但观感一般。
     ❌ 透明 + `#000` 文字 = 暗色模式下整张图看不见。
3. **图里的字比正文小** —— dpi 不够 / figsize 太扁。`dpi ≥ 150`（Retina 用 200），
   图内字号 ≥ 11pt，线宽 ≥ 1.5。
4. **坐标轴没单位** —— `能量 / kJ·mol⁻¹`、`log[K]`、`log(δ)` 必须写全。

### B.4 模板（直接改）

```python
# 存成 scripts/plot_xxx.py，输出到 content/<课程>/图片保存/
import matplotlib
matplotlib.use("Agg")                      # 无显示器环境必须
import matplotlib.pyplot as plt

matplotlib.rcParams["font.sans-serif"] = [
    "Noto Sans CJK SC", "Source Han Sans SC", "WenQuanYi Zen Hei", "DejaVu Sans",
]
matplotlib.rcParams["axes.unicode_minus"] = False

# ---- 数据：必须能指回笔记正文/表格 ----
pKa = 4.76                                 # 乙酸，见 知识点/反应类型/酸碱反应.md
pts_x = [2.0, 3.0, 3.76, 4.76, 5.5, 6.0, 8.0]
pts_y = [0.0014, 0.064, 0.36, 0.5, 0.79, 0.943, 0.9998]   # δ(A⁻)
SCHEMATIC = False                          # 没有精确数值时改成 True

# ---- 样式 ----
FIG_BG = "#fbfbfb"                         # 浅色卡片；想透明就改成 "none"
FG, GRID = "#3a3a3a", "#d8d8d8"

fig, ax = plt.subplots(figsize=(6.4, 3.6), dpi=200)
fig.patch.set_facecolor(FIG_BG)
ax.set_facecolor(FIG_BG)

ax.plot(pts_x, pts_y, marker="o", ms=4, lw=1.8, color=FG,
        ls="--" if SCHEMATIC else "-", zorder=3)
ax.axvline(pKa, color=GRID, lw=1.2, ls=":", zorder=1)
ax.axhline(0.5, color=GRID, lw=1.2, ls=":", zorder=1)

ax.set_xlabel("pH")
ax.set_ylabel(r"分布分数 $\delta(\mathrm{A^-})$")
ax.set_title("乙酸的分布分数随 pH 变化", fontsize=12, color=FG)
ax.set_xlim(1.5, 8.5); ax.set_ylim(0, 1.02)
ax.grid(True, color=GRID, lw=0.8, alpha=0.6)
ax.tick_params(colors=FG); ax.xaxis.label.set_color(FG); ax.yaxis.label.set_color(FG)
for s in ax.spines.values():
    s.set_color(GRID)

fig.tight_layout()
# 优先矢量：独立 .svg 走 <img>，不跟随主题（见 SVG画图.md 第一节）
fig.savefig("content/有机化学笔记/图片保存/乙酸分布分数-pH曲线-自绘.svg", transparent=False)
print("saved")
```

## 路线 C · 权威机构现成图

### C.1 可以用（优先查这些）

| 来源 | 许可 | 适合 |
|---|---|---|
| **RCSB PDB** | public domain | 蛋白质/分子 3D 结构与渲染图 |
| **PubChem / NCI Sketcher** | public domain | 结构式、3D 构象 |
| **NIH / NIGMS / NIAMS / CDC** | 多为 public domain 或 CC-BY（**逐张看页面标注**） | 科普示意图、显微图 |
| **Wikimedia Commons** | **逐张看**（多数 CC BY-SA，也有 PD） | 各类示意图 |
| **OpenStax 等开放教科书** | CC-BY | 教科书级配图 |
| **开放获取论文（CC-BY）** | CC-BY（**必须署名**） | 实验数据图 |

### C.2 禁用

- ❌ 商业网站与题库（百度百科、知乎、教科书扫描件、付费资料）
- ❌ 搜索结果里的图片 —— **一律不用**，来源不明
- ❌ 许可看不明白的图 —— 说不清就不动

### C.3 必查四项（缺一不可）

1. **许可**：页面上的 license 标注是什么？CC-BY 要署名；PD 最省事。
2. **这张图画的是不是这个概念**：读图注（caption）和正文，别只看标题。
3. **标注和笔记是否一致**：符号、单位、方向、比例、结构残基编号。
4. **能不能离线**：必须下载到本地，**不外链**（外链会被防盗链、换 URL、离线时直接挂）。

### C.4 操作纪律

- 文件名带来源便于追溯：`细胞膜流动镶嵌模型-Wikipedia.png`
- 图下方必写出处：`*图：Wikimedia Commons，CC BY-SA 4.0*`
  （CC-BY 类必须署名；PD 也写一句，图注里没有来源的外部图一律视为不合格）
- ⚠️ **尽量不改图**。必须裁剪/调色时，在图注里注明「（已裁去图例）」——
  改过就是衍生作品，许可要求要跟着走。
- 分辨率太低的图（文字糊）直接弃用，找 SVG 版本或换来源。
