## 二、七条让它显得「专业」的写法

### 1. 每个结论都跟「为什么」
只给结论 = 复习资料；给本质 = 教材。

> **本质**：决速步生成更稳定的碳正离子中间体（叔 > 仲 > 伯），$\mathrm{X^-}$ 随后结合。

对比同文件里不合格的写法：`碳正离子很稳定。` —— 哪个稳定？为什么稳定？排序依据是什么？

### 2. 数值必须带上下文
`乙炔 | ≈ 25 | 需强碱才拔氢` —— 光写 `25` 是数据，配上「所以会怎样」才是知识。
pKa 表、活性顺序、pH 区间、℃、nm、kDa 都这么写。

### 3. 关键概念加粗，不要花里胡哨
`**马氏规则**`、`**不重排**`、`**顺式加成（syn-addition）**`。
加粗只给「考试要考的点」，一段里超过 3 处加粗就失效了。

### 4. 横向对比一律用表
机理对比、试剂表、活性顺序、条件差异 → 表格。列头加粗，首列加粗。

### 5. 中英双语术语
`亲电加成（Electrophilic Addition）`、`肟（Oxime）`、`鎓离子（bromonium ion）`。
首次出现标英文，之后用中文。跨学科笔记里的**课程专有名词尤其要标**——
读者可能是从另一个尺度来的。

### 6. callout 类型各司其职，别混用
| 类型 | 只用来写 |
|---|---|
| `[!note]` | 概念定义、机理总览 |
| `[!info]` | 分类依据、术语辨析 |
| `[!important]` | 核心机理、定理、必须记住的判据 |
| `[!tip]` | 口诀、活性顺序、合成方案的选择 |
| `[!warning]` | 易错点，**必须写清「为什么错」** |
| `[!example]` | 生物工程应用 / 拓展，**必须给具体工程实例** |
| `[!summary]` | 速记、核心概念清单 |

可用类型由 `quartz/plugins/transformers/ofm.ts` 的 `calloutMapping` 决定，
**没有 `danger`**（有 `bug` / `failure`）。

### 7. 「与生物工程的联系」是整库的脊椎
鱼的学科是生物工程。每篇知识点笔记末尾都要有一节，把有机机理落到具体工程实例：

- 油脂氢化 → 人造黄油 / 反式脂肪酸
- Schiff 碱 → 视紫红质 / PLP 转氨
- NAD⁺/NADH → 生物版 NaBH₄
- 醛缩酶 → 糖酵解的 C–C 键断裂

**写法要求**：一个 `(1)(2)(3)` 小节 = 一个真实机制，说清谁催化、什么底物、什么产物。
空泛的「可用于医药合成」不算。

## 三、公式怎么写

```markdown
$$\mathrm{R{-}CH{=}CH_2 + Br_2 \longrightarrow R{-}CHBr{-}CH_2Br}$$

$$\mathrm{R{-}CH{=}CH_2 \xrightarrow[1.\ H_2O]{(CH_3COO)_2Hg} R{-}CH(OH){-}CH_3}$$

$$\mathrm{R{-}CO{-}R' + R{-}MgX \xrightarrow{H_2O,\ H^+} R{-}CH(O^{-}){-}R'}$$
```

- **独立成行**，不用行内 `$...$`（长式会撑破栏宽）
- **键用 `{-}`**：`\mathrm{C{-}H}`，不要 `\mathrm{C-H}`（减号会变数学减号）
- **双键/三键**：`\mathrm{C{=}C}`、`\mathrm{C{\equiv}C}`
- **条件挂箭头上**：`\xrightarrow{试剂/条件}`、需要分步时 `\xrightarrow[下]{上}`
- **化学式全包 `\mathrm{}`**；元素/基团名不要写进 math（见审校规则）
- **构型**：`$(E)$` / `$(Z)$`、`$(R)$` / `$(S)$`
- **电荷**：`$\mathrm{R_2CuLi}$`、`$\mathrm{X^-}$`、`$\overset{+}{\mathrm{C}}$`
- **裸 `>` 是关系符会自动加内边距**，连排时缝隙忽大忽小 → 写 `\gt` 更整齐（可选）

## 六、画图：SVG，不是 ASCII 也不是 mermaid

**硬规则：笔记里发现用代码块 / ASCII 字符画画的图，一律取缔，优先换成 SVG。**

范本里那两处被删掉的「示意图」（ASCII 能量图、ASCII 转化关系图），
**正确替代物是 SVG，不是「改成表格」**。

- ✅ **内联 SVG 可用**：`processors/parse.ts:30` 有 `remarkRehype, { allowDangerousHtml: true }`，
  `ofm.ts` 的 `htmlPlugins()` 挂了 `rehype-raw`。写原始 HTML（含 `<svg>`）会原样渲染。
- ❌ ASCII 字符画：窄屏必错行。
- ❌ mermaid：本站渲染不出来（上游 rehype-pretty-code 0.10.0 的锅，已放弃）。

**替换时必须先判读，不能照抄**：把 ASCII 的格子 1:1 复刻成 SVG，
只是把难看的图换个难看的画法。正确做法是读上下文 → 搞清楚这张图在讲什么 →
重新设计。五步流程（取证 / 判读 / 选型 / 替换 / 验收）见 `references/SVG画图.md` 第六节。

**优先画 SVG 的场景**：反应机理一步一箭、能量剖面与过渡态、分类树/实验流程、
立体构象（环己椅、顺反排列）、四谱归属分工。

**配色别写死** —— 本站背景是背景图 + 着色层，`stroke="currentColor"` 才会跟随明暗模式。
`<marker>` 的 `id` 必须全站唯一，否则同页多图箭头串位。
完整规矩和可复制模板见 `references/SVG画图.md`。

⚠️ **但也别滥用**：两三个节点的转化，一行文字 `A ──(试剂/条件)──► B` 就够，
不必上图。SVG 有它的成本（md 变长、marker id 要管、必须亲眼验一次渲染）。
